# 固定した相対評価の参照値

`validation1_v802/scores.csv` は `tools/validation1` 全500件の固定参照である。各入力を長時間探索して得た合法な最良解の手数を保存する。最適性は証明していない。

`outputs/` の操作列と `manifest.json` の実行条件、出典、ハッシュもGitで共有する。CSVの `input_sha256` が一致する入力にだけ参照値を使う。詳細な計算記録は [v802の実験ノート](../experiments/v802.md) を参照する。

## 別環境での復元

`main` を更新した後、プロジェクト直下で実行する。

```sh
python3 adhoc/scripts/run_v802_reference.py --install
```

このコマンドは入力と出力のハッシュ、独立再生、公式採点を確認し、500件を `results/eval_records.jsonl` と要約CSVへ登録する。操作列は `results/out/v802/` へ復元する。同じ記録を再度登録しても行は増えない。solverの探索は実行しない。Python 3.9以降とCargoが必要である。

## 固定参照での比較

```sh
python3 adhoc/scripts/run_v802_reference.py --compare
```

保存済みの `tools/validation1` 全500件の評価を、同じ固定参照で集計する。ケースごとに `round(10^9 × 参照値 / 自身のスコア)` を計算し、その平均を示す。`relative_avg_100` は上限相当を100に換算した値である。参照より短い新しい解を得た場合には100を超え得る。

評価画面は従来どおり、登録済みの全版のケース別最小値を使う。v802を登録すると長時間参照がその最小値に加わるが、将来それより短い版が現れれば画面の分子は更新される。固定参照で比較する場合はCSVまたは上の集計コマンドを使う。

この参照用の操作列は検証集合の成果であり、NN学習には使わない。
