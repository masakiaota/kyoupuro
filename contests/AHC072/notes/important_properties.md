# Important Properties

このファイルは、問題の重要な性質を整理する場所である。記号の定義・代表名・型・制約は `notes/notations.md` を参照し、ここでは性質そのものだけを書く。

## 最適化の目的

最小化するのは公式スコア `S = T + 100000E` であり、全帰巣して `E = 0` としたうえで操作数 `T` を減らすことを目指す。総輸送量 `W` を少なくすること自体は目的ではない。

`W` は経路や混載の挙動を調べる診断指標として使う。遠回りによって `W` が増えても、混載や踏み台の利用で `T` が減るなら改善である。探索候補の採否を、`W` の大小だけで決めてはならない。

## 1. 巣への最終ジャンプを可能にする踏み台

### 主張

色 `c` の巣から上下左右の一直線上に `l` マス離れた位置に、高さ `l - 1` 以上の踏み台があれば、その上に載った色 `c` のスライムを1操作で帰巣させられる。ただし、巣まで壁がなく、踏み台に載った時点と巣への着地時点で高さ制限を満たすものとする。

踏み台の高さはちょうど `l - 1` である必要はない。たとえば、高さ4の踏み台を残すなら、飛距離 `l` は1〜5から選べる。また、踏み台の色は色 `c` 以外に限定されない。

### なぜ成り立つか

下の踏み台を残して、上にまとまった色 `c` のスライムだけを飛ばす。`k >= l - 1` なので、飛距離の条件 `l <= k + 1` を満たす。飛ぶスライムはすべて色 `c` であり、上下順序が反転しても巣への着地後にすべて帰巣する。

高さ制限は `h <= 8` および `g + (h - k) <= 8` であり、後者は帰巣前に満たす必要がある。

### 探索・構築での意味

色 `c` の輸送先は巣そのものだけでなく、この条件を満たす踏み台まで広げて考えられる。踏み台に到達した同色のまとまりは、あと1操作で帰巣できる。

## 2. 同色輸送の反転不変性

### 主張

飛ばす部分がすべて色 `c` なら、宙返りによる順序反転を無視できる。同色のまとまり同士が合流した場合も、内部の順序を管理する必要はない。

### なぜ成り立つか

同じ色だけからなる列は、反転しても色の並びが変わらない。下の踏み台が混色でも、そこを崩さず上の同色部分だけを飛ばす限り、この性質が成り立つ。

### 探索・構築での意味

運ぶ同色のまとまりは、色と匹数だけで表現できる。内部の並び順を探索対象から除けるため、状態表現と操作適用を簡単にできる。異なる色を混ぜて運ぶ部分には、別途順序の管理が必要となる。

## 3. 固定踏み台の再利用と構築費用の共有

### 主張

輸送の前後で踏み台が維持されるなら、同じ踏み台を複数の色・複数回の輸送に再利用できる。その構築費用は、利用する輸送全体で共有できる。

### なぜ成り立つか

踏み台の上に着地したまとまりだけを次のジャンプで飛ばせば、下の踏み台の匹数と順序は変わらない。ただし、踏み台自身が帰巣して消える場合などは、同じ高さで再利用できるとは限らない。

### 探索・構築での意味

踏み台の設置位置は、特定の巣への近さだけでなく、利用する輸送全体で削減できる操作回数で評価する。移動するマス数が増えても、長距離ジャンプによって操作回数が減るなら有利になり得る。

配置の採否には、輸送の操作削減量と、踏み台の構築および踏み台自身の帰巣に伴う追加操作の収支を使う。多くの輸送が利用でき、必要な期間維持できる位置が候補となる。再利用できること自体は性質だが、配置によって総操作回数が減るかは、この収支に依存する。

## 4. 固定踏み台網による連続ジャンプ

### 主張

固定された踏み台同士を合法なジャンプでつなげられるなら、運ぶまとまりを踏み台から踏み台へ連続して移動させられる。各中継点で方向を変えられるため、直線状だけでなく、格子状や折れ曲がった配置も輸送網として使える。

### なぜ成り立つか

着地後に下の踏み台を残し、上のまとまりだけを再び飛ばせば、各踏み台を維持しながら輸送を続けられる。各区間で、壁のない直線経路、出発側の `l <= k + 1`、着地側の高さ制限を満たせばよい。同じ高さの踏み台を並べる場合、間隔はその高さに1を足した距離以内でよく、最大距離ぴったりに限らない。

### 探索・構築での意味

踏み台を中継点、1操作での移動を辺とする輸送網として考えられる。固定された網で、運ぶまとまりが各区間の高さ制限を満たすなら、中継点間の輸送操作回数は通る辺の数となる。踏み台の高さが異なる場合、往路と復路でジャンプの可否が異なることがある。

踏み台を高くすると飛距離は伸びる一方、上に載せて運べる匹数は減る。たとえば高さ4の踏み台網では、最大5マスずつ跳べるが、運ぶまとまりは最大4匹となる。配置と高さは、飛距離と輸送容量の両方から評価する。

## 5. 輸送量の積上限と最適な踏み台高さ

### 主張

操作前の塔の高さが `h` のとき、1操作の輸送量には次の上限がある。

\[
W_t \le \left\lfloor \frac{(h+1)^2}{4} \right\rfloor
\]

壁と着地点の高さ制限が妨げなければ、この上限は達成できる。`h <= 8` なので、1操作の輸送量は最大20匹・マスである。20を達成する組み合わせは、次の2つだけである。

- `h = 8, k = 3, l = 4`：踏み台3匹を残し、5匹を4マス運ぶ。
- `h = 8, k = 4, l = 5`：踏み台4匹を残し、4匹を5マス運ぶ。

### なぜ成り立つか

飛距離の条件から、`W_t = (h - k) × l <= (h - k) × (k + 1)` となる。運ぶ匹数 `h - k` と最大飛距離 `k + 1` の和は常に `h + 1` である。和が一定の正整数2つの積は、両者が最も近いとき最大になるため、上記の上限を得る。

等号成立には、最大飛距離 `l = k + 1` を選び、運ぶ匹数 `h - k` と飛距離 `k + 1` の差を1以下にする必要がある。着地点では、別途 `g + (h - k) <= 8` を満たす必要がある。

高さ8の場合の内訳は次のとおりである。

| 残す匹数 `k` | 運ぶ匹数 `8 - k` | 最大飛距離 `k + 1` | 最大輸送量（匹・マス） |
|---:|---:|---:|---:|
| 0 | 8 | 1 | 8 |
| 1 | 7 | 2 | 14 |
| 2 | 6 | 3 | 18 |
| 3 | 5 | 4 | 20 |
| 4 | 4 | 5 | 20 |
| 5 | 3 | 6 | 18 |
| 6 | 2 | 7 | 14 |
| 7 | 1 | 8 | 8 |

### 系：飛距離による輸送量の上限

`l` マス跳ぶには `k >= l - 1` が必要なので、運べる匹数は最大 `9 - l` 匹となる。したがって、`W_t <= l × (9 - l)` が成り立つ。

長く跳ぶほど輸送量が大きくなるわけではない。飛距離4または5のときに、最大の20匹・マスを実現できる。

### 系：操作列全体の輸送量の上限

すべての操作で `W_t <= 20` なので、次が成り立つ。

\[
W \le 20T, \qquad T \ge \left\lceil \frac{W}{20} \right\rceil
\]

これは、その操作列が実現する輸送量に対する必要操作数の下限である。`W` 自体は選ぶ操作列によって変わる。

### 探索・構築での意味

1操作の輸送量を最大化するには、踏み台3匹と荷物5匹、または踏み台4匹と荷物4匹の配分が最適となる。これは巣への接近とは独立した、輸送量そのものの性質である。

高さ3の踏み台を4マス間隔で並べて5匹を運ぶ網と、高さ4の踏み台を5マス間隔で並べて4匹を運ぶ網は、どちらも各ジャンプで20匹・マスを達成できる。ただし、各区間に壁がなく、輸送中に踏み台と荷物が維持されることを前提とする。網の構築や荷物の集約に必要な操作は、この1操作あたりの上限とは別に評価する。

## 6. 混色輸送における積み順と飛距離の偶奇

### 主張

同じスライムのまとまりを、途中で分割したり一部を帰巣させたりせずに運ぶ。踏み台への着地は許すが、まとまりの内部へ別のスライムを挟まないものとする。

このとき、到着時の積み順は、始点と終点の座標和 `i + j` の偶奇、および輸送中の偶数距離ジャンプの回数の偶奇だけで決まる。

| 始点と終点の `i + j` の偶奇 | 偶数距離ジャンプの回数 | 到着時の積み順 |
|---|---|---|
| 同じ | 偶数回（0回を含む） | 出発時と同じ |
| 同じ | 奇数回 | 出発時の逆順 |
| 異なる | 偶数回（0回を含む） | 出発時の逆順 |
| 異なる | 奇数回 | 出発時と同じ |

したがって、**奇数距離のジャンプだけを使う限り、始点と終点を固定すると到着時の積み順も固定される。** 経路を迂回させたり、途中で往復したりしても変えられない。

巣への着地で帰巣が起きる場合、この関係は帰巣処理直前の積み順に適用する。

### なぜ成り立つか

まとまりが跳ぶたびに、その積み順は1回反転する。一方、座標和 `i + j` の偶奇が変わるのは、飛距離 `l` が奇数のときだけである。

奇数距離のジャンプでは、積み順の反転と座標和の偶奇の変化が対応する。偶数距離のジャンプでは、座標和の偶奇を保ったまま積み順だけが反転する。このずれが奇数回生じたとき、始点と終点から決まる通常の向きが逆転する。

壁や迂回は利用できる経路を制限するが、この関係自体には影響しない。

### 系：8匹を分割せずに運ぶ場合

8匹のまとまりを一度に動かすには `k = 0` が必要であり、飛距離は常に `l = 1` となる。また、着地点は空いていなければならない。

したがって、8匹のまとまりを分割せず、途中で帰巣もさせずに運ぶ場合、到着時の積み順は始点と終点だけで決まる。輸送経路の変更では向きを調整できない。

### 探索や構築での意味

- 奇数距離だけで運ぶ区間では、目的地で必要な積み順から、出発時に必要な積み順を逆算できる。到着時の向きが合わない場合、迂回経路を探しても解決しない。
- 同じ始点と終点で逆の向きを実現するには、まとまりを保つ限り、偶数距離ジャンプの回数の偶奇が異なる経路が必要になる。ただし、その経路が存在するかは壁、踏み台、高さ制限に依存する。
- 踏み台は飛距離を伸ばす用途に加え、偶数距離ジャンプを可能にして混色の積み順を調整する用途を持つ。

## 7. 合流点への到着順による積み順の調整

### 主張

同じ合流点へ同じスライムを集めても、先に置くまとまりと後から載せるまとまりを入れ替えると、合流後の積み順が変わり得る。

同じ経路と操作回数で到着順を入れ替えられる場合、集荷の費用を増やさずに積み順を調整できる。その結果、後の配送で必要になる分離や回収の操作を減らせる場合がある。

ここでは、合流点で帰巣が起きず、どちらの到着順も高さ制限などを満たすものとする。

### なぜ成り立つか

先に合流点へ置いた塔は、後から別のまとまりが着地しても順序を保つ。後から来るまとまりは、ジャンプで反転して既存の塔の上へ加わる。このため、到着順が合流後の上下関係を決める。

例えば、巣のない空の合流点に隣接する別々のマスに、下から `[0, 0, 1]` の混色塔と、色1が1匹だけの単色塔があるとする。それぞれを丸ごと1マス跳ばすと、次の違いが生じる。

| 到着順 | 合流後の積み順（下から上） |
|---|---|
| 混色塔 → 単色塔 | `[1, 0, 0, 1]` |
| 単色塔 → 混色塔 | `[1, 1, 0, 0]` |

どちらも2操作で同じ4匹を同じマスへ集めるが、前者では色1が上下に分かれ、後者では連続する。

### 探索や構築での意味

合流点と集荷経路を決める際は、その地点へ各まとまりを到着させる順序も選択対象に含める。同じ位置に同じ色別匹数を集める計画でも、到着順によって以後の配送に必要な操作数が変わり得る。

合流後の輸送で起きる反転と、各巣で帰す順序から必要な積み順を考え、それを作れる到着順を選ぶ。同色を連続させておくことは、帰巣後の取り残しや追加の積み替えを減らす手段になる。

## 8. 同色のまとまりを利用した帰巣と輸送

### 主張

塔内で色 `c` のスライムが一つの連続したまとまりになっていれば、その直下または直上で切り分けることで、帰巣と他色の輸送を1操作で行える。

次の2通りがある。ただし、各操作は飛距離、壁、着地時の高さ制限を満たすものとする。

1. 色 `c` のまとまりの直下で切り、その上側全体を色 `c` の巣へ飛ばす。飛ぶ部分が反転するため、色 `c` が最上段に来て帰巣する。上にあった他色も同じ巣まで運ばれる。
2. 色 `c` の巣の上で、そのまとまりの直上にあるスライムをすべて飛ばす。出発点で色 `c` が露出して帰巣する。飛ばした他色は次の配送へ進められる。

したがって、巣への到着時に対象色が最上段になっていなくても、覆っている他色を合法に送り出せるなら、追加の1操作でその色を帰巣させられる。

### なぜ成り立つか

着地点では、飛ぶ部分の最下段にあったスライムが反転によって最上段になる。そのため、対象色のまとまりを飛ぶ部分の下端に含めれば、上に他色が載っていても着地後に対象色が帰巣する。

出発点では、残した部分の積み順が変わらない。対象色を覆う上側だけを飛ばせば、残った塔の最上段に対象色が露出し、連続する同色が帰巣する。

出発点で帰巣するスライムも、ジャンプ時には下段の `k` 匹に含まれる。自身が帰巣する直前に、他色を遠くへ送る踏み台として利用できる。

### 探索や構築での意味

集荷では、同色を連続したまとまりにすることに価値がある。まとまりの上下を切り分けることで、その色を一度に帰巣させやすくなる。

帰巣のために覆いを外す操作も、他色を次の目的地へ運ぶ操作として使える。そのため、巣への到着時に対象色が露出する向きだけを選ぶと、帰巣と後続の輸送を兼ねる手順を逃す場合がある。

向きによって、飛ばす匹数、残せる踏み台の高さ、他色が残る位置は変わる。これらを含む全帰巣までの操作数で比較する。性質6の反転の制約は残るが、同色がまとまっていれば、到着時の向きを整える必要が小さくなる場合がある。

## 9. 輸送中の部分取り出しと再合流

### 主張

塔の中央にある連続した部分を別の場所へ送り出し、残りを元の積み順で再合流させて、輸送を続けられる。

取り出す部分は混色でもよい。残りの塔の上下関係と内部順序だけでなく、取り出した部分の内部順序も保てる。

### 手順

次の配置を考える。矢印は1マスの移動を表す。4か所は異なる床マスであり、中継点、合流先、送り出し先は空いているものとする。また、これらの場所で帰巣は起きないものとする。

```text
開始位置 → 中継点 → 合流先
              ↓
          送り出し先
```

開始時の塔を、下から「下段／取り出す部分／上段」の3部分として考える。ここでは3部分とも空でないものとし、次の4操作を行う。

1. 塔全体を中継点へ運ぶ。反転により、元の下段が最上部になる。
2. 元の下段を合流先へ飛ばす。
3. 露出した取り出す部分を、送り出し先へ飛ばす。
4. 中継点に残った元の上段を合流先へ飛ばし、下段の上に載せる。

合流先には「下段／上段」、送り出し先には「取り出す部分」ができる。元の塔から中央の一区間だけを抜いた形になる。

### なぜ順序を保てるか

各部分は、中継点へ入るときと中継点から出るときの2回反転するため、内部の積み順が元に戻る。

合流先には元の下段を先に置き、元の上段を後から載せるため、両者の上下関係も元どおりになる。各操作でできる塔の高さは開始時の塔の高さ以下であり、高さ8の制限も満たす。

塔全体なら2操作で通過する区間を4操作で進むので、この手順による部分取り出しの追加操作は2回である。

積み順は開始位置での塔を基準にしている。合流先は中継点から1マス先で、開始位置からは2回の1マス移動で到達する。再合流した塔全体をさらに1マス運ぶと、残りの塔全体が逆順になる。

### 特殊例：中継点が対象色の巣である場合

取り出す部分が塔内の色 `c` をすべて含む同色のまとまりで、中継点が色 `c` の巣なら、手順2で覆いが外れた直後に自動で帰巣する。このとき手順3と送り出し先が不要となる。合流先では帰巣が起きないものとする。

したがって、3操作でその色だけを帰巣させ、残りを元の積み順で合流先へ運べる。通常の通過に対する追加操作は1回である。

### 探索や構築での意味

混載した塔の一部を、途中で踏み台として残したり、別の配送経路へ送り分けたりできる。その後も、残りを一つの塔にまとめて運び続けられる。

この操作では、取り出す部分の前後にある色のまとまりや上下関係を維持できる。そのため、一部を途中で降ろすことを含めて、混載する範囲と輸送経路を計画できる。

## 10. 帰巣のない隣接2マス間の操作列の圧縮

### 主張

壁で隔てられていない隣接2マス間だけで連続して操作し、その間に出発点と着地点のどちらでも帰巣が起きないものとする。

このとき、操作列全体を0〜1操作へ置き換え、終了時のスライムの配置を積み順まで再現できる。同じ方向へ分けて運ぶ場合と、往復する場合の両方に成り立つ。

### なぜ成り立つか

一方の塔を下から上へ、続けてもう一方の塔を上から下へ読む。この読み方では、飛ぶ部分の反転によって、色の並びが常に保たれる。操作で変わるのは、一続きの列を2つの塔に分ける境界だけである。

したがって、開始時の配置を固定すると、終了時の各塔の高さだけで積み順も決まる。高さが減った側から増えた側へ、その差に相当する匹数を一度移せば、同じ配置になる。両方の高さが開始時と同じなら、配置も元どおりなので、操作列全体を省ける。

置き換えた操作の着地高さは元の終了時と同じであり、1マスの移動には踏み台が不要なので、置き換え後も合法である。

### 探索や構築での意味

すべての合法な1操作を候補に含める探索では、直前と同じ隣接2マス間を移す操作を、直前と今回のどちらでも帰巣が起きない場合に枝刈りできる。同じ配置へ、より少ない操作で到達できるためである。

既に得た操作列の短縮にも使える。同じ隣接2マス間での連続操作を見つけ、その間に帰巣が起きていなければ、開始時と終了時の高さの差から0〜1操作へまとめられる。

帰巣を伴う操作列や、他のマスへの移動を挟む操作列は、この圧縮の対象外である。
