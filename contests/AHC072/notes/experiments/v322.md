# v322: 少数マスの差分を追う操作列の局所書換え

## 実験前

基準は main 7e5c9ba03eadf0a7bb143a476b9f878ecc341cbb の v113_integrated_nn_lns.cpp（SHA256 037f9fcca137552c097bc396428699850cf591cf58e513e874c9058309bfd258）。新しい実験番号と関連する履歴を照合した。validation1の入力と評価値を本実験では使わない。

- 仮説: O75は、小さい操作差でも64手を超える期間に影響が残る保存例を示す。O53/O77の全個体除去による支持破壊も踏まえ、1操作を削除し、後続の少数操作だけを変更して元の色盤面へ戻せば、全履歴の除去と逐次再挿入では作りにくい短縮を作れる。Planning by Rewriting（Ambite/Knoblock, JAIR 2001, DOI 10.1613/jair.754）を着想とするが、本実装はこのゲーム向けの独自近傍であり同論文の再現ではない。
- 変更: v113を保持し、差分が最大4マス、幅8、元列256操作までの書換え探索を加える。元の1操作を省き、影響を受ける後続操作を同じ着地点への合法な分割変更または差分マスからの直接移動へ変更する。追加の省略を含め省略は最大3、編集は最大12。操作追加はしない。無関係な操作はそのまま通す。途中の高さ差も許し、同色個体は色列として扱う。元と全色盤面が一致した時だけ完成候補を返す。幅制限の順位は未一致の色数とマス数を使うヒューリスティックであり下界と呼ばない。
- 機構確認: 一時的な高さ差、分割変更、出発点変更、64手超の無関係な操作を含む人工列を検査する。差分表現と全盤面再生を照合する。帰巣前の容量、壁、支持距離、積み順、出発点と着地点の帰巣を検査する。完成候補は独立に再生し、全帰巣を確認する。LOCALと非LOCALの両ビルド、完全前処理の変更範囲、NNの重みと既存時計の保持を確認する。幅刈り、差分上限、編集上限、期限による打切りと実際の採用を別計数する。
- 採否基準: 新規公式生成128件とin100件で親を同条件で評価する。新規集合とinの両方で絶対合計非悪化、inのv800単独固定参照相対値改善、全出力合法かつ全帰巣、既存の診断エラー0、外部2秒以内を必須とする。厳密な1.9秒以内も別途報告する。条件を変更せずinまで評価し、未達ならv113を維持する。in195手以下は目標であり保証しない。

追加近傍は並べ替え以外の29反復ごとの枠で試し、累積費用を各LNSの使用時間の6%までに制限する。1試行の期限はPROGRAM_TIME_LIMIT_SECの0.00075倍、全体と育成区間の期限以内とする。開始操作は既存乱数で一様に選ぶ。NN重み、初期候補数、育成配分、通常の再挿入、受理式と時計は変更しない。得点を見て頻度や幅を変更しない。

GCC14.2/C++23、非LOCAL、親の1.9秒基準、2並列で行う。この環境にはGCC15がないため、ユーザー環境の数値と直接差を取らない。新規seedは3220000000000から64刻みの128個に固定し、inとの内容重複だけを検査する。validation1は重複検査にも開かない。各入力各版1回、ウォームアップを除外し、同じ入力の親子を同じCPUで続けて実行してAB/BAを交替する。公式Rust visと独立Python再生で採点する。共有評価ログとeval viewerには登録しない。

v063/v064/v065は任意終点への個体再挿入、v050系は経路ごとの向き差の継続、既存Joint/Finiteは選択した窓と塔の探索である。本案は個体の予定を抜かず、操作省略で生じた色盤面差を可変の4マスで運び、高さ差も許す。一般的な共同探索の優位までは主張しない。

実装と診断を凍結してから評価する。通常のスコア結果による修正、候補差し替え、追加学習は行わない。結果と調査記録、完全CPPをmainへ直接保存する。
