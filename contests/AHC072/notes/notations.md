# 記号一覧

このファイルは、問題で使う記号と、実装・会話で使う代表名・型・制約の正本である。

## 表記方針

- 公式記号名はコードでも保持する。`N`, `K`, `T`, `E` などを、対応付けだけを目的に小文字へ変えない。
- 座標・色・操作番号はすべて 0-based とする。
- 座標 `(i, j)` は上から `i` 行目、左から `j` 列目を表す。
- 塔内の順序を書くときは下から上の順とする。
- 会話とコードでは、入力しやすい ASCII 表記の `h`, `k`, `d`, `l`, `rho`, `beta` を使う。
- 解法上の評価値や探索状態は、確定するまでこのファイルへ加えない。

## 入力と盤面

### 盤面サイズ `N`

盤面の一辺の長さである。

- コード上の代表名: `N`
- C++ 型: `int`
- 制約: `12 <= N <= 20`
- 座標範囲: `0 <= i < N`, `0 <= j < N`

### 色数 `K`

スライムと巣の色数である。色は `0, 1, ..., K - 1` で表す。

- コード上の代表名: `K`
- C++ 型: `int`
- 制約: `4 <= K <= 12`

### 色 `c`

任意の1色を指定する記号である。スライムの色と巣の色に共通して使う。

- コード上の代表名: `c`
- C++ 型: `int`
- 範囲: `0 <= c < K`

### 初期盤面 `C[i][j]`

入力文字列 `C_i` の `j` 文字目であり、マス `(i, j)` の初期状態を表す。

- コード上の代表名: `C`
- C++ 型: `vector<string>` または `array<string, 20>`
- 添字範囲: `0 <= i, j < N`
- `#`: 壁
- `.`: スライムも巣もない床
- `a` から `a + K - 1`: 対応する色のスライムが1匹いる床
- `A` から `A + K - 1`: 対応する色の巣がある床
- 不変条件: 床は少なくとも `2K` マスあり、上下左右の隣接関係について連結である。
- 不変条件: 各色の巣はちょうど1個、各色のスライムは1匹以上存在する。

### 座標 `(i, j)`

盤面上のマスを表す。左上が `(0, 0)` であり、`i` は下向き、`j` は右向きに増える。

- コード上の代表名: `Point { int i, j; }` または `pair<int, int>`
- C++ 型: 各成分は `int`
- 範囲: `0 <= i, j < N`

## 塔と操作

### 塔の高さ `h`

操作前の出発点 `(i, j)` に積まれているスライム数である。

- コード上の代表名: `h`
- C++ 型: `int`
- 操作可能条件: `1 <= h <= 8`
- 全盤面での不変条件: 塔の高さは常に `0` 以上 `8` 以下

### 下に残す匹数 `k`

宙返りジャンプで出発点に残す、塔の下側のスライム数である。

- コード上の代表名: `k`
- C++ 型: `int`
- 制約: `0 <= k < h`
- 跳ぶ匹数: `h - k`
- 操作後も、残った `k` 匹の上下順序は変わらない。

### 方向 `d`

宙返りジャンプの方向である。

- コード上の代表名: `d`
- C++ 型: `char`
- 値: `U`, `D`, `L`, `R`
- 座標差: `U=(-1,0)`, `D=(1,0)`, `L=(0,-1)`, `R=(0,1)`

### 飛距離 `l`

出発点から着地点まで、方向 `d` に進むマス数である。

- コード上の代表名: `l`
- C++ 型: `int`
- 制約: `1 <= l <= k + 1`
- 通過条件: 出発点から `1, 2, ..., l` マス先がすべて盤面内の床である。
- 備考: 途中の床にある塔は飛び越えられる。

### 着地点の操作前の高さ `g`

宙返りジャンプの着地点に、操作前から積まれているスライム数である。

- コード上の代表名: `g`
- C++ 型: `int`
- 制約: `0 <= g <= 8`
- 着地可能条件: `g + (h - k) <= 8`
- 備考: この条件は、着地後の帰巣が起こる前の高さで判定する。

### 塔の内容 `tower[i][j]`

マス `(i, j)` にいるスライムの色を、下から上の順に保持する実装用状態量である。

- コード上の代表名: `tower`
- C++ 想定型: `array<array<vector<int>, 20>, 20>`、または高さ上限8を使った固定長表現
- 要素の範囲: 各色 `c` は `0 <= c < K`
- 不変条件: `tower[i][j].size() <= 8`
- 宙返りジャンプ: 上側 `h - k` 匹の順序を反転し、着地点の塔の上へ追加する。
- 帰巣: 巣の色と最上段の色が一致する間、最上段を取り除く。

### 巣の色 `nest[i][j]`

マス `(i, j)` にある巣の色を表す実装用状態量である。

- コード上の代表名: `nest`
- C++ 想定型: `array<array<int, 20>, 20>`
- 値域: 巣がなければ `-1`、巣があれば `0 <= nest[i][j] < K`
- 不変条件: 各色の巣は盤面にちょうど1個ある。

## 出力と得点

### 操作番号 `t`

出力する操作の番号である。

- 添字範囲: `0 <= t < T`
- 1行の出力: `i_t j_t k_t d_t l_t`

### 操作回数 `T`

出力した宙返りジャンプの総数である。

- コード上の代表名: `T`
- C++ 型: `int`
- 制約: `0 <= T <= 100000`

### 残存スライム数 `E`

全操作終了時に盤面上へ残っているスライムの総数である。

- コード上の代表名: `E`
- C++ 型: `int`
- 範囲: `0 <= E <= M <= N^2`

### 絶対スコア `S`

各テストケースの絶対スコアである。

`S = T + 100000 E`

- コード上の代表名: `S`
- C++ 型: `int64_t`
- 評価方向: 小さいほどよい。

### 相対評価の `MIN` と `YOUR`

- `YOUR`: 自身の絶対スコア
- `MIN`: そのテストケースで全参加者が得た絶対スコアの最小値
- 相対評価スコア: `round(10^9 * MIN / YOUR)`

## 輸送量

### 操作ごとの輸送量 `W_t`

操作 `t` で動かしたスライムの匹数と、移動したマス数の積である。スライム1匹を1マス動かす輸送量を1とする。

`W_t = (h - k) × l`（`h`, `k`, `l` は操作 `t` の値）

- コード上の代表名: `W[t]`
- C++ 型: 各要素は `int`
- 添字範囲: `0 <= t < T`
- 単位: 匹・マス
- 遠回りや巣から遠ざかる移動も含め、実際に動かした距離を数える。巣までの最短距離の減少量とは区別する。

### 操作列全体の輸送量 `W`

各操作の輸送量の総和である。

\[
W = \sum_{t=0}^{T-1} W_t
\]

- コード上の代表名: `total_transport`
- C++ 型: `int64_t`
- 単位: 匹・マス
- `T = 0` のとき `W = 0`。
- `T > 0` のとき、`W / T` は1操作あたりの平均輸送量を表す。

## 入力生成で使う記号

### スライム密度 `rho`

- コード上の代表名: `rho`
- C++ 型: `double`
- 生成範囲: `[0.12, 0.65)`

### 壁の提案率 `beta`

- コード上の代表名: `beta`
- C++ 型: `double`
- 生成範囲: `[0, 0.40)`

### 巣のない床の数 `F`

- コード上の代表名: `F`
- C++ 型: `int`
- 意味: 巣を配置した後の、巣がない床マスの数

### スライム総数 `M`

`M = max(K, round(rho F))`

- コード上の代表名: `M`
- C++ 型: `int`
- 範囲: `K <= M <= F <= N^2`

### 色数生成用の境界 `s_i`

`K - 1` 個の整数を `[0, M - K]` から独立に一様生成し、昇順に並べた値である。

- コード上の代表名: `s`
- C++ 型: `vector<int>` または `array<int, 13>`
- 添字範囲: `0 <= i <= K`
- 端点: `s_0 = 0`, `s_K = M - K`
- 不変条件: `s_0 <= s_1 <= ... <= s_K`

### 色 `c` の初期スライム数 `b_c`

`b_c = s_{c+1} - s_c + 1`

- コード上の代表名: `b`
- C++ 型: `vector<int>` または `array<int, 12>`
- 添字範囲: `0 <= c < K`
- 不変条件: `b_c >= 1` かつ `sum(b_c) = M`（全色 `c` についての総和）
