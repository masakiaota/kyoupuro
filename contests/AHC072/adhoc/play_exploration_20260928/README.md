## 確認できた圧縮性質の拡張

帰巣のない固定2マス間の操作は、隣接していなくても0〜1手に圧縮できる。2マスが壁のない一直線上にあり、元の各操作が合法であることを前提とする。

性質10と同じく、一方を下から上へ、もう一方を上から下へ読んだ列が不変である。正味の送り出し側で最後に送り出した直後には、飛距離 `l` に対して `k >= l - 1` が成り立つ。その後は受け取りしかないので、その側の終了時の高さも `l - 1` 以上である。したがって、開始時と終了時の高さの差だけを一度に送る操作も、飛距離と着地高さの条件を満たす。

さらに、間にある操作が両端のどちらも出発点または着地点にしなければ、その操作を挟んだ2点間の転送もまとめられる。飛び越す途中の塔には操作が作用せず、その高さも合法性に関係しないためである。
