# 重ね合成による無傷 3 巡回(overlap composition)[IDEA-C18]

- 出自: 2026-07-18、ユーザー発案(ビジュアライザー観察:「同サイズの縦長方形を 2 つ並べると、並べ方次第で 2 回スワップされて元に戻るものができ、途中を崩さず 1 個の要素をスキップ搬送できるのでは」)。Claude が定式化し、シミュレーションで検証した。
- 位置づけ: 問題文から演繹できる操作の合成性質。`notes/important_properties.md` への転記候補(許可待ち)。応用先は終盤パターン(IDEA-C6)、保護確定系の経路自由化(v004/v011、IDEA-C13)、2 手マクロ候補(IDEA-C17 と並ぶ候補拡張)。

## 1. 性質の言明

### (a) 行ずらし版(同じ列範囲・帯を s ずらす)

シフト量 d の縦半交換 2 つを、同じ列区間(幅 w)で行方向に s(1 <= s <= d)ずらして連続適用する:
A = (r, c, 2d, w) → B = (r+s, c, 2d, w)。合併帯 [r, r+2d+s) × 列区間が両操作とも合法(内部壁なし)であることが実行条件。

正味の置換は「**幅 s の 3 ブロック [r, r+s)、[r+d, r+d+s)、[r+2d, r+2d+s) の巡回**」×(w 列同時)であり、**帯内の残り 2(d−s) 行 × w 列は完全に元へ戻る**。巡回方向は適用順(A→B / B→A)で反転する。

### (b) 列ずらし版(同じ帯・列範囲をずらす)

同じ帯 (r, 2d) で列区間だけ違う 2 つの縦操作を連続適用すると、**重なった列は 2 回交換されて恒等に戻り、対称差の列だけが上下交換される**。連続区間しか選べない制約を 2 手で「離れた 2 つの列区間の同時交換」「区間の切り抜き」に拡張できる(列ごとに独立なので自明に成立)。

横操作でも (a)(b) とも対称に成り立つ。

## 2. 検証

Python シミュレーション(2026-07-18、1 列分)で確認済み:

| d | s | 動くカード | 内容 |
|---|---|---|---|
| 9 | 1 | 3 枚のみ | 0→18, 9→0, 18→9(等間隔 3 サイクル)。間の 16 枚は無傷 |
| 9 | 2 | 6 枚 | 幅 2 ブロック 3 個の巡回。他は無傷 |
| 5 | 1 | 3 枚のみ | 0→10, 5→0, 10→5 |
| 5 | 5 (=d) | 15 枚 | 3 ブロック回転(無傷部分なし、s=d の極限) |
| 3 | 2 | 6 枚 | 幅 2 ブロック 3 個の巡回 |

証明スケッチ: 帯の重なり部分 [r+s, r+2d) のカードは、A で属した半分と B で属する半分が必ず逆になる(A の上半分→B では下半分相当、など)ため +d と −d が相殺する。相殺しないのは A だけに含まれる [r, r+s) と B だけに含まれる [r+2d, r+2d+s)、およびそれらの往来相手 [r+d, r+d+s) の 3 ブロックのみ。

## 3. 応用

1. **終盤の等間隔 3 サイクルが 2 手・巻き添えゼロ**。従来知見では一般 2 枚交換は共役 g·s·g の 3 手でしかも成立条件付き(important_properties「任意の二枚交換を常に三操作で実現できるとは限らない」)。本構成は (x, x+d, x+2d) 型の 3 サイクルを 2 手で無条件に(壁が許せば)解消でき、確定効率は 1.5 枚/手と互換 3 手(0.67 枚/手)の 2 倍超。IDEA-C6 パターン表の主力エントリになる。d は 1..9 で選べるので (x, x+d, x+2d) の族はかなり広い。
2. **無傷ブロック搬送**: s 幅のブロックを d ずつ「ワープ」させ、通過帯を毎回無傷に保てる。s=1, d=9 の反復で 1 枚を 18 行ずつスキップ搬送。
3. **保護確定系の経路自由化**(v004/v011 に直結): 現行の保護は「確定セルを巻き添えにしない」制約で搬送経路を制限している。本構成を 2 手アトミックなマクロとして扱えば、確定セルのカードは 1 手目で動いても 2 手目で戻るため、**3 ブロック位置にだけ確定セルがなければ、確定領域を貫通する搬送が合法化できる**(保護不変量を「各手後」から「マクロ完了後」に緩める)。経路蛇行(claude_v004_improvement_analysis.md の無駄 1)と袋小路の迂回(IDEA-C13)の両方を緩和する新しい攻め口。
4. 3 連発以上(k 個の対合の積)でさらに一般の置換を無傷構成できる可能性は未探索の問い。

## 4. 限界

- 合併帯 [r, r+2d+s) の壁なしが必要で、**壁を飛び越える搬送はできない**(壁強ケースの通路問題は解決しない)。
- 巡回の 3 点は等間隔 (x, x+d, x+2d) に限る。任意 3 点の巡回には使えない。
- 2 手で 3s·w 枚の巡回なので、益が出るのは「3 ブロックのうち 2 つ以上が得する」局面。探索での使い方は、2 手マクロ候補として生成し木距離和評価に判定させる形が安全(v011 の候補拡張と同じ流儀)。
