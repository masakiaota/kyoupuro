## 部品用語集

解法部品に名前をつけ、エントリはこの用語で書く。

- **葉剥がし**: 全域木の葉へ正しいカードを隣接 swap で運び、その葉を以後の経路から除外する整列手順。
- **階層シフト**: シフト量を `10,5,3,2,1` の順に固定し、同じ座標残差を持つカードを長方形操作へ相乗りさせる計画。

## v003_timed_complete — 棄却: 固定した粗密順序が狭い通路の処理を終盤へ押し込む
- 仮説: 階層シフト候補を複数軌道へ展開し、各終端を実際の完成列長で比較すれば、単手貪欲の局所最適を回避しつつ全ケースを完成させ、隣接 swap baseline より短い解を得られる
- 変更: `v002_hierarchical_shift` を基に、各段階で上位複数操作を展開する時間制ビーム探索へ置換する。各ビーム終端には同一の葉剥がし完成処理を適用し、階層シフト prefix と合わせた総 `T` を探索評価と出力選択に使う
- 機構確認: TraceStats の `beam_expanded`・`beam_kept`・`beam_rounds`・`complete_candidates`・`best_updates`、選択した prefix/tail 操作数、最終 `E`、探索経過時間
- 採否基準: tools/in 100 ケースで全操作合法、全ケース E=0、T<=100,000、最大実行時間が制限内で、平均得点が v001_baseline の 3,528,927 を上回れば採用する。10,000,000 との差も併記する
- 結果: tools/in は 100/100 ケースで合法かつ E=0、T<=11,040、最大 1,411ms。v001 比で平均得点 +11.6%、平均 T -23.2%となり全採否条件を達成したが、10,000,000 には 60.6%届かない。選択 prefix は全ケース非空で、複数分岐ノード最小 36,754、平均 27.85 beam round、平均 109.79 完成候補、平均探索時間 1.400s を確認
- 学び: 操作サイズを大から小へ固定すると、大操作が通れない狭い通路のカードが終盤まで残り、その後に必要となる隣接 swap が既に整えたマスを再び崩すため、次は階層を設けずに大小の合法操作を全深さで同時に候補化する通常のビームサーチを検討する

## v005_chokudai_free — 棄却: needs 主評価が tail 長と乖離、探索評価は総 T 推定でなければ効かない
- 仮説: シフト量を階層で固定せず毎手 δ=1..10 の全帯から needs 純益 Kadane で候補を作り、深さ別キューの chokudai 探索で時間を使い切れば、正益限定の単手貪欲の停滞(v002)と粗密固定の終盤押し込み(v003)を代替軌道で回避し、v003 より短い完成列を得られる
- 変更: 新規 `v005_chokudai_free`(Claude 実装)。v000_template の土台と v001 の葉剥がしを tail 部品化し、自由 δ の帯 Kadane 候補上位 K=12 を深さ別キュー(容量 64、最大深さ 320)で chokudai 展開、Zobrist で深さ別重複排除、E が記録を 8 以上更新したノードにのみ tail を実走して prefix+tail の総 T 最小を anytime 保持する(開始時に初期盤面へ tail を実走して完成列を初期化するため E=0 は構造的に保証)
- 機構確認: TraceStats の `rounds`・`expanded`・`dup_hits`・`tail_runs`・`best_updates`・`complete_by_search`、best の prefix/tail 内訳、local 時の出力列再生 assert、経過時間
- 採否基準: tools/in 100 ケースで全操作合法、全ケース E=0、T<=100,000、時間制限内。平均得点が v003_timed_complete の実測(v001 比 +11.6% ≒ 3,938,000)を上回れば採用候補、6,500,000 以上(幾何平均 T およそ 1,100 以下)なら主系列候補。OBS-A02 天井(平均 8.874M)との差も併記する
- 結果: tools/in は 100/100 で scorer 成功(全ケース E=0、max 1,434ms)。平均得点 3,709,129(min 2,879,464 / max 4,335,954)。正当性 gate は全通過したが、採用候補基準 3,937,085(v003 実測)に対し −5.8% で未達(v001 比では +5.1%)。幾何平均 T 換算は v001 ≈ 8,667 → v005 ≈ 7,651 → v003 ≈ 6,527。天井 8.874M の 41.8%。機構確認(0000)は全発火: expanded 46,415、dup_hits 28,293、tail_runs 10、best = prefix 317 + tail 7,129、E は 400→336 までしか低下せず総手数は tail が支配
