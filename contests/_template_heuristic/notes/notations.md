# 記号一覧

このファイルは、問題で使う記号と、実装・会話で使う代表名・型・制約の正本である。以下は記載例であり、実際には問題固有の記号で置き換える。(置き換えたらこの文章を削除せよ。)

## notation 方針

- 公式記号名は保持する。公式が `N`, `M` なら `N`, `M` と書き、Rust 風の `n`, `m` へ直さない。
- 添字は原則 0-based にし、`h[i,j]` のような配列アクセス風表記にしてよい。
- 問題文にない実装用の状態量は、`state[g]`, `X[p,g]` のようにコードとの対応が見える名前にする。
- TeX は条件付き確率、総和、総積、比例関係などの構造だけに使い、コードフェンスには入れない。
- 解法考察や仮説は混ぜない。状態量・添字・型・不変条件だけを書く。

## 固定サイズ

### 入力サイズ `N`

問題の主要なサイズを表す。グリッド問題なら盤面サイズ、列問題なら列長のように、問題ごとの主サイズとして使う。

- 議論用 notation: `N`
- コード上の代表名: `N`。実装で別名を使うなら `n`, `size` なども併記する。
- Rust 型: `usize`
- index 範囲・不変条件: 問題文の制約に従う。0-based 添字の境界判定では `0 <= i < N` を使う。
- 備考: 問題に複数サイズがあるなら、`N` を使う対象を明示する。

## 座標・要素

### 位置 `pos[i,j]`

グリッド上の位置を表す。`i` は行、`j` は列である。

- 議論用 notation: `pos[i,j]`
- コード上の代表名: `pos`, `Point { i, j }`, `(i, j)`
- Rust 型: `(usize, usize)` または専用 `struct`
- index 範囲・不変条件: `0 <= i < H`, `0 <= j < W`
- 備考: 公式問題文が `(1,1)` 始まりの場合でも、実装・議論では 0-based の `pos[i,j]` に直して扱う。

### turn ごとの値 `value[t,i]`

turn `t` における要素 `i` の値を表す。時系列の観測、スコア寄与、配列更新などの例で使う。

- 議論用 notation: `value[t,i]`
- コード上の代表名: `value`, `values`, `history`
- Rust 型: `Vec<Vec<i64>>`, `Vec<Vec<f64>>`, または固定長配列
- index 範囲・不変条件: `0 <= t < T`, `0 <= i < N`
- 備考: 公式問題文の query 番号が 1-based の場合は、実装上の `t` が `k - 1` に対応することを明記する。

## 状態量

### セグメント状態 `state[g]`

グループ、行、列、区間など、同じ構造を持つ単位 `g` の状態を表す。

- 議論用 notation: `state[g]`
- コード上の代表名: `state`, `states`, `SegmentState`
- Rust 型: `Vec<State>` または固定長配列
- index 範囲・不変条件: `0 <= g < G`
- 備考: `g` が何を連番化したものか、例えば前半が行・後半が列などの場合はここに書く。

### パラメータ配列 `X[p,g]`

状態 `g` に属する成分 `p` のパラメータを表す。

- 議論用 notation: `X[p,g]`
- コード上の代表名: `x`, `param`, `params`
- Rust 型: `[[f64; G]; P]`, `[[f64; P]; G]`, `Vec<[f64; P]>` など。実際の添字順を必ず書く。
- index 範囲・不変条件: `0 <= p < P`, `0 <= g < G`
- 備考: 議論用 notation と Rust の実メモリ配置が逆順なら、ここで `X[p,g]` は `params[g][p]` に対応すると明記する。

## 数式の書き方

数式では公式記号名を保ち、添字や実装で追加した状態量だけ配列アクセス風 notation を使う。

$$
p(state[g] \mid data[t], state_without[g])
$$

総和や比例関係も、構造だけ TeX に寄せる。

$$
score
\propto
\sum_{t=0}^{T-1}
weight[t] value[t,i]
$$

コードフェンスは入力形式や plain text の対応表にだけ使う。TeX 数式はコードフェンスに入れない。
