# Journal

実験の正史である。1 実験 = 1 エントリを「エントリ」節の下に時系列で追記する。
書式・更新義務・判定ルールは AGENTS.md の「実験知見の記録」に従う。

エントリの書式例を示す。着手時は見出しを `## <bin名> — 実験中` とし、仮説・変更・機構確認・採否基準の 4 行だけを書く。判定時に見出しを確定し、結果・学びの 2 行を追記する。(最初のエントリを書くときに、この説明と以下の例を削除せよ。)

```markdown
## v012_reconnect — 棄却: 発動するが採択されない
- 仮説: 停滞の原因は近傍が 2-opt だけなこと。セグメント再接続近傍なら山を越えられる
- 変更: v008 ベース + SA に reconnect 近傍を追加。それ以外は不変
- 機構確認: TraceStats の reconnect_accept が全ケースで 1 以上 → 実測: 発動あり、採択率 0.3%
- 採否基準: tools/in の total_avg が v008 を +0.5% 以上上回る
- 結果: v008 比 +0.1% で基準未達
- 学び: delta が温度に対して大きすぎて採択されない。再開条件: 低温帯の kick として使う場合
```
