# 現在地

目標、評価方針、提出状況、提出候補、実験中の一覧の正本である。新しいセッションは、まずこのファイルで現在地を把握する。

## 書くこと・書かないこと

書くこと

- 現在の目標と評価方針。
- ユーザーが報告した AtCoder の直近の提出と、その結果。
- 次の提出候補と、その根拠となる実験ノートへのリンク。
- 実験中の実験番号とテーマ。1 件 1 行で記す。

書かないこと

- 経過、過去の値、過去との差分、セッションの作業記録。常に現在の状態だけを書き、変わったら該当箇所を書き換える。
- 実験の内容、結果、考察。これらは実験ノートに書き、ここからはリンクする。
- 未着手の案と観察。これらは [backlog.md](backlog.md) に書く。
- 問題の性質と記号。これらは [important_properties.md](important_properties.md) と [notations.md](notations.md) に書く。
- セッションや端末ごとの個別報告。項目は 1 つの現在値だけを持ち、報告者ごとに段落を増やさない。

各節は数行に保つ。節が伸びてきたら、上の「書かないこと」に当たる内容が混ざっていないか確かめる。
