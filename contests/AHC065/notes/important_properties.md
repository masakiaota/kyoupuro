# Important Properties

このファイルは、問題の重要な性質を整理する場所である。記号の定義・代表名・型・制約は `notes/notations.md` を参照し、ここでは性質そのものだけを書く。

## 1. 縦横ベルト戦略は未来箱の集約が弱い

### 主張
2行リングと2列リングを敷く縦横ベルト戦略は、任意の箱を `E` へ短経路で運びやすい一方、後続の箱を戦略的に `E` 付近へ集める力が弱い。

### なぜ成り立つか
各操作の副作用は同じ2行または同じ2列のリング内に閉じやすく、盤面全体から `E` へ向かう一方向の流れを作りにくい。現在の箱を動かす操作が、後続の箱を入口側へ集約する staging になりにくい。

### 実装上どう効くか
縦横ベルト上の経路探索や未来距離評価を強化しても伸びが頭打ちになりやすい。上位を狙うには、ベルト配置そのものに collector / funnel / staging lane のような集約構造を持たせる必要がある。
