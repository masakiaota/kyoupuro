# 制御紙を外した側面6窓の相補符号を各群で独立に決める

## 実験前

専用制御紙をなくしても全ての群で同じ6ビットの相補極性を使う制約が残っていた。群ごとに別の側面符号を持ち、実主部26窓と側面6窓の両方でペアを選ぶ。全商品について元の64窓の光学閉包を検査し、より良い主紙と取得・修復経路が増えるか試す。

変更経路の発動を計測し、まず小標本で出発版と比較する。採用条件は、提出ファイルを使った公式100件で全件E=0・不正操作0・各ケース2秒以内、かつ同条件の出発版より平均スコアが低いこと。

## 途中保存

人工6件で対照11,085.33、候補11,032.17、差−53.17（SE99.89）。v6593比−128.00。全E0・不正0・全再生、両時間とも全件2秒以内。群別に側面符号を持つ完全な提出版を、公式全件評価を待たずに保存。

```
6 11085.333 0 0 1.834824 1.887178 0 6
6 11032.167 0 0 1.845037 1.886468 0 6
delta -53.167 se 99.886
``` [ソース](https://github.com/masakiaota/AHC074/blob/f97d5afb40be100ecbd991198a94d548dff0d5ce/src/bin/v6597_independent_side_codes.cpp)・[個票](https://github.com/masakiaota/AHC074/blob/f97d5afb40be100ecbd991198a94d548dff0d5ce/results/v6597_paired_session.csv)。

## 実験後

追加5版の公式100件は11,007.63手（同条件v6417比+55.76、SE20.26）。全E0・不正0・全再生、最大CPU1.838056秒・実時間1.904990秒で両制限を全件通過。群別側面符号の人工6表での改善は公式100件で再現せず棄却。[個票](https://github.com/masakiaota/AHC074/blob/f97d5afb40be100ecbd991198a94d548dff0d5ce/results/joint65_late_cases.csv)。
