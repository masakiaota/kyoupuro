# 記号一覧

このファイルは、AHC074「A - Layered Barcode Display」で使う記号と、実装・会話で使う代表名・型・制約の正本である。問題文は `../problem_description.txt` を参照する。

## 表記方針

- 公式記号の大文字小文字をコードでも保持する。`N`, `K`, `P`, `R`, `A`, `S`, `a`, `E`, `T` を対応づけだけのために別名へ変換しない。
- 窓・紙・商品・注文・操作の添字はすべて 0-based とする。`A[v,j]` は C++ の `A[v][j]`、`S[k,j]` は `S[k][j]` に対応する。
- 問題文にない実装用の名前は `snake_case` とする。以下の状態量の名前・型は代表案であり、保存形式や専用構造体の設計は未確定である。
- 状態量は `state[g]` のようにコードと対応させる。軽微なローカル変数は一覧への登録を省く。
- TeX は条件付き確率、総和、総積、比例関係などの構造に使い、コードフェンスの外に書く。
- 以下の C++ 型は想定型である。固定長配列など、同じ値域を表す型への変更は可能である。
- 公式は `r` を注文番号と順位の両方に使う。注文処理の `r` は整数、得点計算の `r` は半整数になり得る値として、節の文脈で区別する。

## 入力と固定サイズ

| 記号 | 意味 | コード上の代表名・想定型 | 範囲・制約 |
| --- | --- | --- | --- |
| `N` | 横一列に並ぶ窓の数、バーコードと紙の模様の長さ | `N`: `int` | `N = 64` |
| `K` | 紙の枚数 | `K`: `int` | `K = 192` |
| `P` | 商品の種類数 | `P`: `int` | `P = 256` |
| `R` | 注文数 | `R`: `int` | `R = 1024` |
| `A[v]` | 商品 `v` に対応するバーコード | `A`: `std::vector<std::string>` | 要素数 `P`。各文字列の長さは `N`。文字は `'0'` または `'1'`。各文字列に `'1'` がちょうど 32 個あり、すべて相異なる |
| `A[v,j]` | 商品 `v` のバーコードの窓 `j` に対応する文字 | `A[v][j]`: `char` | `'0'` は白、`'1'` は黒 |
| `a[r]` | 注文 `r` で要求される商品番号 | 現在の入力は `a`: `int`。履歴を保存する場合は `a`: `std::vector<int>` の `a[r]` | 正常入力は `0 <= a[r] < P`。`r >= 1` では `a[r] != a[r-1]`。注文ごとに逐次与えられる |

上記の固定値は本番の全テストケースに対する制約である。問題文の小さな例だけは `N=4, K=3, P=4, R=3` を使う。

`A` は長さ 64、黒 32 個の全二値文字列から重複なしで一様に抽出される。`a[0]` は全商品から一様に選ばれ、以降は直前の商品を除く `P-1` 種類から一様に選ばれる。

## 添字と位置

| 記号 | 意味 | コード上の代表名・想定型 | 範囲・制約 |
| --- | --- | --- | --- |
| `j` | 窓番号、文字列内の位置 | `j`: `int` | `0 <= j < N` |
| `k` | 紙の番号 | `k`: `int` | `0 <= k < K`。並べ替え後も紙自体の番号は変わらない |
| `v` | 商品番号 | `v`: `int` | `0 <= v < P` |
| `r` | 注文番号 | `r`: `int` | `0 <= r < R` |
| `i` | 現在の注文に対する操作番号 | `i`: `int` | `0 <= i < m` |
| `t` | 入出力例の表における注文番号の見出し | 実装では注文番号 `r` を使う | 例では `0, 1, 2`。初期情報・設計出力の行には番号がない |
| `depth` | 紙を重ねた位置。実装用の名前 | `depth`: `int` | `0 <= depth < K`。`0` が最上部、`K-1` が最下部 |

## 紙の設計と操作出力

| 記号 | 意味 | コード上の代表名・想定型 | 範囲・制約 |
| --- | --- | --- | --- |
| `S[k]` | 紙 `k` の模様 | `S`: `std::vector<std::string>` | 要素数 `K`、各文字列の長さは `N`。文字は `'0'`, `'1'`, `'.'`。設計出力後は変更できない |
| `S[k,j]` | 紙 `k` の窓 `j` に対応する部分 | `S[k][j]`: `char` | `'0'` は白、`'1'` は黒、`'.'` は穴。全位置が穴の紙も許される |
| `m` | 現在の注文で行う操作数 | `m`: `int` | `0 <= m <= 2K`。本番では最大 384 回 |
| `k[i]` | 操作 `i` で取り出す紙の番号 | 操作のメンバー `k`: `int`、または `k`: `std::vector<int>` | `0 <= k[i] < K`。その操作の直前に、少なくとも一つの窓から見えている紙でなければならない |
| `d[i]` | 操作 `i` で紙を挿入する位置 | 操作のメンバー `d`: `int`、または `d`: `std::vector<int>` | `0 <= d[i] < K`。取り出した後に残る紙の上から `d[i]` 枚の下へ挿入する |

単一操作の説明では `k`, `d` と書く。`d=0` は最上部、`d=K-1` は最下部への挿入を表す。移動しない紙の相対順序は保存される。操作列を保存する構造体・配列の形式は未確定である。

## 表示状態

以下は問題の状態を表すための実装用の代表名であり、公式記号ではない。

| 状態量 | 意味 | コード上の代表名・想定型 | 範囲・不変条件 |
| --- | --- | --- | --- |
| `order[depth]` | 上から `depth` 番目にある紙の番号 | `order`: `std::vector<int>` | `0, ..., K-1` の順列。初期状態は `order[depth] = depth`。注文間で引き継ぐ |
| `visible_sheet[j]` | 窓 `j` から見える紙の番号 | `visible_sheet`: `std::vector<int>` | 上から調べて最初に `S[k,j] != '.'` となる紙 `k`。該当する紙がなければ代表値として `-1` を使う |
| `display[j]` | 現在、窓 `j` に表示される色 | `display`: `std::string`、各文字は `char` | `visible_sheet[j] >= 0` なら `S[visible_sheet[j],j]`。該当する紙がなければ白の `'0'` |

紙 `k` は、いずれかの窓 `j` で `visible_sheet[j] = k` となるときに操作対象として選べる。全紙が穴である窓は白く表示されるが、その窓から見える紙は存在しない。

注文 `r` の操作列を適用し終えた時点で `display` 全体と `A[a[r]]` を比較する。不一致の窓が一つ以上あれば、その注文について誤りを 1 件数える。不一致の窓数そのものは誤り件数に加算しない。

## 得点

| 記号 | 意味 | コード上の代表名・想定型 | 範囲・制約 |
| --- | --- | --- | --- |
| `E` | 表示が要求バーコードと一致しなかった注文数 | `E`: `int` | `0 <= E <= R` |
| `T` | 全注文を通じた操作回数の合計 | `T`: `int` | `0 <= T <= 2KR`。本番では最大 393216 回 |
| `2KE + T` | 1 ケースの絶対スコア | `absolute_score`: `int64_t` | 小さいほど良い。本番での値域の上界は 786432 |
| `n_submit` | 提出した参加者数 | `n_submit`: `int64_t` | 相対評価で使う。自分を含むため `n_submit >= 1` |
| `n_lose` | 自分より絶対スコアが小さい参加者数 | `n_lose`: `int64_t` | `0 <= n_lose <= n_submit-1` |
| `n_tie` | 自分と絶対スコアが等しい、自分以外の参加者数 | `n_tie`: `int64_t` | `0 <= n_tie <= n_submit-1`、`n_lose + n_tie <= n_submit-1` |
| 得点計算の `r` | `n_lose + 0.5 n_tie` で定義されるケース内順位 | 得点計算の局所変数 `r`: `double` | 注文番号の `r` とは別の量。整数または半整数 |
| `round(10^9 × (1 - r / n_submit))` | 1 ケースの順位スコア | `rank_score`: `int64_t` | 大きいほど良い。提出全体の得点は各ケースの順位スコアの合計 |

不正出力・時間超過があったケースの順位スコアは 0 となる。

## 対話上の条件

- `A` は設計前にすべて与えられる。`a[r]` は設計出力後、現在の注文を処理するたびに一つずつ与えられる。
- 正常な商品番号とは別に、無効な設計・操作・出力形式を知らせる入力値 `-1` がある。受け取ったら直ちに終了する。
- 設計と各注文への出力には改行を付け、標準出力をフラッシュする。`m=0` のときは `0` のみを出力する。
- 最後の注文への出力後に終了する。正常終了時に追加の入力はない。途中での出力終了や対話終了後の余分な出力は無効である。
- ローカルテスタ用入力ファイルには、初期情報に続いて全注文 `a[0], ..., a[R-1]` が入る。solver に対する公式の入力は逐次である。

## 手の分類

1 手（見えている紙 `k` を取り出し、深さ `d` へ挿入する操作）を、動かした紙 `k` をどう扱うかという一つの観点で分類する。

### 分類（どの手もちょうど一つに当てはまる）

動かした直後に、紙 `k` の印字（`S[k,j] != '.'` の窓 `j`）がどれだけ見えているかで分ける。

| 名前 | 動かした直後の紙 `k` | コード上の代表名 |
| --- | --- | --- |
| 上被せ手 | 印字がすべて見える | `cover` |
| 一部見せ手 | 印字の一部が見え、残りは上の紙に隠れる | `partial_show` |
| 埋める手 | 印字がまったく見えない | `bury` |

### 属性（分類に重ねて値で持つ）

いずれも紙 `k` についての量であり、名前は付けない。集計では組み合わせて使う（例：出どころが「開始時」の埋める手）。

| 属性 | 値 | コード上の代表名・想定型 |
| --- | --- | --- |
| 出どころ | 注文の開始時に見えていた／注文の途中で見えるようになった | `visible_at_start`: `bool` |
| 行き先 | 注文の完成時に見えている／見えていない | `visible_at_end`: `bool` |
| 回数 | その注文で初めて動かした／2 回目以降 | `is_repeat`: `bool` |
| 見えている窓数 | 動かす直前と直後に、`visible_sheet[j] = k` となる窓 `j` の数 | `visible_before`, `visible_after`: `int` |

- 分類は `visible_after` で決まる。印字の窓数と等しければ上被せ手、`0` より大きく印字の窓数未満なら一部見せ手、`0` なら埋める手である。
- 「蓋をする手」は見えている窓数（直後）が多い上被せ手、「蓋解除手」は見えている窓数（直前）が多い埋める手の呼び名とする。使うときは閾値を明記する。
- 上下入れ替え（部分的に重なる 2 枚の上下を変える手）は、上被せ手または一部見せ手として数える。
- 据え置き・備える手・回り道の手は、注文全体の進め方の分類であり、この節の分類とは別の軸である。
