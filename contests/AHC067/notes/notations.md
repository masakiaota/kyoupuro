# 記号一覧

このファイルは、問題で使う記号と、実装・会話で使う代表名・型・制約の正本である。

## notation 方針

- 公式記号名は保持する。公式が `N`, `M`, `K` なら `N`, `M`, `K` と書き、Rust 風の `n`, `m`, `k` へ直さない。
- 添字は 0-based とし、`c[i,j]` のような配列アクセス風表記にする。
- 座標 `(i,j)` は `i` が行、`j` が列である。
- 問題文にない実装用の状態量は、`mask`, `door_h[i,j]` のようにコードとの対応が見える名前にする。
- TeX は数式構造だけに使い、コードフェンスには入れない。
- 解法考察や仮説は混ぜない。状態量・添字・型・不変条件だけを書く。

## 固定サイズ

### 盤面サイズ `N`

- 議論用 notation: `N`
- コード上の代表名: `N`, `n`
- Rust 型: `usize`
- index 範囲・不変条件: `N = 20`
- 備考: 盤面は `N x N` マスである。

### 扉の最大枚数 `M`

- 議論用 notation: `M`
- コード上の代表名: `M`, `m`
- Rust 型: `usize`
- index 範囲・不変条件: `M = 50`
- 備考: 出力する扉の枚数 `D` は `0 <= D <= M` を満たす。

### スイッチ種類数 `K`

- 議論用 notation: `K`
- コード上の代表名: `K`, `kinds`
- Rust 型: `usize`
- index 範囲・不変条件: `K = 10`
- 備考: スイッチ種類は `0 <= k < K`、扉の型は `0 <= g < 2K` である。

## 入力

### 盤面 `c[i,j]`

- 議論用 notation: `c[i,j]`
- コード上の代表名: `c`, `grid`
- Rust 型: `Vec<Vec<u8>>`, `Vec<Vec<char>>`, `[[u8; N]; N]`
- index 範囲・不変条件: `0 <= i < N`, `0 <= j < N`
- 値: 空きマス `.` または障害物 `#`
- 備考: `c[0,0] = c[N-1,N-1] = .` であり、すべての空きマスは空きマスのみを通って入口から到達可能である。

### 入口 `start`

- 議論用 notation: `(0,0)`
- コード上の代表名: `start`, `START`
- Rust 型: `(usize, usize)` または `Point`
- index 範囲・不変条件: 常に空きマス
- 備考: 勇者の初期位置である。

### 玉座 `goal`

- 議論用 notation: `(N-1,N-1)`
- コード上の代表名: `goal`, `GOAL`
- Rust 型: `(usize, usize)` または `Point`
- index 範囲・不変条件: 常に空きマス
- 備考: 到達対象である。

## 出力: 扉

### 扉枚数 `D`

- 議論用 notation: `D`
- コード上の代表名: `D`, `doors.len()`
- Rust 型: `usize`
- index 範囲・不変条件: `0 <= D <= M`
- 備考: 出力する扉の総数である。

### 扉出力 `door[a] = (d_a, i_a, j_a, g_a)`

- 議論用 notation: `door[a]`
- コード上の代表名: `doors`, `Door { d, i, j, g }`
- Rust 型: `Vec<Door>`
- index 範囲・不変条件: `0 <= a < D`
- `d_a = 0`: `(i_a,j_a)` と `(i_a+1,j_a)` の間に扉 `g_a` を設置する。`0 <= i_a < N-1`, `0 <= j_a < N`
- `d_a = 1`: `(i_a,j_a)` と `(i_a,j_a+1)` の間に扉 `g_a` を設置する。`0 <= i_a < N`, `0 <= j_a < N-1`
- 型制約: `0 <= g_a < 2K`
- 不変条件: 同じ 2 マスの間に複数の扉を設置してはならない。
- 備考: 障害物マスとの間に扉を設置してもよいが、その扉を通る移動はできない。

### 上下方向の扉 `door_h[i,j]`

- 議論用 notation: `door_h[i,j]`
- コード上の代表名: `door_h`
- Rust 型: `Vec<Vec<i32>>`, `[[i32; N]; N-1]`, `Vec<Vec<Option<usize>>>`
- index 範囲・不変条件: `0 <= i < N-1`, `0 <= j < N`
- 値: `(i,j)` と `(i+1,j)` の間の扉の型 `g`。扉なしは `-1` または `None`
- 備考: 公式の `d_a = 0` に対応する。

### 左右方向の扉 `door_v[i,j]`

- 議論用 notation: `door_v[i,j]`
- コード上の代表名: `door_v`
- Rust 型: `Vec<Vec<i32>>`, `[[i32; N-1]; N]`, `Vec<Vec<Option<usize>>>`
- index 範囲・不変条件: `0 <= i < N`, `0 <= j < N-1`
- 値: `(i,j)` と `(i,j+1)` の間の扉の型 `g`。扉なしは `-1` または `None`
- 備考: 公式の `d_a = 1` に対応する。

### 扉の型 `g`

- 議論用 notation: `g`
- コード上の代表名: `g`, `door_type`
- Rust 型: `usize`
- index 範囲・不変条件: `0 <= g < 2K`
- 備考: 型 `2k` と型 `2k+1` はスイッチ `k` によって制御され、同じ型の扉は開閉状態を共有する。

## 出力: スイッチ

### スイッチ個数 `S`

- 議論用 notation: `S`
- コード上の代表名: `S`, `switches.len()`
- Rust 型: `usize`
- index 範囲・不変条件: `0 <= S <= N^2`
- 備考: 出力するスイッチの総数である。

### スイッチ出力 `switch_out[b] = (p_b, q_b, s_b)`

- 議論用 notation: `switch_out[b]`
- コード上の代表名: `switches`, `Switch { p, q, s }`
- Rust 型: `Vec<Switch>`
- index 範囲・不変条件: `0 <= b < S`
- 座標制約: `0 <= p_b, q_b < N`
- 種類制約: `0 <= s_b < K`
- 不変条件: 同じマスに複数のスイッチを設置してはならない。
- 備考: 障害物マスにスイッチを設置してもよいが、そのスイッチは押せない。

### スイッチ配置 `switch[i,j]`

- 議論用 notation: `switch[i,j]`
- コード上の代表名: `switch`, `switch_grid`
- Rust 型: `Vec<Vec<i32>>`, `[[i32; N]; N]`, `Vec<Vec<Option<usize>>>`
- index 範囲・不変条件: `0 <= i < N`, `0 <= j < N`
- 値: マス `(i,j)` に置かれたスイッチの種類 `s`。スイッチなしは `-1` または `None`
- 備考: 入口 `(0,0)` や玉座 `(N-1,N-1)` にもスイッチを設置してよい。

### スイッチ種類 `k`, `s`

- 議論用 notation: `k`, `s`
- コード上の代表名: `k`, `s`, `switch_type`
- Rust 型: `usize`
- index 範囲・不変条件: `0 <= k < K`, `0 <= s < K`
- 備考: スイッチ `k` は扉 `2k` と扉 `2k+1` の開閉を入れ替える。

## 状態量

### スイッチ状態 `mask`

- 議論用 notation: `mask`
- コード上の代表名: `mask`
- Rust 型: `usize`
- index 範囲・不変条件: `0 <= mask < 2^K`
- 意味: bit `k` が、スイッチ `k` が押された回数の偶奇を表す。`0` は偶数回、`1` は奇数回である。
- 備考: 初期状態は `mask = 0` である。

### 扉開閉判定 `is_open(g, mask)`

- 議論用 notation: `is_open(g, mask)`
- コード上の代表名: `is_open`
- Rust 型: `fn(usize, usize) -> bool`。扉なしを扱う場合は `Option<usize>` または sentinel `-1` を使う。
- 不変条件: 扉型 `g` は、`((mask >> (g / 2)) & 1) == (g & 1)` のとき開いている。
- 備考: 初期状態では偶数型 `2k` が開き、奇数型 `2k+1` が閉じている。

### BFS 状態 `(mask,i,j)`

- 議論用 notation: `(mask,i,j)`
- コード上の代表名: `State { mask, i, j }`, `(mask, i, j)`
- Rust 型: `(usize, usize, usize)` または専用 `struct`
- index 範囲・不変条件: `0 <= mask < 2^K`, `0 <= i,j < N`, `c[i,j] = .`
- 備考: 勇者の現在位置と、各スイッチが押された回数の偶奇を合わせた状態である。

### 最短距離 `dist[mask][i][j]`

- 議論用 notation: `dist[mask][i][j]`
- コード上の代表名: `dist`
- Rust 型: `Vec<Vec<Vec<i32>>>`, `Vec<[i32; N*N]>`, `Vec<i32>`
- index 範囲・不変条件: `0 <= mask < 2^K`, `0 <= i,j < N`
- 値: 初期状態 `(0,0,0)` から状態 `(mask,i,j)` へ到達する最小行動回数。未到達は `-1` などで表す。

### 最小行動回数 `T`

- 議論用 notation: `T`
- コード上の代表名: `T`, `best_dist`
- Rust 型: `i64`, `usize`
- index 範囲・不変条件: 到達可能なら正の整数、到達不能なら scorer の計算例では `0`
- 備考: 勇者は `T` を最小化するように行動する。こちらの目的は `T` を最大化することである。

## 行動

### 移動方向 `DIRS`

- 議論用 notation: `(di,dj)`
- コード上の代表名: `DIRS`, `DIRECTIONS`
- Rust 型: `[(isize, isize); 4]`
- 値: `(-1,0)`, `(1,0)`, `(0,-1)`, `(0,1)`
- 備考: 移動先が空きマスで、間の扉が存在しないか開いている場合に移動できる。

### スイッチ押下

- 議論用 notation: `mask ^ (1 << s)`
- コード上の代表名: `nmask`, `next_mask`
- Rust 型: `usize`
- index 範囲・不変条件: 現在位置 `(i,j)` に種類 `s` のスイッチがある場合のみ可能
- 備考: スイッチを押す行動 1 回として数える。スイッチがあるマスでも、押さずに移動してよい。

## スコア

### 得点 `score`

- 議論用 notation: `score`
- コード上の代表名: `score`
- Rust 型: `i64`
- 不変条件: 到達可能な場合は `round(10^6 * log_2(T / N))`。到達不能な場合は 1 点。
- 備考: 全 150 ケースの得点合計が提出の得点である。

## 入力生成

### 生成順序

- 議論用 notation: `order`
- コード上の代表名: `order`, `cells`
- Rust 型: `Vec<(usize, usize)>`
- index 範囲・不変条件: `(0,0)` と `(N-1,N-1)` 以外のマスをランダム順に処理する。
- 備考: まず全マス空きから障害物を作り、その後、障害物を最大 `N` 回だけ空きマスへ戻す。
