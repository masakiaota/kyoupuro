# v501_pro_shadow_packing の部品分析

## 評価で確認できた事実

v501 の平均絶対スコアは 62,136,847 だった。
これは v002 の 51,987,123 を 19.524% 上回る。
ケース別でも v501 は v002 を 100 ケースすべてで上回り、平均差は 10,149,724 だった。

v501 は 100,000 到着のうち 63,940 組を受け入れた。
v002 の受け入れは 52,981 組だったため、統合手法は受け入れ数も 10,959 組増やしている。

ただし、両 solver は価格判定と配置可能性の定義が異なる。
したがって、幾何棄却が v002 の 22,567 件から v501 の 16,982 件へ減ったという差だけを、特定の配置部品の効果とはみなせない。

## 動的シャドー価格

v501 のシャドー価格は、生成分布から求めた平均負荷だけでは決まらない。
次の補正を組み合わせている。

- 時間軸の端では滞在区間が重なる確率が下がるため、到着時刻に応じて提示負荷を補正する。
- 滞在区間内の 3 点で局所価格を計算し、その加重平均をグループの基準価格にする。
- 現在占有セル数が目標占有量を上回ると価格を上げ、下回ると価格を下げる。
- 池の量と芝生成分数から、実効容量を利用可能芝生の 80% から 89% に設定する。
- 小さな空き成分では将来収容できる人数が限られるため、成分サイズに応じて価格を下げる。

時間端補正と小成分の価格低下には、使えないセル時間の機会費用を低くするという説明がつく。
一方、実効容量率と占有誤差の係数は経験的な値であり、問題から導かれた定数としては扱わない。

## 柔軟な形状と断片化評価

v501 は最小周長形状だけを探すわけではない。
通常探索では `L_min` から `L_min+6` までを調べ、規則形状が見つからないときは空き連結成分内で領域を成長させる。
利用料の低下を受け入れてでも合法配置を得るため、最小周長形状しか許可しない v002 とは目的が異なる。

候補選択では、配置後の空き領域について次を罰している。

- 次数 1 以下の空きセル
- 4 マス未満の空き成分
- 150 マス未満で、将来の人数分布を収容しにくい空き成分

`fragment_evaluated` は 100 ケースで 960,714 回発動した。
この値は断片化評価が探索へ実際に入ったことを示すが、スコアへの寄与量は示さない。
断片化ペナルティの係数も経験的なので、アブレーションせずに v002 へ移植する根拠にはならない。

`growth_placement_success` は 33,003 回だった。
このカウンタには通常配置だけでなく局所再配置の beam search 中に得た候補も含まれるため、33,003 組が成長形状で受理されたという意味ではない。

## 退去時刻の非対称評価

v002 は隣接グループとの退去時刻差を絶対値で扱う。
v501 は、隣接グループが到着グループより先に退去する場合と後に退去する場合で重みを変える。

この非対称性には、空き領域が生じる順序を配置へ反映するという意味がある。
ただし、v501 では断片化評価と同時に使われているため、対称評価との差は単独では測れていない。

## 局所再配置

局所再配置は 17,618 回試行され、996 回成功した。
成功率は 5.653% で、1 成功当たりの移動グループ数は平均 1.514 組、移動費は平均 7,480 だった。
ログ上の採算余剰は 1 成功当たり平均 62,054 だった。

ログ上の採算余剰総額 61,805,378 は、v501 と v002 の総スコア差 1,014,972,361 の 6.089% に当たる。
両者は同じ量ではなく、再配置後の将来効果もあるため、この比率を寄与率とはみなさない。
それでも、成功回数と金額規模から、v501 の改善を局所再配置だけで説明することは難しい。

## 切り出す順序

最初に、v002 の admission と退去時刻評価を固定したまま、周長に余裕を持たせる配置だけを追加する。
これにより、柔軟な形状が幾何棄却とスコアへ与える効果を測れる。

次に、断片化評価、動的シャドー価格、退去時刻の非対称化をそれぞれ単独で比較する。
局所再配置は成功頻度が低く実装間の相互作用も大きいため、これらの後に評価する。
