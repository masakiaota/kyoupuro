# 記号一覧

このファイルは、問題で使う記号と、実装・会話で使う代表名・型・制約の正本である。添字は問題文・実装ともに 0-based とする。

## 基本パラメータ

### 公園サイズ `N`

- 議論用 notation: `N`
- コード上の代表名: `N`
- Rust 型: `usize`
- 値・不変条件: `N = 50`。座標 `(x, y)` は `0 <= x, y < N`。

### グループ数 `M`

- 議論用 notation: `M`
- コード上の代表名: `M`
- Rust 型: `usize`
- 値・不変条件: `M = 1000`。グループ番号は `0 <= i < M`。

### 移動コスト係数 `R`

- 議論用 notation: `R`
- コード上の代表名: `R`
- Rust 型: `f64`。丸めを厳密に扱う実装では補助的に `R_milli: i64` として千分率を保持してよい。
- 値・不変条件: `0.001 <= R <= 0.1`、小数点以下 3 桁まで。

### 滞在時間分布パラメータ `θ`

- 議論用 notation: $\theta$。グループ `i` までの到着順 prefix から求めたオンライン推定値を区別するときは $\hat{\theta}[i]$。
- コード上の代表名: `theta`。真値と推定値を同時に扱う場合は `theta_true`, `theta_estimate`。
- Rust 型: 通常は `f64`。入力生成器や分析コードで真値を整数として保持する場合は `usize`。
- 値・不変条件: 真値はケースごとに一つだけ `2000..=8000` から一様に選ばれ、全グループで共通する。solver には直接与えられない。`l[i] = D[i] - 1` は、率 `1 / θ` の指数分布から得た値を丸めて生成される。
- 推定上の注意: $\hat{\theta}[i]$ は到着済みグループ `0..=i` だけから求める。到着順 prefix の偏りと未到着グループの打ち切り情報は `notes/input_distribution.md` の「オンライン観測の偏り」に従う。

## 公園

### マス `(x, y)` と形状 `row[x][y]`

- 議論用 notation: `(x, y)`, `row[x][y]`
- コード上の代表名: `pos: (usize, usize)`, `row`, `is_grass`
- Rust 型: 座標は `(usize, usize)`、形状は `Vec<Vec<u8>>` または等価な表現。
- index 範囲・不変条件: `x`, `y` は `0 <= x, y < N`。`row[x][y] = '.'` は芝生、`'#'` は池。隣接は上下左右の 4 近傍のみ。

### 領域 `region[g]`

- 議論用 notation: `region[g]`
- コード上の代表名: `region`, `regions`
- Rust 型: `Vec<Vec<(usize, usize)>>`、または occupancy と併用する等価な表現。
- index 範囲・不変条件: 許可されたグループ `g` についてちょうど `P[g]` 個の芝生マスからなり、上下左右に連結する。同時に利用中の異なるグループの領域は互いに素。

## グループ入力

### 到着・退去時刻 `S[i]`, `T[i]`

- 議論用 notation: `S[i]`, `T[i]`
- コード上の代表名: `S`, `T`
- Rust 型: `i64` または `usize`
- index 範囲・不変条件: `0 <= S[i] < T[i] <= 100000`。`S[i] < S[i+1]`。全ての `S[i]` と `T[i]` は互いに異なる。

### 滞在時間 `D[i]`

- 議論用 notation: $D[i] = T[i] - S[i]$
- コード上の代表名: `D`, `duration`
- Rust 型: `i64` または `usize`
- 値・不変条件: $1 \le D[i] \le 100000$。グループ $i$ が $P[i]$ マスを占有する時間の長さ。

### 人数 `P[i]`

- 議論用 notation: `P[i]`
- コード上の代表名: `P`
- Rust 型: `usize`
- 値・不変条件: `4 <= P[i] <= 150`。割り当て・移動後の領域のマス数と常に一致する。

### 基本支払額 `V[i]`

- 議論用 notation: `V[i]`
- コード上の代表名: `V`
- Rust 型: `i64`
- 値・不変条件: `1 <= V[i] <= 10^8`。

### 価値補正倍率 `Q[i]`

- 議論用 notation: $Q[i] = V[i] / (P[i]D[i]^{0.9})$
- コード上の代表名: `value_multiplier`
- Rust 型: `f64`
- 値・不変条件: 人数と滞在時間による基準値 $P[i]D[i]^{0.9}$ に対して、$V[i]$ が何倍であるかを表す無次元の倍率。入力された $V[i]$, $P[i]$, $D[i]$ から計算する派生量であり、所持金へ直接加算される金額ではない。入力生成時の丸めと上限制限の影響を除けば、$Q[i] \simeq 2^{gauss(0,0.8)}$ である。

### 基本支払額のセル時間密度 `rho[i]`

- 議論用 notation: $\rho[i] = V[i] / (P[i]D[i])$
- コード上の代表名: `value_per_cell_time`
- Rust 型: `f64`。比較だけなら分子 $V[i]$ と分母 $P[i]D[i]$ の組を保持し、交差積で厳密に比較してよい。
- 値・不変条件: $P[i]D[i]$ セル時間を消費して得る基本支払額の、1 セル時間あたりの値。コンパクト度と移動コストを含まず、実際に所持金へ加算される金額ではない。

### 実効セル時間密度 `eta[i]`

- 議論用 notation: $\eta[i] = C[i]\rho[i] = V[i]C[i] / (P[i]D[i])$
- コード上の代表名: `effective_value_per_cell_time`
- Rust 型: `f64`
- 値・不変条件: グループ $i$ の全滞在履歴における最低コンパクト度 $C[i]$ を反映した、四捨五入前の利用料の 1 セル時間あたりの値。厳密な利用料に基づく値は $round(V[i]C[i]) / (P[i]D[i])$ である。最終的な $C[i]$ が確定するまでは $\eta[i]$ も確定せず、移動コストは含まない。

## 利用状態と移動

### 利用状態 `state[g]`

- 議論用 notation: `state[g]`
- コード上の代表名: `state`, `active`
- Rust 型: `Vec<GroupState>` または `Vec<Option<GroupState>>`
- index 範囲・不変条件: `g` は `0 <= g < M`。利用を許可されたグループは到着後から `T[g]` まで利用中であり、退去時に領域が解放される。

### 移動数 `A[i]` と移動先 `(z[k], w[k])`

- 議論用 notation: `A[i]`, `(z[k], w[k])`
- コード上の代表名: `A`, `move_dest`
- Rust 型: `usize`, `Vec<(usize, usize)>`
- index 範囲・不変条件: グループ i の到着直前に、`0 <= A[i] <=` 現在利用中のグループ数。1 回の移動で同じグループを複数回指定しない。指定された全グループは一度に旧領域を空けてから新領域へ移るため、相互の位置交換が可能である。

### 新規割当座標 `(x[k], y[k])`

- 議論用 notation: `(x[k], y[k])`
- コード上の代表名: `assign_cells`
- Rust 型: `Vec<(usize, usize)>`
- index 範囲・不変条件: 長さは `P[i]`。新規に許可するグループ i の `region[i]` を表し、芝生・連結・他の利用中領域との非重複を満たす。

### 移動コスト `move_cost[g]`

- 議論用 notation: `max(round(V[g] × R), 1)`
- コード上の代表名: `move_cost`
- Rust 型: `i64`
- 値・不変条件: グループ g を 1 回移動させるごとに所持金から減算する。

## コンパクト度とスコア

### 境界長 `L` とコンパクト度 `C`

- 議論用 notation: `L(region)`, `C(region) = 4 × sqrt(P) / L`
- コード上の代表名: `perimeter`, `compactness`
- Rust 型: `L` は `i64` または `usize`、`C` は比較・支払計算に応じて `f64` または厳密な有理数表現。
- 値・不変条件: L は領域外または公園外との辺の総数。`0 < C <= 1`。P はその領域のマス数。

### グループの最小コンパクト度 `C[i]`

- 議論用 notation: `C[i]`
- コード上の代表名: `min_compactness`
- Rust 型: `f64` または `L` を用いた比較可能な厳密表現。
- index 範囲・不変条件: 初回配置時と全ての移動後のコンパクト度の最小値。退去時の利用料は `round(V[i] × C[i])`。

### 所持金 `X`、絶対スコア `abs_score`

- 議論用 notation: `X`, `max(X, 0)`
- コード上の代表名: `X`, `abs_score`
- Rust 型: `i64`
- 値・不変条件: X は初期値 0。退去時の利用料を加算し、移動コストを減算するため負になりうる。最終絶対スコアは `max(X, 0)`。

### 四捨五入 `round(x)`

- 議論用 notation: `round(x)`
- コード上の代表名: `round`
- Rust 型: 入力に応じて整数または浮動小数点数、結果は `i64`
- 値・不変条件: `x + 0.5` 以下の最大の整数。問題文で用いる引数は非負である。

### 相対評価スコア

- 議論用 notation: `round(10^9 × own_abs_score / max_abs_score)`
- コード上の代表名: `relative_score`
- Rust 型: 集計側の整数値。solver 内では直接計算しない。
- 値・不変条件: テストケースごとの絶対スコアを全参加者中の最大絶対スコアで正規化する。提出得点は全ケースの和。
