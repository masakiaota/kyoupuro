## 解法の全体像

操作 `X` を使わず、拾う順番だけを焼きなましする。状態は `(番号, 0/1)` の長さ400の列 `p` であり、同じ番号の2要素が正しい入れ子関係を保つようにする。

初期解は番号順に、まだ入っていないペアを隣接2要素として最良位置へ挿入して作る。その後は、ランダムに選んだ番号 `n` の2要素を列から抜き、別の合法な位置に入れ直す遷移を繰り返す。遷移は連結リストと補助bool配列により、平均 `O(1)` で差分評価できるようにしたと説明されている。

## 主要アイデア

- `X` を捨て、状態を正しい括弧列に対応する `(n, side)` 列に限定する。
- 遷移は「1ペアを抜いて挿し直す」に絞る。
- 隣接挿入だけでなく、既存の完結した部分列を包む挿入を確率的に生成する。
- `(n,0),(n,1)` のどちらを先に置くかは、差分スコアが良い向きを選ぶ。
- 連結リストでノード前後を持ち、挿入・削除時に影響する接続辺だけで差分計算する。
- 区間reverseやvalid区間移動は、遷移コストが重く最終的には不採用。

### 状態表現

- `p`: `(n, 0/1)` の順列。各 `n` は2回現れる。
- 各要素を連結リストのノードとして持つ。
- 各 `n` について、2つのノードへの参照を持つ。
- 各 `n` について、`(n,0)` と `(n,1)` のどちらが前にあるかをboolで持つ。
- 現在スコアを保持し、更新時は差分だけ足し引きする。

記事は添字で説明しているが、実装では「どの組の前後に挿入するか」を決めて連結リストを更新した、と述べている。

### 観測・制約・入力の扱い

- 入力から各番号の2座標を持つ。
- `(n,0)` と `(n,1)` はその2座標のどちらを先に訪れるかを表す。
- 操作 `X` は使わないため、列が実行可能である条件は「同じ番号の2回目が現れるとき、その番号が現在の山札トップにある」ことである。
- 遷移はこの制約を壊さない挿入位置だけを生成する。

### 評価関数

評価関数はスコアと同じ、すなわち全カードを消す前提での移動回数最小化である。

```text
cost(p):
    prev = (0, 0)
    total = 0
    for (n, side) in p:
        q = position[n][side]
        total += manhattan(prev, q)
        prev = q
    return total
```

焼きなましでは `cost` の差分を使って採択判定する。記事には温度式や時間配分の詳細はない。

### 探索・構築・更新

初期解:

- 空列から始める。
- `i=0..199` の順に、`(i,a),(i,b)` を隣接して挿入する。
- 挿入位置と向きのうちコスト最小のものを選ぶ。
- 計算量は `O(N^4)` と説明されており、全体では十分速い。

焼きなまし遷移:

1つの番号 `n` をランダムに選び、列から `(n,0),(n,1)` を抜く。その後、次のいずれかで挿入する。

- 遷移1: ランダムな位置に `(n,a),(n,b)` を隣接挿入する。
- 遷移2: 既存ペア `x` の開き側の前と閉じ側の後を選び、その範囲を包むように `(n,a)` と `(n,b)` を挿入する。

さらに遷移2では、1つの完結部分列だけでなく、複数の完結部分列をまとめて包めるようにする。境界 `i` の直前が別ペアの閉じ側であり、その対応する開き側 `k` が存在する場合、確率 `P=50%` で `i` を `k` にジャンプする。右境界 `j` でも同様の操作を行う。これにより、隣接した複数の完結区間を1つの新ペアで囲む遷移が発生する。

### 操作・クエリ・出力選択

- 最終列 `p` に従ってカード位置へ移動し、各位置で `Z` を出す。
- `X` は出力しない。
- 2要素の向き `(a,b)` は、挿入候補ごとに `(0,1)` と `(1,0)` を比べて良い方を選ぶ。

### 時間配分・パラメータ

- 遷移1と遷移2の比率は `4:6`。
- 遷移2で境界を外側へ広げ続ける確率 `P` は50%。
- 温度、反復回数、乱数種は記事からは読み取れない。
- 連結リストとbool配列により、遷移とスコア計算を `O(1)`、遷移2は平均 `O(1)` にしたと説明されている。

## 実装上重要な断片

連結リストで1ペアを抜き挿しする差分更新が重要である。

```text
try_move(n):
    old_edges = edges around the two nodes of n
    unlink two nodes

    choose insertion boundaries
    choose better orientation of n
    new_edges = edges created by insertion
    delta = new_edges - old_edges

    if accept(delta):
        link nodes at new boundaries
        score += delta
    else:
        restore old links
```

遷移2の境界拡張は、完結区間を外側へ確率的にたどる処理である。

```text
expand_left(i):
    while previous element closes some pair y:
        k = matching opening index of y
        with probability P:
            i = k
        else:
            break
    return i
```

## この解法の本質

焼きなましの遷移を「正しい括弧列上の1ペア再挿入」に絞り、かつ連結リストで極端に軽くした点が本質である。探索空間全体を見ると入れ子構造の変化は大きいが、各試行は1ペアの削除と挿入だけなので、時間内に大量の近傍を試せる。

## 真似するならまず実装する部分

まず配列状態で、1ペアを抜いて隣接挿入する山登りを作る。その後、正しい括弧列を保つ「既存ペアを包む挿入」を足す。スコアが見えてから連結リスト化し、差分計算を入れるのがよい。最初から平均 `O(1)` 実装にすると、正しさの確認が難しい。
