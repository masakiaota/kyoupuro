## 解法の全体像

この解法は、幅4程度の帯を単位にしたDPで強い初期解を作り、その後に焼きなましで局所改善する方針である。発想の出発点は、単純な蛇行を「行き」と「帰り」に分けることだった。2行幅であれば、各列の上下2セルから小さい方を行き、大きい方を帰りへ回せる。これを4行幅へ拡張し、DPで各帯の通り方を最適化する。

最終的には、盤面の回転・反転8パターンを試して良い初期解を選び、1点Swapと2-optを中心とした焼きなましを適用している。

## 主要アイデア

- 単純な蛇行を、前半に小さい値、後半に大きい値が来る往復型へ変形する。
- 2行幅では、各列で上下の小さい側を先に、大きい側を後にするだけで大きく改善する。
- 4行幅では局所的な選択自由度が増えるため、DPで接続可能な経路を選ぶ。
- 同じ構築でも盤面の向きで結果が変わるので、回転・反転8パターンを全て試す。
- 初期解後は、訪問順の局所入れ替えや2-optでさらに相関を上げる。

## 最終コードの構造

以下は記事本文とキャッシュ実装 `#74068987` から確認した構造である。

### 状態表現

- 初期解は、盤面を幅4の帯に分けた経路として持つ。
- 経路は「前半側」と「後半側」の2系統、またはそれに準じる複数の局所経路として扱っていると考えられる。
- DP状態は、帯の境界で次に接続できる端点配置を表すものだと読める。
- 焼きなまし用には、訪問順配列と、各セルの現在位置を持つのが自然である。

### 観測・制約・入力の扱い

- 入力値はランダムな permutation なので、近傍セルの空間的な偏りよりも局所ペア・局所ブロック内の大小関係が重要になる。
- 8近傍移動が許されるため、2行幅や4行幅の折り返しを比較的柔軟に接続できる。
- 回転・反転を試すことで、端や折り返しに置かれるセルの偏りを軽減している。

### 評価関数

- 基本評価は元スコア `sum k*A[path[k]]` である。
- 初期解DPでは、低人口を前半側、高人口を後半側に送るような局所評価を使っていると考えられる。
- 焼きなましでは、Swapや2-optのスコア差分を見て採択する。

### 探索・構築・更新

- 2行幅の考え方:
  - 各列で2セルを比較し、小さい側を行き、大きい側を帰りへ割り当てる。
  - 折り返しは8近傍の斜め移動を利用して接続する。
- 4行幅DP:
  - 幅4の帯内で、どのセルを前半側・後半側に置くかをDPで決める。
  - 接続可能な端点状態だけを遷移として許す。
- 回転・反転:
  - 8通りの座標変換に対して同じ構築を行い、元座標へ戻してスコア最大を採用する。
- 焼きなまし:
  - 1点Swapで訪問順の2点を入れ替える。
  - 2-optで区間反転または経路のつなぎ替えに相当する近傍を試す。
  - 記事では、これらを初期解の上に重ねて本番9位まで伸ばしたと説明されている。

### 操作・クエリ・出力選択

- 最終的には、全セルの訪問順を1本のパスとして出力する。
- 初期解の8パターン比較で最良の向きを選び、それを焼きなましで改善したものを出力する。

### 時間配分・パラメータ

- 盤面変換8通りを試し、初期スコア上位2通りだけに焼きなましを適用する。
- DP構築は5レーン、40バンド、`TOTAL_STEPS=7639`、状態は5!通りのレーン順列。
- 焼きなまし時間の95%をSA、5%を山登りに割る。
- SA温度は `2e6 -> 10`。
- swap比率は進行に応じて20%から80%へ増やし、残りを2-opt/shiftに使う。

## 実装上重要な断片

キャッシュ実装の初期構築は4行幅ではなく5レーンDPである。各行に5本のスレッドを通し、隣接行への遷移では各レーンの列変化を高々1に制限する。重みは `s,15999-s,16000+s,31999-s,32000+s` の5系列で、`s` を5から8000へ動かすことで前半/後半に置きたい値を制御する。39回のUターンは固定形状で接続し、最終的に5本を `P0, reverse(P1), P2, reverse(P3), P4` と縫い合わせる。

局所探索では、パス配列と各セル位置を持ち、swap、2-opt、shiftを差分評価する。swapは座標±3程度の近傍セルと交換し、境界隣接だけ確認する。2-optは前後境界が8近傍でつながる区間反転、shiftは1点を抜いて近い位置へ挿入する近傍である。

```text
build_initial_solution:
    best = none
    for transform in 8 coordinate transforms:
        transformed_A = apply(transform, A)
        path = width4_dp(transformed_A)
        path = inverse_transform(path)
        if score(path) is best:
            best = path
    return best
```

```text
anneal(path):
    while time remains:
        choose move from {one_point_swap, two_opt}
        if move keeps adjacency and uniqueness:
            delta = score_after - score_before
            accept by annealing rule
```

## この解法の本質

強い初期解を作ってから局所探索する、という役割分担が本質である。焼きなましだけでランダムなハミルトン路を良くするのは難しいが、幅4DPで「低人口を前へ、高人口を後ろへ」という大局構造を作っておくと、局所探索はそのズレを直す仕事に集中できる。

また、回転・反転8パターンは実装量の割に効きやすい。構造化パスは端や折り返しの扱いに癖が出るため、座標変換を試すだけで、同じロジックのまま複数のバイアスを比較できる。

## 真似するならまず実装する部分

まずは2行幅の往復型を実装し、前半に小さいセル、後半に大きいセルを置く効果を確認するのがよい。次に4行幅のDPへ拡張する。

焼きなましは後回しでよい。初期解が弱い段階で1点Swapや2-optを入れても改善幅が小さいため、先に幅4DPまたはそれに近い構築を安定させるべきである。
