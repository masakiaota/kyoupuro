# A - Alien's Genome Assembly

実行時間制限: 3 sec / メモリ制限: 1024 MiB

## ストーリー

人間の遺伝情報は二重らせん構造のDNAに記録されており、`A`, `G`, `C`, `T` の4種類の文字からなる非常に長い文字列で表現される。最近、隕石の中から宇宙人の細胞が見つかった。調査の結果、この宇宙人の遺伝情報はトーラス状の物質に記録されており、`A`, `B`, `C`, `D`, `E`, `F`, `G`, `H` の8種類の文字からなる `N × N` の行列として表現されることが分かった。既存の装置では、この行列を直接読み取ることは出来なかったが、縦方向、もしくは横方向に連続する一次元の部分列を沢山読み取ることに成功した。この部分列の情報を元に行列を推定してほしい。

## 問題文

一次元の列 `b = (b_0, ..., b_{k-1})` が行列 `a = (a_{i,j})_{0 <= i,j <= N-1}` の部分列であるとは、ある `(i, j)` が存在し、以下のどちらか一つ以上を満たすことと定義する。

- 全ての `p = 0, ..., k - 1` で `b_p = a_{i,(j+p) mod N}` （横方向に一致）

- 全ての `p = 0, ..., k - 1` で `b_p = a_{(i+p) mod N,j}` （縦方向に一致）

インデックスが `N` 以上となった場合に `N` で割った余りを取っていることに注意（つまり、`a` は左端と右端、上端と下端がつながっている）。

`A`, `B`, `...`, `H` からなる `M` 個の文字列 `s_1, ..., s_M` が与えられるので、これらのうち出来るだけ多くを部分列として含むような `A`, `B`, `...`, `H` もしくは `.` からなる `N × N` の行列を求めよ。`.` は空白を意味する。

## 得点

`s_i` が出力の部分列であるような `i` の個数を `c` (`c <= M`)、出力に含まれる `.` の個数を `d` (`d <= N^2`) としたとき、以下の得点が得られる。

- `c < M` の場合、`round(10^8 × c / M)`

- `c = M` の場合、`round(10^8 × 2N^2 / (2N^2 - d))`

不正な出力（`N × N` 行列でない、`A`, `B`, `...`, `H`, `.` 以外の文字を含む）がされた場合、`WA` と判定される。

## 入力

入力は以下の形式で標準入力から与えられる。

```text
N M
s_1
:
s_M
```

- `N` は全テストケースを通して20で固定

- `M` は400以上800以下の整数値

- 各 `s_i` は `A`, `B`, `...`, `H` の8種類の文字からなる長さ2以上12以下の文字列

## 出力

`A`, `B`, `...`, `H`, `.` からなる長さ `N` の文字列を `N` 行出力せよ。

## 入力生成方法

`L` 以上 `U` 以下の整数値を一様ランダムに生成する関数を `rand(L, U)` で表す。

まずはじめに、`N × N` の行列 `a = (a_{i,j})_{0 <= i,j <= N-1}` を、各要素毎に独立に一様ランダムに `A`, `B`, `...`, `H` から選択することで生成する。次に、平均長を決めるパラメータ `L = rand(4, 10)` と文字列の個数 `M = rand(400, 800)` を生成し、以下の処理を独立に `M` 回繰り返すことで `M` 個の文字列 `s_1, ..., s_M` を生成する。

文字列の始点を表す2つの整数 `i = rand(0, N-1)` と `j = rand(0, N-1)`、向きを表す整数 `d = rand(0, 1)`、長さを表す整数 `k = rand(L-2, L+2)` を生成する。

- `d = 0` の場合、横方向の部分列 `(a_{i,j}, a_{i,(j+1) mod N}, ..., a_{i,(j+k-1) mod N})` を採用する。

- `d = 1` の場合、縦方向の部分列 `(a_{i,j}, a_{(i+1) mod N,j}, ..., a_{(i+k-1) mod N,j})` を採用する。
