## 問題の本質

この問題は、盤面上の餌を単に回収する問題ではなく、蛇の頭側からの色列を目標列に揃える順序制御問題である。餌を食べると色は尾側に追加されるため、基本的には目標列の次色を順番に食べたい。しかし、蛇の体が障害物になり、非目標餌や胴体衝突を完全に避け続けるのは難しい。

重要なのは、噛みちぎりが失敗処理ではなく、体長・向き・餌配置・色ずれを再調整する操作である点である。上位解法は、次色への経路探索と噛みちぎり後の復元を組み合わせ、一致接頭長を伸ばす探索として扱っている。

## 実装キャッシュ反映

Ang107kは該当ACキャッシュがなく、記事ベースのままにした。mya3 `#74942882` と kaede2020 `#74943069` は読めており、mya3はEditorialに近いbeam定数と状態表現を確認した。kaede2020は記事の試行錯誤からさらに、`Yosasou` 構築解、複数beam variant、fallback sweep、tail searchを併用する提出コードだった。

## 共通している考え方

- 一致接頭長を最重要指標にする。
- 次の目標色へ行く経路をBFS/ダイクストラで作る。
- 体のマスがいつ空くかを考慮する。
- 噛みちぎり後は、切れた尾または古い体列を辿ると正しい順に復元できる。
- BFSの方向順や候補選択に乱択を入れると、同じ最短距離でも違う未来を作れる。
- 評価関数だけでなく、候補生成の質がスコアに大きく効く。

## 解法の分類

- 大遷移ビーム型: through、mya3、takitamoのビーム部分。
- 差分更新ビーム型: Ang107k。
- ルールベース救済型: takitamo、kaede2020初期方針。
- 盤面編集/構築型: kaede2020の1個ずつ配置する方針。
- 高速化・候補管理型: throughのビットボード、Ang107kのActionPool、mya3の状態圧縮。

## 推奨して理解すべき順序

1. まずtakitamoを読む。状態、噛みちぎり、復元、ダイクストラ救済が具体的で分かりやすい。
2. 次にmya3 Editorialを読む。4種類のパス探索として問題を整理できる。
3. throughを読む。上位解法でどの遷移を分けるべきか、Wanderや軽いハッシュの意味が分かる。
4. Ang107kを読む。実装を高速化して重い手を扱う設計を学ぶ。
5. kaede2020を読む。失敗した特徴量や構築方針から、別方向の発想を得る。

## 実装するならどのルートか

理解のための最小実装は、takitamo+mya3をベースにするのがよい。

1. 正確なシミュレータを作る。
2. 一致接頭長を持つ。
3. 非目標餌を避けるBFSで次色を取る。
4. 色ずれ時に噛みちぎり、古い体/切れた尾を辿って復元する。
5. 小さなビームで `matchIndex` 最大、同点なら手数最小を選ぶ。

上位化するなら、throughのように遷移を分ける。

- GoTarget強/弱を分ける。
- CutRecoverを短手版と接頭長付近版に分ける。
- Wanderを入れて詰まり局面を崩す。
- ビットボードと軽いハッシュで高速化する。
- さらに必要ならAng107kのActionPool/受理閾値方式へ進む。

## 重要な実装要素

- 状態表現
  - 体の座標列、色列、餌盤面、色別餌位置、現在ターン、一致接頭長。
  - 噛みちぎり直後の頭尾同座標状態を扱えること。
- 評価関数
  - 最低限は一致接頭長とターン数。
  - 上位化では壁/角餌、中心距離和、隣接次色、行き止まりなどを補助にする。
- 近傍/遷移
  - 目標色へのBFS。
  - 噛みちぎり+復元。
  - 非目標餌許容の救済経路。
  - 1マス散歩またはWander。
- 差分更新
  - 食事、通常移動、噛みちぎりで、体・色・餌・占有を矛盾なく更新する。
- 候補管理
  - ターン数層、またはステップ層のビーム。
  - 状態圧縮/ハッシュは細かすぎても粗すぎても悪い。
- 出力判定
  - 完成したら手数最小。
  - 未完成なら絶対スコア上、接頭長が長い状態が重要。
- パラメータ
  - ビーム幅、Cut探索深さ、Wander長、候補数、復元を止める残り長。

## 落とし穴

- 尾が消える通常移動と、餌を食べて尾が残る移動で、体衝突判定が変わる。
- 噛みちぎり後、切れた尾側を餌に戻す色と座標をずらすと、以後すべて壊れる。
- 完全復元は安全に見えるが、同じ詰まりへ戻る場合がある。
- BFS方向順固定は、同じ距離の別経路を潰してスコアを悪化させやすい。
- 状態コピーが重いとビーム幅を増やせない。ビットボード、リングバッファ、ActionPoolが効く。
- 未完成解を捨てると、絶対スコア上は損することがある。
- TLE時のスコア0は順位への影響が大きい。滑り止め解は重要である。
