## 解法の全体像

公式解説は、まずこの問題で単純な貪欲やビームサーチが難しい理由を説明し、そのうえで「部分的に壊して、より賢い貪欲で作り直す」局所探索を中心方針として示している。

writer解コードは、現在解の一部領域をランダムに破壊し、破壊された点に依存する長方形も連鎖的に削除する。その盤面から候補長方形を再列挙し、1x1を優先しつつ短いランダムプレイアウトで再構築する。改善すれば採用し、悪化しても焼きなまし確率で採用する。

## 主要アイデア

- 途中盤面の生スコアは外側の点を過大評価し、大きな長方形を早く置いて後続の邪魔を作りやすい。
- ビームサーチは「途中状態がどれだけ外側へ伸びられるか」を評価する必要があり、生スコアだけでは弱い。
- 良い解は小さい長方形、特に 1x1 を多用し、各頂点の使用可能な辺の枠を無駄にしない。
- 解全体を作り直すのではなく、局所領域と依存先だけを消して再構築する。
- 再構築の貪欲を完全ランダムから改善すると、局所探索の到達スコアが大きく上がる。
- 序盤は全点重み1に近い評価で詰めることを優先し、時間経過で正規の重みへ寄せる。

## 最終コードの構造

### 状態表現

- `State` が盤面を持つ。
- `has_point: [Vec<u64>; 4]` は横、斜め、縦、逆斜めの4種類の直線上の印を64bitで保持する。
- `has_edge: Vec<u8>` は各点から8方向の辺使用状況をビットで保持する。
- `cand: [Vec<Rect>; 2]` は描画候補を 1x1 とそれ以外に分けて保持する。
- `score` は問題本来の重み和、`score2` は全点重み1の重み和を表す。
- `Rect` は4頂点と最初の辺方向を持つ。

### 観測・制約・入力の扱い

- 初期点をすべて `insert_point` し、4直線方向のビットボードを更新する。
- `next_point(p, d)` で8方向の次の印をビット演算により取得する。
- `can_draw` は次を確認する。
  - 新点が未使用である。
  - 外周に既存の印がない。
  - 外周に既存辺との正の長さの共有がない。
- 新点が既存長方形の辺上に乗る場合、その点にも辺情報を追加して以後の合法性判定を崩さない。

### 評価関数

- 最終スコアは問題本来の正規化スコアを使う。
- 焼きなまし中の評価は、時刻に応じて `score2` から `score` へ線形に寄せる。
- 候補選択 `eval` は、長方形の4頂点について反対側の辺が既に使われているなら加点する。既存辺上に点を置く候補はペナルティを受ける。
- 1x1 とそれ以外を分け、良い解で多用される 1x1 を優先しやすくする。

### 探索・構築・更新

- メインループは制限時間 4.9 秒まで回る。
- 既存解からランダムなマンハッタン円領域を選び、その領域内の追加点を削除対象にする。
- 削除対象点を使って作られた長方形も連鎖的に削除する。
- 消しすぎると再構築が重く弱くなるため、削除数が閾値以上なら試行を捨てる。
- 削除後に候補を再初期化し、`playout` で候補を追加し尽くす。
- `playout` では候補から最大4個をランダムに取り出し、評価値最大のものを描画し、残りを戻す。
- 採択条件は改善なら必ず採用、悪化なら温度 `T` に基づく確率採用である。

### 操作・クエリ・出力選択

- 途中で見つかった本来スコア最大の操作列を `best` に保存する。
- 出力は `best` の長方形列をそのまま操作列として出す。
- 各行は新点 `rect[0]` から始まる4点を出力する。

### 時間配分・パラメータ

- 制限時間は 4.9 秒。
- 温度は `T0 = 0.015`, `T1 = 0.0025` を幾何的に補間し、`61 / N` を掛ける。
- 初期点数が少ない入力は密に詰めるより外側に広げる傾向があるため、最初から本来重みを使う。
- 削除上限は現在の best score から概算される `NUM` を使う。

## 実装上重要な断片

```text
loop until time_limit:
    choose random center and radius
    mark added points in the region as deleted
    scan current rectangles in order
        if new point is deleted or depends on deleted point:
            mark this rectangle deleted
    clone state and delete marked rectangles
    rebuild candidates from remaining points
    playout greedily with random candidate sampling
    accept by simulated annealing
```

```text
playout:
    for tier in [1x1, other] with random rotation:
        sample up to 4 drawable candidates
        draw the candidate with max eval
        insert candidates newly enabled by the new point
```

## この解法の本質

この問題では、1手の得点よりも「あとで密に伸びる盤面を残しているか」が重要である。公式解は、途中盤面の精密な評価を作る代わりに、現在解の大部分を残したまま局所だけを壊し、再構築結果の最終スコアで判断する。局所性と依存関係を利用して、ビームサーチでは見にくい長期的な良さを局所探索の反復で拾っている。

## 真似するならまず実装する部分

最初は、`marked` と 8方向の `edge` を持つ合法判定、候補列挙、1x1優先の貪欲を作るのがよい。次に、追加点から作られた長方形を辿って依存削除し、削除後に貪欲で作り直す山登りへ進む。ビットボードや重み補間は、その後の高速化・上位化として入れる。
