## 解法の全体像

`M` と `epsilon` によって複数方式を使い分ける。一般的な場合は、頂点を3つのクリークに分け、その3グループのサイズ組で情報を伝える。受信時は各頂点のグループ割当を山登りで推定し、復元された3サイズの組から元グラフ番号を決める。

`epsilon=0` では、同型でない小グラフを使って完全識別する。`epsilon` が小さい場合は、同型グラフ同士の編集距離に余裕を持たせ、1辺程度のノイズなら近い代表に戻す。`epsilon` も `M` も大きい場合は高精度復元を諦め、`N=4` の小さいグラフでランダム寄りに答える。

## 主要アイデア

- 大きめのクリークはノイズ後もサイズを推定しやすいので、クリークサイズの組で情報を伝える。
- 3グループなら、`N` に対しておよそ2次元分のサイズ組が作れ、`M <= 100` を表しやすい。
- 復元は「このグループ割当ならノイズ反転が何回起きたことになるか」を評価して山登りする。
- `epsilon` が大きいほど小さいブロックは取り違えやすいため、最小ブロックサイズを上げる。
- さらに2ブロックのサイズ変動をシミュレーションし、サイズ組同士のブレ幅が重ならないように候補を選ぶ。
- `epsilon=0` は同型類代表グラフを使い、`N=6` で100種類を十分表せる。
- 小epsilonでは、代表グラフ同士を辺編集距離で離し、ノイズ後のグラフを最も尤もらしい代表へ戻す。

  - 代表間の辺編集距離、またはノイズ後グラフから代表への対応表。

### 観測・制約・入力の扱い

- `M, epsilon` で方式を分岐する。
- 一般方式では、決めた `N` と `M` 個の3クリークグラフを出力する。
- 観測グラフは頂点番号が失われているので、グループ割当だけを推定する。
- `epsilon=0` ではノイズがないため、受信グラフを同型判定して代表番号へ写す。
- 小epsilonでは、1辺程度の反転を許容するマップを用意しておく。

### 評価関数

一般方式の復元評価は、「推定グループ構造から見て、観測辺がどれだけノイズなし構造に合うか」である。

```text
cost(assignment):
    cost = 0
    for each pair (u, v):
        expected_edge = same_group(assignment[u], assignment[v])
        if observed_edge(u, v) != expected_edge:
            cost += 1
    return cost
```

記事ではノイズ反転回数を評価値として山登りしたとあるため、最小化対象はこの不一致数に近いと考えられる。サイズ組選択では、推定サイズのブレ幅を標準偏差に比例する幅として見積もり、候補間の重なりを避ける。

### 探索・構築・更新

- 一般方式の復元:
  - 頂点にランダムなグループを振る。
  - 1頂点を別グループへ移す近傍で山登りする。
  - 局所解に着いたら一部をランダムシャッフルして再開する。
  - 最も不一致数が少ない割当を採用する。
- サイズ組の構築:
  - 最小ブロックサイズ制約を `epsilon` に応じて変える。
  - 2ブロックのサイズ変動をシミュレーションし、3ブロックの各ペアへ組み合わせてブレを見積もる。
  - 使用サイズ組同士が近すぎないように選ぶ。
- 小epsilon同型方式:
  - 同型類代表グラフを頂点とするグラフを考え、1辺反転で移る関係を辺として扱う。
  - 互いに距離2以上離れた代表集合を選ぶ。
  - 中間グラフが来たら最も確率の高い代表へ戻す。

### 操作・クエリ・出力選択

- 一般方式では、復元したグループサイズ組をソートまたは正規化し、対応するグラフ番号を出す。
- サイズ組が複数候補に近い場合は、推定誤差幅を考慮した最近傍選択をしていたと推測される。
- 小epsilon方式では、受信グラフの同型類を求め、直接代表か、隣接代表に対応付ける。
- 運任せ方式では、空グラフ寄りか完全グラフ寄りかを多数決で判定し、その半分の候補から答える。

### 時間配分・パラメータ

- 最小ブロックサイズは `epsilon` に依存。
- `N` は `M` と `epsilon` ごとに実験で事前計算しようとしたが、完全な探索は間に合わず、`M` 10個間隔の実験から補完したとある。
- 小epsilon方式は、`epsilon=0.01` は全 `M`、`0.02..0.04` は `M` が小さい範囲で採用、`0.05` 以上は一般方式を主に採用。
- 運任せ方式は改善後、`epsilon` と `M` がどちらも大きい場合のみ採用。

## この解法の本質

この解法の本質は、ノイズのあるグラフを細かい辺単位で読むのを諦め、連結密度が大きく変わる「塊のサイズ」に情報を落とす点である。クリークは多数決構造なので、頂点数が十分あれば辺反転に強い。

一方で、グループサイズは確率的にぶれる。そこで、サイズのブレ幅をシミュレーションで見積もり、識別可能な距離を空けて符号語を置く、という誤り訂正符号に近い考え方が入っている。

## 真似するならまず実装する部分

まずは3クリークサイズ方式だけを実装するのがよい。固定 `N` でサイズ三つ組を列挙し、ランダム初期解からの山登りでグループ復元し、サイズ最近傍で答える。小epsilon同型方式や運任せ分岐は後から加えられる。
