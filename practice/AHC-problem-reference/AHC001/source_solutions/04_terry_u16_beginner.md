## 解法の全体像

この記事は、AHC初心者向けに「正の得点を取る」「山登りを入れる」「平行移動を入れる」「焼きなましを入れる」という順で改善していく。最終段階は、各広告を1マスから始め、ランダムに選んだ広告を拡大、平行移動、縮小のいずれかで1マス変化させる焼きなましである。

高得点解法というより、AHC001でまず実装すべき最小の探索基盤を示す記事である。状態、交差判定、点包含判定、差分スコア、温度付き受理といった基本要素が揃っている。

## 主要アイデア

- どの広告も希望点を含む1x1矩形なら、必ず非重複で正の得点を取れる。
- そこから1広告を1マス拡大する山登りだけでも、かなりの得点になる。
- 拡大だけだと他広告が邪魔で詰まるため、平行移動を入れて場所をずらす。
- この問題では満足度を均す方がよいため、たまに縮む操作が必要になる。
- 縮小は短期的にはスコアを下げるので、焼きなましで悪化遷移も確率的に受理する。
- 重なり判定は `n <= 200` なので愚直 `O(n)` でも十分に使える。

## 最終コードの構造

### 状態表現

- `Request { row, col, area }`: 希望点と要求面積。
- `Input { count, requests, since }`: 入力と開始時刻。
- `Advertisement { row0, col0, row1, col1 }`: 半開区間の矩形。
- `results`: 現在の広告矩形配列。
- `scores[i]`: 広告ごとの現在スコア。
- `current_score`, `best_score`, `best_result`: 現在状態と最良状態。

### 観測・制約・入力の扱い

- 初期解は各希望点の1x1矩形。
- `intersects` で任意2矩形の正面積交差を判定する。
- `contains` で希望点を含むか判定する。
- 新しい矩形が盤面外、空矩形、希望点を含まない、または他矩形と交差する場合は棄却する。
- 記事では、実装を関数や構造体へ分け、`assert` などで不変条件を確認することも勧めている。

### 評価関数

- 個別スコアは問題文通り。
- 1マス解と初期山登りでは、面積が要求面積を超える遷移は採用しない段階がある。
- 焼きなまし版では、各遷移で対象広告1つのスコア差だけを計算する。
- 温度は `TEMP0=1e-5`, `TEMP1=1e-7` の幾何的補間で下げる。

### 探索・構築・更新

- 1マス解:
  - 各広告を `(x_i, y_i, x_i+1, y_i+1)` にする。

- 山登り版:
  - ランダムに広告を1つ選ぶ。
  - ランダムな方向へ1マス拡大する。
  - 他広告と交差せず、要求面積以下なら採用する。

- 改善版:
  - 遷移に平行移動を追加する。
  - 希望点を含まなくなる遷移は棄却する。

- 焼きなまし版:
  - 遷移は12種類。4方向拡大、4方向平行移動、4方向縮小。
  - 対象広告だけのスコア差を計算する。
  - 改善なら採用、悪化なら `exp(diff / temp)` で採用する。
  - スコアが最大になった状態を保存して最後に返す。

### 操作・クエリ・出力選択

- 時間いっぱいランダム近傍を回す。
- 最終出力は焼きなまし中の最良状態。
- 各矩形を `row0 col0 row1 col1` の形式で出力する。

### 時間配分・パラメータ

- 時間制限は約4.98秒として扱う。
- 焼きなまし版は100反復ごとに時刻と温度を更新する。
- 乱数seedは42固定。
- 焼きなましの温度は `1e-5 -> 1e-7`。

## 実装上重要な断片

```text
initial:
    for each i:
        rect[i] = [x_i, x_i+1) x [y_i, y_i+1)
```

```text
annealing_step:
    i = random ad
    move = random from 12 moves
    new_rect = apply(move, rect[i])
    reject if invalid or intersects or not contains point_i
    diff = score(new_rect) - score(rect[i])
    if diff >= 0 or rand < exp(diff / temp):
        rect[i] = new_rect
        update scores and best
```

## この解法の本質

この解法の本質は、AHC001を「非重複矩形集合の局所探索」として最小限の部品で扱えるようにした点である。1x1初期解でWAを避け、愚直交差判定で制約を守り、差分スコアで軽く回す。焼きなましにより、面積を少し譲って別の広告を伸ばすための悪化遷移を許す。

上位解法のような大きな破壊近傍はないが、状態表現と検証、評価、受理判定が素直なので、後から近傍を足す土台として優れている。

## 真似するならまず実装する部分

まず1x1初期解、矩形交差判定、点包含判定、個別スコア関数を作る。その後、1広告1辺を1マス伸ばす山登りを実装する。

次に平行移動と縮小を加えて焼きなましにする。ここまでできれば、以降の破壊近傍や多点スタートを追加しても、スコア計算と制約判定を使い回せる。

## 注意点・未理解点

- `contains` は半開区間として実装する必要がある。右端・上端の扱いを間違えると希望点判定がずれる。
- 縮小や平行移動は希望点を外しやすいので、受理前に必ず点包含を確認する。
- 焼きなましの温度はスコア差のスケールに合わせる必要がある。記事の提出コードでは個別スコアが0から1なので非常に小さい温度を使っている。
- 拡大・縮小・平行移動だけでは、詰まった配置からの脱出力は限定的である。上位化には破壊近傍や再構築が必要になる。
