## 解法の全体像

記事は「手抜きルート」と「本気ルート」に分けて、正の得点を取るところから96%台までの改善を段階的に説明している。最終解法は、全希望点を確保する再帰分割で初期解を作り、各矩形をランダムに選んで伸ばす局所改善を行い、最後に近い5個の矩形をまとめて小さく戻して再改善する局所破壊を加える。

アルゴリズム的には、最初に領域を分割して衝突しない配置を保証し、その後は「どの方向にどれだけ伸ばせるか」を愚直な衝突判定で計算して面積を増やしていく構成である。

## 主要アイデア

- まず全点を含む状態を作る。高得点には全広告が希望点を含むことがほぼ必須だと見る。
- 初期解は再帰的な2分割。点集合を含む最小矩形を見て、点が分かれるように領域を切る。
- 1点だけになった小領域では、希望点を含む正方形寄りの矩形を作る。
- 局所改善ではランダムな広告と方向を選び、他矩形や盤面境界にぶつかるまでの最大伸長量を `O(n)` で求める。
- 伸ばした結果、要求面積を超えてもよい。その直後にスケール調整して、面積を要求面積以下または近傍へ戻す。
- 一度矩形が密着すると動きにくいので、ランダム点からマンハッタン距離が近い `K=5` 個を小さめの正方形寄りに戻し、その部分だけ再改善する。
- 最終の破壊受理は山登りで、スコアが上がったときだけ採用する。

## 最終コードの構造

### 状態表現

- `Point`: 整数座標。
- `Range { l, r }`: 1次元半開区間。幅、包含、平行移動を持つ。
- `RectRange { x, y }`: 矩形半開区間。面積、幅、高さ、点包含、和集合相当の演算を持つ。
- `Query { p, r }`: 希望点と要求面積。
- `Input { n, Q }`, `Output { R }`: 入出力。
- `RecursiveNode`: 領域サイズとその中のクエリ集合を持ち、再帰分割で矩形配列を返す。
- `ImprovingSolution`: 現在解に対して、1広告を1方向へ伸ばす局所改善を行う。
- `NeighborSearch`: 近い `K` 個を破壊して再改善する。

### 観測・制約・入力の扱い

- 半開区間で矩形を扱い、希望点は整数セル `(x, y)` が矩形に含まれるかで判定する。
- 入力を読んだ後、`RecursiveSolution` で必ず全点をどこかの非重複矩形に入れる。
- `max_delta` は対象矩形と同じ投影範囲を持つ他矩形だけを見て、その方向に伸ばせる限界距離を求める。
- 最終コードには検証用の `Evaluator` と `SimpleEvaluator` があり、WA条件とスコア計算を分けている。

### 評価関数

- `SimpleEvaluator` は、各矩形が希望点を含むなら `1 - d^2` を足す。ここで `d = 1 - min(r, s) / max(r, s)`。
- 全広告分を平均して `1e9` 倍し、丸める。
- 最終の局所破壊では、破壊前後の全体スコアを比較し、改善していれば採用する。

### 探索・構築・更新

- `OneQuery`:
  - 1点だけの領域に対して、要求面積の平方根程度の幅を取り、領域内に収まるよう平行移動する。
  - 領域の縦横が逆なら回転して処理する。

- `RecursiveSolution`:
  - クエリが0なら空、1なら `OneQuery`。
  - 複数点なら、点集合を含む最小矩形を作る。
  - その最小矩形の幅と高さを比べ、広い方向を中央付近で切る。
  - 2つの部分領域にクエリを振り分け、座標を部分領域基準へ変換して再帰する。

- `ImprovingSolution`:
  - ランダムに広告と方向を選ぶ。
  - その方向に伸ばせる最大距離 `max_delta` を求める。
  - 最大距離と引数 `max_delta_const` の小さい方だけ伸ばす。
  - 面積が要求面積を超えたら、幅高さを平方根スケールで縮め、希望点を含むよう平行移動する。

- `NeighborSearch`:
  - ランダムな点 `C` を選ぶ。
  - 希望点から `C` へのマンハッタン距離が小さい順に `K=5` 個を選ぶ。
  - 選んだ矩形を、その現在の枠内で小さめの正方形寄り矩形に戻す。
  - 選んだ `K` 個だけに対して、伸長改善を `max_delta=100, 10, 1` の順で繰り返す。
  - スコアが下がらなければ状態を置き換える。

### 操作・クエリ・出力選択

- 最終コードの流れは次の通り。
  - `RecursiveSolution` で初期解を作る。
  - `ImprovingSolution` を `max_delta=100, 10, 1` で各5万回ずつ実行する。
  - `NeighborSearch(5)` を `500000 / n` 回実行する。
  - 評価して出力する。

### 時間配分・パラメータ

- 乱数seedは0。
- 初期改善は `50000` 回ずつ3段階。
- 局所破壊は `K=5`。
- 破壊後の再改善は、各対象に対して `max_delta=100` を200回、`10` を200回、`1` を200回。
- 時間制御より固定回数ベースの実装である。

## 実装上重要な断片

```text
recursive(node):
    if no query: return []
    if one query: return near_square_rect_containing_point()
    bbox = bounding box of query points
    cut direction = longer side of bbox
    split region into two
    recurse on each side
```

```text
improve(i, dir, limit):
    d = min(limit, max_delta(i, dir))
    expand rect i by d in dir
    if area exceeds target:
        shrink width and height by sqrt(target / area)
        shift back so the requested point remains included
```

```text
neighbor_search(K):
    C = random point
    targets = K nearest requested points by Manhattan distance from C
    shrink each target to a compact rectangle
    improve only targets with large, medium, small deltas
    commit if total score does not decrease
```

## この解法の本質

この解法の強みは、構築と改善の役割を明確に分けている点である。再帰分割で「全点を含み、重ならない」という土台を作り、局所改善では空き面積を少しずつ回収する。破壊近傍も、全体を壊すのではなく、空間的に近い少数の矩形だけを小さく戻すため、実装が比較的単純で効果も読みやすい。

記事の「algo勢」らしさは、各段階を小さな構築問題へ分解しているところにある。1マス解、等分スライス、割り当て、再帰分割、伸長、局所破壊という順で、各改善が何を解決しているかが追いやすい。

## 真似するならまず実装する部分

まず再帰2分割による初期解を実装するとよい。全点を確保できる非重複解が手に入るため、その後の局所探索が作りやすい。

次に、`max_delta` を `O(n)` で求めて1方向へ伸ばす改善を実装する。破壊近傍はその後でよい。最初から破壊まで入れるより、再帰分割と伸長改善の2つだけで評価基盤を作る方が理解しやすい。

## 注意点・未理解点

- 再帰分割は点集合の形に依存する。切り方が悪いと細長い領域や小さすぎる領域ができ、後段の伸長が弱くなる。
- `max_delta` は矩形の投影区間の交差を正しく見る必要がある。上下左右で式を取り違えやすい。
- 面積超過後の縮小は希望点を含むよう戻す処理が必須である。
- 固定回数ベースなので、環境差や `n` によって時間に余裕が出たり不足したりする可能性がある。
- 途中提出も読めたが、最終メモでは最終コードと記事本文から読める発展過程を中心に整理している。
