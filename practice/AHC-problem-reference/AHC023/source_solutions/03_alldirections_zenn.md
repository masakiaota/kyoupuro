## 解法の全体像

まず、通路用セルと作付用セルを完全に分ける。通路用セルは出入口から連結で、作物を植えない。作付用セルは通路に隣接する。これにより、作付用セル同士の相互依存を消し、到達性を単純化する。

その後、BFS で作った出入口根の木を使い、葉から順に作物計画を決める方針へ進む。木のあるセルに作物を植えると、そのセルの部分木へ到達できない期間が生じるため、部分木側で必要な植え付け・収穫タイミングを塞がないようにする。作物選択は、収穫月ごとのナップサック DP で最大化する。さらに、パス再計画や迂回路を使った追加作付けで少し改善する。

## 主要アイデア

- 通路と作付区画を分離すると、各作付区画を独立に近く扱える。
- BFS 木を出入口根で作り、部分木の予定を邪魔しないよう葉側から計画する。
- あるセルに作物を植える可否は、そのセルの部分木で到達が必要な月を塞ぐかどうかで判定する。
- `T=100` なので、塞いではいけない月集合は bitset で管理できる。
- 作物選択は `dp[t]=max(dp[t-1], dp[S_i-1]+value_i)` の区間 DP として解く。
- 生スコア `D_i-S_i+1` では短い作物を詰めすぎるため、最終的には `2V_i-3` のように長い作物をやや優遇する重みを使う。
- ランダムに選んだ区画から出入口までのパスを解放し、そこだけ計画し直す局所再構築を行う。
- 木では塞いで見えるセルでも、元グラフの迂回路で到達できるなら追加作付けできる。

## 最終コードの構造

Browserで読めた提出 `45449108` と記事本文を合わせた実装構造を書く。

### 状態表現

- 水路を除いたグリッドグラフ。
- 出入口根の BFS 木:
  - 親、子リスト
  - DFS 順または部分木のセル集合
  - 各セルの部分木に含まれる到達イベント月 bitset
- 各セルに割り当てた作物列。
- 使用済み作物集合。
- `forbidden[cell]`: そのセルに作物を植えると部分木の到達を邪魔する月集合。

### 観測・制約・入力の扱い

- 入力から隣接可能なグラフを作る。
- 初期方針では、通路セルを出入口から BFS で伸ばし、通路隣接セルを作付候補にする。
- 木方針では、部分木内の植え付け・収穫イベントを親へマージする。
- 記事中では、植えられる期間全体を見る必要はなく、収穫月を覆っているかを確認すればよいという気づきが述べられている。

### 評価関数

- 実スコアは `sum(D_i-S_i+1)`。
- DP で使う内部重みは調整されており、最終版では `V_i=D_i-S_i+1` に対して `2V_i-3` を使ったと書かれている。
- 長い作物を奥に置きやすくし、短い作物で隙間だけを埋める偏りを避ける意図である。

### 探索・構築・更新

- 通路構築の貪欲:
  - 全セルを接触不能から始める。
  - 出入口から通路を広げる。
  - 通路に接するセルのうち、通路にしたとき接触不能セルが最も減るものを優先度付きキューで選ぶ。
- 木上の計画:
  - 葉側からセルを処理する。
  - 部分木の到達イベント bitset を見て、そのセルで使える時間区間を得る。
  - 作物候補に対して DP で採用列を選ぶ。
- パス再計画:
  - ランダムなセル `i` を選ぶ。
  - `i` から出入口までの木パス上の作物を解放する。
  - そのパス上の計画をやり直す。
- 迂回路改善:
  - 出入口、現時点で到達不可、唯一の接点、元グラフの関節点を候補から除く。
  - 各時刻で追加可能なセル候補を探し、最も長い区間を取れるものに作物を入れる。

### 操作・クエリ・出力選択

- 各セルに決めた作物列を、作物 ID、座標、植える月として出力する。
- 同じ月の順序は出力しないが、木の葉から奥・手前の関係を守ることでジャッジが適切な順序を見つけられる計画にする。

### 時間配分・パラメータ

- `T=100` を活かし bitset を使う。
- 初期のランダム作物選択では1セルあたり500個程度の確認で 31M。
- 多重カウント修正後は全作物を見られるようになり、DP 化でほぼ最終版に近い点数。
- パス再計画は最終的に 38.7M から 38.75M 程度、迂回路改善は 38.75M から 38.77M 程度の寄与。

## 実装上重要な断片

```text
plan_cell(cell):
    blocked = forbidden months from children/subtree
    dp[0..T] = -inf
    dp[0] = 0
    for t in 1..T:
        dp[t] = dp[t-1]
        for crop with D[crop] == t:
            if interval [S[crop], D[crop]] is compatible with blocked:
                dp[t] = max(dp[t], dp[S[crop]-1] + adjusted_value(crop))
    restore chosen crops
    update forbidden[parent] with this cell's events
```

```text
replan_path():
    v = random cell
    path = tree path from v to entrance
    unassign crops on path
    recompute plans for path cells in leaf-to-root order
```

## この解法の本質

空間の連結制約を、出入口根の木に沿った部分木制約へ変換している点が本質である。木にすると「このセルを塞ぐと、下の部分木へ行けない」という関係が明確になる。さらに `T=100` の小ささを使い、到達が必要な月集合を bitset としてマージすることで、重い到達性シミュレーションを避けている。

## 真似するならまず実装する部分

まず BFS 木を作り、葉から順に「部分木の収穫月 bitset を塞がない作物だけ選ぶ」実装を作るとよい。作物選択は最初は貪欲でよく、その後 `dp[t]=max(dp[t-1], dp[S_i-1]+value_i)` の復元付き DP に置き換えるのがよい。

## 注意点・未理解点

- 提出コードでbitset、DP復元、部分木ブロック判定は確認できたが、内部重み係数の調整意図は記事以上には分からない。
- 「収穫月だけ見れば十分」という主張は記事内での気づきとして書かれているが、実装でどのイベントを bitset に入れるかは注意が必要である。
- 重み `2V_i-3` は経験的調整で、他の構築順では最適とは限らない。
- 迂回路改善は効果が小さく、関節点・唯一接点の判定を誤ると WA になりやすい。
