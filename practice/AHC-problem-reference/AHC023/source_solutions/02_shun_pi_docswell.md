## 解法の全体像

序盤は、常に空ける通路と、その通路に接する小グループを作る固定通路貪欲で進める。通路を木としてランダムに伸ばし、通路に隣接する非通路セルをグループ根として多点 BFS でグループ分けする。各グループ内では、同じような `S,D` の作物をまとめて植え、周期を短くして利用率を上げる。

最終解法は、固定通路の限界を見てから、全ターンの「収穫領域」を状態として焼きなます方針に移る。あるターンに収穫するマス集合は出入口を含む連結領域である必要がある。この全ターン分の領域が決まると、各マスの時間軸が収穫・空きターンで区切られ、各区間に作物を高々1つ割り当てられる。近傍は、あるターンの収穫領域を1マス増やす・減らすことであり、これはそのマスの時間区間に区切りを入れる・区切りを消す操作になる。

## 主要アイデア

- 固定通路方針では、通路と小グループに分けることで各グループを独立に近く扱う。
- グループ割当では、最終ターン `d` を固定し、`S` を遅らせる損と `D` を早める損が小さい順に貪欲割当する。
- 41M から先は固定通路の未利用マスがボトルネックになるため、通路そのものを固定しない。
- 上位解法は、毎月の収穫領域が伸び縮みする動的通路のような形だと推測する。
- 全ターンの収穫領域を同時に持つと、各マスの作物計画は時間区間の列に分解できる。
- 領域を1マス増やす近傍は、そのマスの区間分割に新しい切れ目を入れることに対応する。
- 領域を1マス減らす近傍は、そのマスの隣接する2区間をマージすることに対応する。
- 連結性維持のため、削除可能判定は LowLink から周囲 3x3 の簡易関節点判定へ高速化する。

## 最終コードの構造

Browserで読めた提出 `45449213` とスライド本文を合わせた実装構造を書く。

### 状態表現

- `region[d]`: ターン `d` に収穫・通行のために空く連結領域。出入口を含む。
- `breaks[cell]`: そのセルが収穫領域に含まれるターン、または空けておくターンの集合。
- `intervals[cell]`: `breaks[cell]` によって区切られた時間区間。
- `assigned[cell][interval]`: 区間に割り当てた作物 ID。割当なしもある。
- `used_crop[k]`: 作物がすでに使われているか。
- `score`: 採用作物の `D_k-S_k+1` の合計。
- 連結性判定用に、各ターンの領域の隣接情報・境界候補・削除候補を持つと考えられる。

### 観測・制約・入力の扱い

- 水路を除いた4近傍グラフを作る。
- 各ターンの収穫領域は出入口から連結である必要がある。
- あるマスの区間 `[l, r]` に作物 `k` を入れるには、収穫月 `D_k` が区間の右端に対応し、植える月は `S_k` 以前へ前倒し可能な範囲で区間左端側に置ける必要がある。
- `S` より前に植えても得点は増えないため、早植えは到達性を満たすための自由度として使う。

### 評価関数

- 基本評価は採用作物の期間長合計。
- 近傍の差分では、削除・追加される作物だけを外して入れ直し、スコア差を計算する。
- 最終調整では「領域追加」の点数を高め、「領域削除」の点数を低くするバイアスを入れ、領域が最適より少し大きくなるよう誘導している。

### 探索・構築・更新

- 初期解は 41.6M 程度の固定通路貪欲。
- 焼きなましの近傍:
  - ターン `d` を選ぶ。
  - `region[d]` に隣接する1マスを追加する。対応セルの区間を2つに割り、元作物を外して2区間へ作物を再割当する。
  - または `region[d]` から削除しても連結が壊れない1マスを消す。対応セルの隣接2区間をマージし、元作物を外して1区間へ作物を再割当する。
- 連結性の削除判定:
  - 初期は LowLink で関節点判定。
  - 高速化後は、対象セル周囲 3x3 内で、対象セルに隣接する領域セルが対象削除後も局所的に連結なら削除可能とする近似判定。
- 数千ループに1回、全マス全区間を見直して作物を再割当する。

### 操作・クエリ・出力選択

- 最終状態の `assigned[cell][interval]` から、各作物の `(k, i, j, s)` を出力する。
- 同月に収穫される領域が連結なので、収穫順序を適切に取れば到達できる。
- 収穫後に次の作物をすぐ植えることで、全体を高利用率に保つ。

### 時間配分・パラメータ

- 焼きなまし初版は手元で約25万ループ。
- 関節点高速化後は約175万ループ。
- 最終提出では乱数を 1000 万個事前生成し、約500万ループ。
- 最終盤の改善で、領域追加・削除の評価に非対称バイアスを入れている。

## 実装上重要な断片

```text
toggle_region_cell(d, cell):
    old_intervals = intervals[cell] around d
    remove assigned crops from affected intervals

    if add cell to region[d]:
        insert break d in breaks[cell]
        create two intervals
    else:
        remove break d from breaks[cell]
        merge two intervals

    greedily assign unused crops to new intervals
    delta = new_score - old_score
    accept by simulated annealing
    if reject:
        rollback breaks, region, assignments, used crops
```

```text
can_remove(d, cell):
    if cell is entrance:
        return false
    neighbors = region[d] cells adjacent to cell
    return neighbors remain connected in local 3x3 graph after deleting cell
```

## この解法の本質

通路を固定すると、その通路セルはほぼ常に得点を生まない。Shun_PI 解は、各ターンの収穫領域を状態にすることで「その月だけ通れる動的通路」を作っている。空間の連結制約を月ごとの連結領域に押し込み、時間方向は各セルの区間分割として扱う。この変換により、近傍操作が「領域の1マス増減」と「1セルの区間分割更新」に局所化される。

## 真似するならまず実装する部分

完全な焼きなましではなく、まず固定通路＋小グループ方針を作るとよい。次に、1セルについて「収穫・空きターンで時間を区切り、各区間に作物を割り当てる」モデルを実装する。そこまでできてから、1ターンの収穫領域を1マス増減する近傍を加えるのが自然である。

## 注意点・未理解点

- 提出コードで作物再割当・温度スケジュールの実装は読めたが、各フェーズの係数調整意図はスライドだけでは完全には分からない。
- 3x3 簡易関節点判定は高速だが、どの条件なら大域連結性を壊さない近似になるかは実装依存である。
- 差分再割当は全体最適ではないとスライドでも述べられており、定期的な全体再割当が重要である。
- 領域追加・削除の非対称評価はパラメータ依存が強く、再現には調整が必要である。
