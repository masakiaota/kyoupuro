# A - Server Room

実行時間制限: 3 sec / メモリ制限: 1024 MiB

## 問題文

株式会社リクルートには `N` 行 `N` 列のグリッドで表されるサーバ室がある。サーバ室の上から `i` 行目（`0 <= i < N`）、左から `j` 列目（`0 <= j < N`）のセルを `(i, j)` と表す。各セルには、コンピュータを最大1個まで置くことができる。

サーバ室には `K` 種類のコンピュータが100個ずつある。既に `100 × K` 個のコンピュータが `100 × K` 個のセルに置かれていて、残りの `N^2 - 100 × K` 個のセルには何も置かれていない。

Xさんはコンピュータを何度か移動した後、コンピュータ同士をまっすぐなケーブルで接続する。移動と接続は次のような操作を指す。

- 移動: 動かしたいコンピュータを1個選び、上下左右の四方向に隣接するセルのどれかへ動かす。一度動かしたコンピュータを複数回動かすこともできる。移動先として他のコンピュータが存在するセルを選ぶことはできず、コンピュータをサーバ室の外へ移動することもできない。
- 接続: つなぎたいコンピュータを2個選び、それら同士をまっすぐなケーブルでつなぐ。選んだ2個のコンピュータは同じ行か同じ列に存在し、間に他のコンピュータが存在しない必要がある。ケーブルは他のケーブルと交差してはならないが、あるコンピュータに複数の方向からケーブルを接続することは可能である。既にケーブルで直接つながっているコンピュータ同士を再び指定することはできず、あるコンピュータの接続先としてそのコンピュータ自身を指定することもできない。

コンピュータたちを接続することでクラスタが作られる。あるコンピュータ `C_i` から別のコンピュータ `C_j` にケーブルを1回以上通ってたどり着くことができる場合に、またその場合に限り、`C_i` と `C_j` は同じクラスタに属するとみなす。

サーバ室の処理性能は、クラスタ内に種類が同じコンピュータの組の数が多ければ多いほど上がり、種類が異なるコンピュータの組の数が多ければ多いほど下がる。厳密には、サーバ室に置かれている `100 × K` 個のコンピュータを `C_0, C_1, ..., C_{100K-1}` と表し、`0 <= i < j < 100 × K` を満たす全ての組 `(i, j)` について以下の点を計算したものの和を処理性能とする。

- `C_i` と `C_j` が同じクラスタに属していて、種類が同じ場合は `1` 点
- `C_i` と `C_j` が同じクラスタに属していて、種類が異なる場合は `-1` 点
- `C_i` と `C_j` が同じクラスタに属さない場合は `0` 点

移動を行う回数と接続を行う回数の和は `100 × K` 以下である必要がある。なるべくサーバ室の処理性能が大きくなるような移動と接続の仕方を見つけよ。

## 得点

サーバ室の処理性能が0点より大きい場合はそれがそのまま得点となり、そうでない場合は0点となる。

## 入力

入力は以下の形式で標準入力から与えられる。

```text
N K
c_{0,0} ... c_{0,N-1}
:
c_{N-1,0} ... c_{N-1,N-1}
```

1行目には2つの整数 `N` と `K` を含む。続く `N` 行のそれぞれには、長さ `N` の文字列が1つ与えられる。

- `N` と `K` はサーバ室の大きさとコンピュータの種類数を表す整数で、以下のいずれかを満たす。
- `K = 2` かつ `15 <= N <= 39`
- `K = 3` かつ `18 <= N <= 42`
- `K = 4` かつ `21 <= N <= 45`
- `K = 5` かつ `24 <= N <= 48`
- `c_{i,j}` はセル `(i, j)` の初期状態を表す整数で、`0 <= c_{i,j} <= K` を満たす。
- `c_{i,j} = 0` の場合、コンピュータが置かれていないことを表す。コンピュータが置かれていないセルは必ず `N^2 - 100 × K` 個であることが保証される。
- `1 <= c_{i,j} <= K` の場合、種類が `c_{i,j}` であるコンピュータが置かれていることを表す。各種コンピュータは必ず100個ずつ置かれていることが保証される。

## 出力

以下の形式で標準出力へ出力せよ。

```text
X
a_0 b_0 c_0 d_0
:
a_{X-1} b_{X-1} c_{X-1} d_{X-1}
Y
e_0 f_0 g_0 h_0
:
e_{Y-1} f_{Y-1} g_{Y-1} h_{Y-1}
```

1行目に、移動を行う回数を表す整数 `X` を出力する。続く `X` 行には、移動の情報を表す4つの整数を移動を行う順に出力する。`i` 行目の整数 `a_i, b_i, c_i, d_i` は、`(a_i, b_i)` に置かれているコンピュータを `(c_i, d_i)` へ移動することを表す。

その後、接続を行う回数を表す整数 `Y` を出力する。続く `Y` 行には、接続の情報を表す4つの整数を出力する。`i` 行目の整数 `e_i, f_i, g_i, h_i` は、`(e_i, f_i)` に置かれているコンピュータと `(g_i, h_i)` に置かれているコンピュータを接続することを表す。

また、以下の制約をすべて満たす必要がある。満たさない場合は `WA` となる。

- `0 <= X`, `0 <= Y`
- `X + Y <= 100 × K`
- 移動と接続は、問題文中に書かれている条件を満たしていること

## 入力生成方法

各ケースはテストケースジェネレータによって生成される。生成手順の概略は以下の通りである。

- `K` は、seed値を4で割った余り + 2 により生成される。
- `N` は、入力の条件を満たすものの中から一様ランダムに生成される。
- `c_{i,j}` は、入力の条件を満たすものの中から一様ランダムに生成される。
