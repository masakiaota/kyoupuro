## 解法の全体像

部分的な縦横切断で盤面を詰め、切断できなかったときにランダムな1マス色変更で形を崩す。突出した細い部分をならすフィルタを定期的に挟み、最後に色0へ消せる外周セルを消す。妥当性はBFSによる各色連結性と、初期隣接集合との一致で判定している。

## 主要アイデア

- まず正しい提出を判定する関数を作る。各色連結性と隣接関係一致を `O(N^2)` で見る。
- 縦または横に切断し、片側を詰めることで空白を外側に作る。
- 行・列全体だけでなく、ランダムな長さの部分切断も試す。
- 1マスだけ飛び出ているような場所は、周囲4マスの最多色へ変えてならす。
- 切断に失敗したとき、ランダムな非0セルを隣接色へ変えて、次の切断が通りやすい形にする。
- 最後は、色0に隣接するセルを0にできるか繰り返し試す。
- 1マスだけの色を隣へ増やす処理も考えたが、最終的には別のランダム色変更で代替している。

## 最終コードの構造

### 状態表現

- `C`: 50x50盤面を一次元化した配列。末尾に外部色0の番兵ノード `NN` を追加する。
- `mapGragh`: 各セルの4近傍グラフ。外周セルは番兵 `NN` と隣接する。
- `g0`: 初期盤面の色隣接集合。
- `minX, maxX, minY, maxY`: 現在の非0領域の概略境界。ランダム切断範囲の制御に使う。
- `dx, dy, dyx`: 近傍方向の補助配列。

### 観測・制約・入力の扱い

- `get_gragh(C)` で、現在盤面の色隣接集合を作る。外部0との隣接も番兵経由で扱う。
- `check_chain(C)` で、各非0色が複数成分に割れていないかをBFSで調べる。
- 色0の連結性はコード上では厳密BFSを省いているが、外側から詰めて0を作る操作に寄せることで破綻しにくくしている。
- 候補操作後は `check_chain` と `get_gragh(C) == g0` を確認し、違反ならロールバックする。

### 評価関数

- スコアは色0セル数 `E + 1` だが、探索中に明示的な評価値比較はあまり使わない。
- 切断や外周削りは空白を増やす操作なので、妥当なら採用する。
- ランダム色変更とならしは、後続の切断成功率を上げるための補助操作である。

### 探索・構築・更新

- 初期に `reshape(C, 5)` で突出部を強めにならす。
- 1.7秒まで、ランダムな垂直切断と水平切断を繰り返す。
- `map_sliceV` と `map_sliceH` は、ランダムに選んだ区間だけを片側へ詰め、外側に0を入れる。
- 切断候補が妥当なら採用し、妥当でなければ復元して `change_color2` を呼ぶ。
- 100ループごとに時間確認と `reshape(C, 1)` を行う。500ループ時に非0領域境界を更新する。
- 最後に `remove_color(C)` で、0に隣接したセルを0へ変えられる限り削る。

### 操作・クエリ・出力選択

- 最終的な `C` を50行に戻して出力する。
- 途中の候補操作は出力せず、妥当な盤面だけが状態に残る。

### 時間配分・パラメータ

- 切断フェーズは1.7秒で打ち切り、最後の0削りに時間を残す。
- 初期ならしは5回、以後100ループごとに1回行う。
- ランダム切断の区間端は `minN = -N*0.5`, `maxN = N*1.5` を使って広めに生成し、盤面内に丸める。
- 提出はPyPy3で、実行時間は約1.86秒である。

## 実装上重要な断片

```text
try_slice_vertical():
    choose x, y1, y2
    save C
    shift interval [y1, y2) at column x toward nearer outside
    if connected(C) and adjacency(C) == g0:
        keep
    else:
        restore
        random_neighbor_repaint()
```

```text
remove_color():
    while changed:
        for each zero cell near active area:
            for each nonzero neighbor:
                set neighbor to 0
                if connected and adjacency unchanged:
                    keep
                else:
                    rollback
```

## この解法の本質

この解法の本質は、行列方向の切断を「全体」ではなく「部分区間」に広げたことにある。全行・全列が削れない局面でも、局所的に詰めることで外側の0を増やし、盤面全体を徐々に縮められる。切断が失敗したときだけランダム色変更を行うため、探索の主目的がぶれにくい。

## 真似するならまず実装する部分

最初に `get_graph` と `check_chain` を作り、列全体または行全体の切断を実装する。次に部分区間切断へ拡張する。`reshape` と `remove_color` は補助改善だが、比較的独立しているため後から追加しやすい。

## 注意点・未理解点

- 提出コードの `reshape` は連結性チェックを省き、隣接関係だけで戻すように見える箇所がある。なぜ安全に動いているかは操作の性質に依存している可能性がある。
- `check_chain` では色0の厳密な連結判定がコメントアウトされている。外側から0を作る操作が中心なので成立していると見られるが、任意の0生成を許す実装では危険である。
- `minX/maxX/minY/maxY` の更新は一部タイミングのみなので、探索範囲制御は近似的である。
- 記事中の「1マスだけの色を隣に増やす」処理は最終提出では使っていない。
