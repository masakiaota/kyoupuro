## 解法の全体像

1マスまたは複数マスを隣接色へ変える焼きなましで、色0セル数を直接増やす。高試行回数を出すために、重いBFS連結判定を避け、局所的な「曲率の離散類似」で連結性を判定する。延長戦では十字型の2マス同時変更、連鎖、回転を近傍に入れ、隣接する異色2マスの候補集合を管理して受理率を上げている。

## 主要アイデア

- 基本近傍は、1点を隣接マスの色で塗ること。
- 1点変更だけでは動けない形に対して、十字で2マスを同時に動かす近傍を使う。
- 評価関数は生スコアを中心にし、コンテスト中は境界長や各色サイズの二乗和をタイブレークに使った。
- 焼きなましの悪化受理を使い、局所解から抜ける。
- 連結判定は、タイル境界の曲がり方を数える局所量で近似・高速化する。
- 1点更新なら周囲4頂点だけを再計算すればよく、3x3パターンをキーに差分値を前計算できる。
- 延長戦では、穴が1つの場合だけ個別対応し、局所判定をより実用的にした。
- 受理率改善のため、異色隣接セルの集合を持ち、意味のある候補を選ぶ。

## 最終コードの構造

Browserで読めた提出 `46961779` と記事本文を合わせた実装構造を書く。

### 状態表現

- `grid`: 現在盤面。
- `score`: 色0セル数に基づく生スコア。
- `adj_count` または隣接関係集合: 隣接関係が壊れていないかを判定する。
- `curvature[color]`: 色ごとの曲率類似量。連結性や穴数の不変性を局所的に見る。
- `candidate_edges`: 色が異なる隣接セルペアの集合。延長戦で受理率改善に使う。
- `area[color]` や `boundary_len`: タイブレーク評価に使う補助値。

### 観測・制約・入力の扱い

- 初期盤面から要求される隣接関係を持つ。
- 1点更新では、変更セル周辺の隣接関係と曲率値だけを差分更新する。
- 曲率類似量は、タイル境界をたどったときの曲がり方を数える発想で、オイラー標数に対応する。
- 穴数が変わらないなら連結性判定に使えるが、局所量だけでは認識できない穴形状があるため、穴が少ないという入力性質に合わせて個別対応している。

### 評価関数

- 延長戦の評価関数は生スコア、つまり色0セル数の最大化である。
- コンテスト中は、生スコアが同じ場合に境界線長の和や各タイルサイズの二乗和でタイブレークした。
- 境界線が短く、色サイズが均されている状態の方が、さらに小さくしやすいという仮説に基づく。

### 探索・構築・更新

- コンテスト中は焼きなましもどきで、悪化を固定確率で受理し、その確率を徐々に下げた。
- 延長戦では通常の焼きなましへ変更した。
- 近傍は、1点隣接色変更、十字2マス同時変更、連鎖、十字回転である。
- 変更候補の周囲だけ、曲率、隣接関係、スコアを差分更新する。
- 異色隣接ペアの集合から候補を取ることで、同色変更など無駄な試行を減らす。

### 操作・クエリ・出力選択

- 最終的に最良盤面を出力する。
- 途中では不変条件を壊す変更をrejectし、焼きなましの採択に通った変更だけ反映する。

### 時間配分・パラメータ

- コンテスト中の悪化受理は、50%から始め、25,000イテレーションごとに0.1%ずつ下げる簡易方式である。
- タイブレークは10,000回ごとに切り替えていた。
- 延長戦では40Mから50M回程度試行し、4M回程度受理している。
- 短時間実行を複数回する方向に変えると100点程度伸びたとされる。
- Clang C++23への変更でも25点程度伸びたと記載されている。

## 実装上重要な断片

```text
local_connectivity_ok(p):
    before = curvature around vertices adjacent to p
    apply candidate change virtually
    after = recomputed local curvature
    return color invariants and handled-hole cases remain valid
```

```text
anneal_step():
    move = choose from adjacent different-color pairs
    diff = score_after(move) - score
    if diff >= 0 or random() < exp(diff / temperature):
        if local validity checks pass:
            commit move and update candidate set
```

## この解法の本質

この解法の本質は、AHC024のボトルネックである連結性判定を大域BFSから局所量へ置き換え、試行回数を桁違いに増やす点にある。1マス変更だけでは地形が動かない局面があるため、2マス同時変更や回転も必要になる。強い近傍と高速判定の両方がそろって初めて、焼きなましが機能する。

## 真似するならまず実装する部分

最初から曲率判定を完全再現するのは難しい。まずは全盤面判定付きの1マス隣接色変更を作り、次に2マス同時変更を入れる。その後、3x3または5x5の局所関節点判定、さらに曲率類似量へ進むのがよい。
