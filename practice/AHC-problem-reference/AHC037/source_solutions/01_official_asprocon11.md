## 解法の全体像

原点から点を伸ばすのではなく、作りたい点を葉として後ろからマージする問題として見る。2点 `p, q` を一つの中間点 `r=(min(p.x,q.x), min(p.y,q.y))` にまとめると、前向きには `r` から `p` と `q` を作る分岐になる。このマージを繰り返すことで、原点を根、入力点を葉とする木が得られる。

基本方針は、マージするペアの選び方を改善していく流れである。最初は距離の近いペアを選ぶ貪欲、次に原点から遠い中間点を優先する強い貪欲、さらにペア選択列をビームサーチで探索する。最上位方針としては、解を全二分木で表現し、部分木の移動や回転を近傍にした焼きなましを行う。

## 主要アイデア

- 前向き構築を後ろ向きマージに変換する。
- 2点 `p, q` のマージ点は `r=(min(p.x,q.x), min(p.y,q.y))` と考える。
- 近いペアからマージするだけだと局所クラスタが残り、終盤に高コストな接続が出る。
- 強い貪欲では `min(p.x,q.x)+min(p.y,q.y)` が大きいペア、つまり原点から遠い中間点を優先する。
- ビームサーチでは、次にマージするペア候補を絞りながら複数状態を残す。
- 焼きなましでは、解を全二分木にして、木構造の変更を直接探索する。
- 入力点が途中の分岐点にもなる場合は、同じ座標の別頂点として二分木上に複製してよい。

## 最終コードの構造

### 状態表現

- 貪欲・ビームでは、まだマージされていない有効点集合を持つ。
- 各マージで、2つの有効点を削除し、`min` 座標の新点を追加する。
- 出力用には、マージ時に作る辺 `r -> p`, `r -> q` を記録し、最後に逆順で出力する。
- 焼きなましでは、入力点を葉、中間点を内部ノードとする全二分木を持つ。
- 各内部ノードの座標は、子2つの座標の `min` として再計算できる。

### 観測・制約・入力の扱い

- 入力点は `N=1000` 固定で、`A` と `B` はそれぞれ相異なる。
- `A=0` の点と `B=0` の点が存在するため、すべての葉をマージした根の座標は `(0,0)` になる。
- 出力操作数は最大 `5N` だが、二分木なら辺数は高々 `2N-2` 程度なので余裕がある。

### 評価関数

- 真の目的は前向き操作の総コスト `C` を最小化すること。
- 二分木表現では、内部ノードごとに子2点間のマンハッタン距離を足せば木のコストになる。
- 強い貪欲の優先値は、距離から導出すると `-2 * (min(p.x,q.x)+min(p.y,q.y))` と同値で、`min` 座標が原点から遠いペアほど得になる。

### 探索・構築・更新

- 貪欲法1:
  - 有効点集合からマンハッタン距離が小さいペアを選ぶ。
  - クラスタ間マージが高くなりやすく、スコアは伸びない。
- 貪欲法2:
  - `min(p.x,q.x)+min(p.y,q.y)` が大きいペアを選ぶ。
  - 右上側から順に分岐をまとめる形になり、強いベースラインになる。
- ビームサーチ:
  - 深さはマージ回数 `N-1`。
  - 各状態から良さそうなペアだけを展開し、上位状態を残す。
  - ペア候補が `O(N^2)` なので枝刈りが必要である。
- 焼きなまし:
  - 木の辺を消して別の場所につなぐ。
  - 部分木を切り離して別の親へ移す。
  - 木回転で局所的な親子関係を変える。
  - 変更後、影響のある祖先だけを再計算する。

### 操作・クエリ・出力選択

- 後ろ向きマージで記録した `r -> p`, `r -> q` を逆順に出す。
- 同じ座標の辺や `(0,0)->(0,0)` は出力しない、または出しても有効性に注意する。
- すべての入力点が最終的にどこかの出力先になる必要がある。

### 時間配分・パラメータ

- PDFでは具体的なビーム幅や温度は示されていない。
- 焼きなましは差分計算を詰めると約400万回程度回せるという説明がある。

```text
merge(p, q):
    r = (min(p.x, q.x), min(p.y, q.y))
    record edge r -> p if r != p
    record edge r -> q if r != q
    active.remove(p)
    active.remove(q)
    active.add(r)
```

## この解法の本質

この問題は、前から見ると「どこに分岐点を置くか」が難しい。一方で後ろから見ると、2つの製品をどの中間点まで共通化するか、つまりペアをどうマージするかに変わる。マンハッタン距離かつ右上方向にしか進まない制約により、2点を共通化する最も得な中間点が `min` 座標で一意に決まる点が強い。

強い貪欲が効く理由は、遠い場所でまとめられる処理ほどコスト削減量が大きいからである。近さだけを優先すると小さいクラスタを作るが、原点側へ戻る大きな接続を後で払うことになる。右上側からマージすることで、大きな共通部分を先に確保できる。

二分木焼きなましの本質は、中間点集合と接続関係を別々にいじらず、木構造だけに探索対象を押し込む点である。木の形が決まれば中間点座標とコストは決まるため、状態空間を整理しやすい。

## 真似するならまず実装する部分

まずは強い貪欲を実装するのがよい。有効点集合、ペア優先度、マージ記録、逆順出力だけで高いスコアに届く。次に、候補を上位に絞ったビームサーチに拡張する。

焼きなましへ進む場合は、いきなり最適化せず、二分木状態、親子リンク、内部ノード座標の再計算、出力復元を先に作る。その後で、部分木移動と木回転を近傍として足す。
