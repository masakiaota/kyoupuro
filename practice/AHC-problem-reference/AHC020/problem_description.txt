# A - Broadcasting

実行時間制限: 2 sec / メモリ制限: 1024 MiB

## ストーリー

AtCoder社は、最新情報の提供や視聴者との交流を目的とした公式生放送「あーだこーだー」をインターネット上で定期的に配信している。より多くの視聴者に生放送を観てもらいたいと考えた高橋社長は、テレビ用の放送網を構築してAA市の全住民に生放送を配信することにした。

AA市のテレビ配信網は放送局を頂点、放送局間の通信ケーブルを辺とした重み付き平面無向グラフで表現され、座標 (x_1, y_1) = (0, 0) に存在する放送局 1 にはAtCoderオフィスが併設されている。各通信ケーブルは電源の ON/OFF を設定可能であり、電源が ON である通信ケーブルのみを経由して放送局 1 から到達できる各放送局からは放送用電波を発信することが可能となる。放送用電波の出力強度は各放送局ごとに調整可能であり、出力強度によって生放送を配信可能となる領域が変化する。

通信ケーブルの使用および放送用電波の発信にはコストがかかるため、できるだけコストを抑えつつ、全ての住民に生放送を配信できるような放送網を構築して欲しい。

## 問題文

N 頂点 M 辺の重み付き平面無向グラフ G が与えられる。頂点 i の座標は (x_i, y_i) であり、辺 j は頂点 u_j と v_j を結ぶ重み w_j の辺である。頂点 u_j と頂点 v_j 間のユークリッド距離を四捨五入したものを D_j=round(sqrt{(x_{u_j}-x_{v_j})^2+(y_{u_j}-y_{v_j})^2}) とすると、重み w_j は 100D_j<= w_j<= 2500D_j を満たす。また住民の座標が K 個与えられ、住民 k の座標は (a_k, b_k) である。

各辺について電源の ON/OFF を、各頂点 i=1,2,...,N について整数値の 出力強度 P_i (0<= P_i<= 5000) を設定せよ。 このとき、以下のようにして生放送が配信される。 電源が ON である辺の集合を E' とする。E' に含まれない辺を G から削除した部分グラフ G' を考え、 G' において頂点 1 と同一連結成分に含まれる頂点集合を V' とする。 各 i in V' について、座標 (x_i, y_i) を中心とした半径 P_i の円形領域内(円周上を含む)に存在する住民が生放送を視聴可能となる。

辺 j の電源を ON に設定すると、コスト w_j が発生する。 また頂点 i の出力強度を P_i に設定すると、コスト P_i^2 が発生する。 i not in V' である i について P_i を正の値に設定してもよいが、生放送視聴可能な領域は発生せずコストのみが発生する。 全ての住民に生放送を配信しつつコストの総和 S=sum_{i=1}^N{P_i^2}+sum_{j in E'} w_j ができるだけ小さくなるような放送網を構築せよ。

## 得点

生放送が視聴可能となった住民の数を n 人としたとき、以下の得点が得られる。

- n< K の場合、 round(10^6 × (n+1)/K)
- n=K の場合、 round(10^6×(1+10^8/(S+10^7)))

S が32bit整数型に収まらない場合がある ことに注意せよ。

## 入力

入力は以下の形式で標準入力から与えられる。

```text
N M K
x_1 y_1
...
x_N y_N
u_1 v_1 w_1
...
u_M v_M w_M
a_1 b_1
...
a_K b_K
```

- N=100
- 100<= M <= 300
- 2000<= K<= 5000
- -10^4<= x_i, y_i, a_k, b_k<= 10^4
- 1<= u_j, v_j<= N
- 1<= w_j<= 10^8
- (x_1, y_1)=(0,0)
- (x_i, y_i)!= (x_{i'}, y_{i'}) (i!= i')
- (a_k, b_k)!= (a_{k'}, b_{k'}) (k!= k')
- (x_i, y_i)!= (a_k, b_k)
- 入力はすべて整数
- 与えられるグラフは連結な平面単純無向グラフである。
- 全ての (a_k, b_k) について、少なくとも1つの (x_i, y_i) とのユークリッド距離が 5000 以下であることが保証される。

## 出力

辺 j の電源がONである場合は 1 、OFFである場合は 0 とした整数を B_j とするとき、以下の形式で標準出力に出力せよ。

```text
P_1 ... P_N
B_1 ... B_M
```

出力は以下の制約を全て満たす必要がある。満たさない場合はWAと判定される。

- 0<= P_i <= 5000
- B_j in { 0, 1 }
- 出力は全て整数

## 入力生成方法

### グラフ G の生成

- (x_1, y_1) = (0, 0) とする。
- 2<= i <= N について、x_i=rand(-10000, 10000) と y_i=rand(-10000, 10000) を生成する。ただし、既に生成した (x_{i'},y_{i'}) のうちいずれかとのユークリッド距離が 1000 未満であった場合は (x_i,y_i) の生成をやり直す。
- 頂点集合に対してドロネー三角形分割を計算し、三角形分割の辺集合を E とする。
- 各辺 j=1,2,...,|E| に対して、頂点 u_j, v_j 間のユークリッド距離を四捨五入したものを D_j=round(sqrt{(x_{u_j}-x_{v_j})^2+(y_{u_j}-y_{v_j})^2}) として、重み w_j を round((randf(10, 50)) ^ 2 × D_j) により求める。

### (a_k, b_k) の生成

- K=rand(2000, 5000) とする。
- 集落の中心地の個数を表す整数 R=rand(20, 40) を生成する。
- 1<= r <= R について、集落の中心地を表す座標 (c_r, d_r) を c_r = rand(-8000, 8000) および d_r = rand(-8000, 8000) により生成する。ただし、既に生成した (c_{r'}, d_{r'}) のうちいずれかとのユークリッド距離が 2000 未満であった場合は (c_r, d_r) の生成をやり直す。
- 1<= r <= R について、集落の広がりを表す実数 sigma _r を sigma_r = randf(200, 1000) により生成する。
- 1<= k <= K について、以下の手順により (a_k, b_k) を生成する。
- 基準とする集落の番号 r_k=rand(1, R) を生成する。
- 住民の家の座標 (a_k, b_k) を a_k = round(norm(c_{r_k}, sigma_{r_k}^2)) および b_k = round(norm(d_{r_k}, sigma_{r_k}^2)) により生成する。ただし、 -10000<= a_k, b_k<= 10000 を満たさない場合および既に生成した (x_i, y_i) または (a_{k'}, b_{k'}) のうちいずれかの座標と一致した場合は (a_k, b_k) の生成をやり直す。

入力生成後、全ての (x_i, y_i) とのユークリッド距離が 5000 より大きい (a_k, b_k) が一つ以上存在する場合は G の生成から再度やり直す。
