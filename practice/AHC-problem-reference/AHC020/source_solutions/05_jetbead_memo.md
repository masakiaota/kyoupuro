## 解法の全体像

AHC020を、施設配置、集合被覆、シュタイナー木が複合した問題として整理している。大きくは、出力強度を状態として探索して使う放送局を接続する方針と、使う放送局集合を探索して出力を貪欲に決める方針がある。記事では、部分破壊再構築、距離境界だけを見る近傍、近似スコアによる高速化、住民クラスタリング、整数二乗距離判定など、複数上位解法に共通する実装要素を横断してまとめている。

## 主要アイデア

- 問題は「どの放送局で住民を覆うか」と「使う放送局をどう根へ接続するか」の複合最適化である。
- 住民は正規分布的に生成されるので、集落のかたまりを利用できる。
- 出力強度コストは二乗なので、少数の大円より複数の中円が有利になる場合がある。
- 使う放送局集合が決まれば、辺選択は最小シュタイナー木問題になる。
- 厳密シュタイナー木は重いので、Prim ヒューリスティックや MST 近似で代用することが多い。
- 出力強度を適当に変えるとカバー集合が変わらない無駄な近傍が多いため、住民をちょうど覆う境界だけを見るとよい。
- 部分破壊再構築近傍が有効である。例として、ある放送局の強度を 0 にし、未カバーになった家を最小コスト貪欲で修復する。
- 探索初期は近似スコアやクラスタリングで粗く動かし、最後に厳密評価へ寄せる方針がある。
- カバー判定は強度と距離を二乗した整数で行い、小数誤差を避ける。

## 最終コードの構造

ページ本体に単一の最終コードはない。リンク先の FakePsyho のコードは、記事の「使う放送局を探索＋強度を乱択greedy」に近い具体例として読める。

### 状態表現

- 横断メモとしては、主に次のどちらかの状態を取る。
- 強度探索型:
  - `P[i]`: 各放送局の出力。
  - `cover_count[k]`: 各住民の被カバー数。
  - `active[i]`: `P[i] > 0` の放送局。
- 使う放送局探索型:
  - `use[i]`: 放送局 `i` を候補として使うか。
  - `P[i]`: `use` のもとで貪欲修復した出力。
  - `B[e]`: MST/シュタイナー木近似で選んだ辺。
- FakePsyho コードでは、`kclosest[k]` に各住民の近い放送局候補、`vclosest[i]` に放送局から近い住民候補、`power` に出力、`need` にMST対象頂点を持つ。

### 観測・制約・入力の扱い

- 放送局と住民の距離は二乗で持つ。
- 距離 5000 を超えるペアはカバー候補から外せる。
- N=100 と小さいため、全点対最短路や MST/Prim を反復で使う設計が可能である。
- グラフの接続は厳密シュタイナー木にすると難しいため、多くの解法では近似を使う。
- 使わない放送局を木から除く際も、根 1 との連結性は必須である。

### 評価関数

- 基本は `S = sum(P_i^2) + edge_cost`。
- 近似スコアとして、MST コストを根からの最小距離や全体MSTの親辺コストで代用する案がある。
- 未カバーを許す場合は、未カバー人数にペナルティを加える Prize-collecting Steiner Tree 的な見方もできる。
- FakePsyho コードでは、候補住民を覆う追加コストを `distance^2 - power[v]^2 + empty_penalty[v]` のように優先度付きキューで扱っている。

### 探索・構築・更新

- 強度探索型:
  - ある放送局の強度を増減する。
  - カバーされない住民が出ないよう、距離順リストと被カバー数で判定する。
  - ある放送局を 0 にして未カバー住民を貪欲修復する部分破壊再構築が有効である。
- 使う放送局探索型:
  - 使う頂点集合を変える。
  - 各住民を最小追加コストの放送局でカバーする貪欲を回す。
  - MST または Prim ヒューリスティックで辺を構築する。
- FakePsyho コード:
  - `find_kclosest(10)` で各住民の近い10放送局だけを候補にする。
  - `kgreedy` で未カバー住民を優先度付きキューから取り、出力を引き上げる。
  - hill climbing で正出力の放送局を1つ選び、出力を 0 またはランダムな低値へ落としてから `kgreedy` で修復する。
  - MST 後、出力 0 の頂点を削除/追加して辺コストが下がるなら採用する。
  - 改善したときだけ採用する山登りで、記事によると 200 から 800 step 程度しか回らない。
- qLethon HackMD:
  - 使う頂点集合 `Z` を焼きなましで持つ案。
  - `Z` をターミナルにしたシュタイナー木を作り、木上で家に近い頂点を選び、出力を決め直してから `P=0` 頂点を省いて再接続する案が書かれていた。

### 操作・クエリ・出力選択

- 最終的には全住民が少なくとも1つの有効放送局円に入り、正出力放送局が頂点 1 と ON 辺で連結している必要がある。
- 強度探索型でも使う放送局探索型でも、最後に `P` と `B` を明示的に構築する。
- MST 近似やクラスタリングを使った場合、最後に元の住民と実辺で検証する必要がある。

### 時間配分・パラメータ

- upsolveメモでは、強度焼きなまし、部分破壊再構築、ベスト解保持、Prim ヒューリスティック、アクティブ集合変化時だけの木計算で 501M 程度とされている。
- クラスタリングや近似スコアは探索初期の高速化に向く。
- FakePsyho コードは 1.9 秒制限で、各住民の近い放送局候補数を 10 にしている。
- qLethon HackMDには k-means や使う放送局集合 SA の試行ログがあるが、最終提出コードとして整理されたものではない。

## 実装上重要な断片

```text
destroy_rebuild(P):
    choose station i
    P[i] = 0
    uncovered = residents no longer covered
    for k in shuffled(uncovered):
        choose station minimizing new_P^2 - old_P^2
        raise that station
```

```text
kgreedy_like():
    initialize pq with uncovered residents and candidate stations
    while pq not empty:
        take smallest additional cost
        if resident already covered:
            continue
        raise selected station to cover resident
        push residents newly affected by this station
```

```text
mst_with_zero_node_pruning():
    build MST/Prim tree for candidate nodes
    repeat:
        try removing zero-power node
        keep removal if edge cost does not increase and connectivity remains
```

## この解法の本質

このメモの本質は、AHC020を一つの魔法の解法ではなく、複数の部分問題の組み合わせとして見る点にある。出力強度、住民割当、使う放送局、接続木は相互に影響するが、全部を同時に厳密最適化するのは難しい。そのため、片方を貪欲や近似で解き、もう片方を局所探索する設計が現実的になる。部分破壊再構築が有効なのは、カバー集合が離散的に変わるため、少しずつ動かすだけでは谷を越えにくいからである。

## 真似するならまず実装する部分

まずは「ある放送局を 0 にして、未カバー住民を最小追加コストで貪欲修復する」部分破壊再構築を実装するのがよい。辺は最初は Prim 風近似で十分だ。次に、距離順リスト、被カバー数、候補住民の枝刈りを入れて高速化する。上位化を狙うなら、木コストの近似評価、住民クラスタリング、未カバー許容ペナルティを順に試す。
