## 問題の本質

この問題は、確率的な二分岐装置を平面上の交差しない DAG として配置し、各ごみ種類が対応する処理装置へ到達する確率を最大化する問題である。

解法視点では、難しさは2つに分かれる。1つ目は、出力が有効な平面 DAG でなければならない点である。交差、閉路、未設置分別器への参照のどれか1つでも壊れると失敗する。2つ目は、同じ有効グラフでも、分別器種類、出口反転、接続先、処理装置割り当てによって確率が大きく変わる点である。

したがって、上位解法はどれも「有効なグラフをどう作るか」と「固定または準固定グラフ上で確率をどう高速評価するか」を分けている。前者は TSP パス、トポロジカル順序固定、分別器追加ビーム、凸包アセンブリ、Delaunay 二分木などに分かれる。後者は、前向き到達確率と後ろ向き成功確率による DP が共通の武器になる。

## 共通している考え方

- まず有効な出力を作る。スコア改善より先に、交差なし、閉路なし、到達先整合を満たす骨格が必要である。
- 確率評価は DP で行う。処理装置から逆向きに「この頂点へ来たごみが正しく処理される確率」を持つと、分別器種類変更の評価がしやすい。
- 出口反転は重要である。`p` が小さい分別器も、出口を入れ替えれば `1-p` の分別器として使える。
- グラフ固定後の分別器種類割り当ては、貪欲や山登りだけでも大きく効く。
- 処理装置割り当ては単なる出力順ではなく、探索対象である。処理装置位置とごみ種類の対応を変えるだけでスコアが動く。
- 平面制約を毎回ゼロから判定すると重いので、候補辺制限、AABB、Delaunay、凸包領域、トポロジカル順序などで探索空間を構造化する。

## 解法の分類

- 高速差分 SA 型: eijirou、rhoo
- トポロジカル順序固定型: rhoo、eijirouの一部
- 有効遷移追加型: ymatsux
- 幾何データ構造重視型: ymatsux
- 部品化構築型: terry_u16
- 平面候補グラフ型: uta_ccc
- 段階最適化型: uta_ccc、terry_u16
- 分別器種類・処理装置割り当て最適化型: 全参照元に共通

## 推奨して理解すべき順序

1. まず uta_ccc を読み、DAG、二分木、固定木上の確率 DP、分別器種類調整の流れを理解する。
2. 次に eijirou を読み、`fdp/bdp` による差分評価がなぜ効くかを理解する。
3. rhoo を読み、トポロジカル順序固定と候補辺前処理で探索を実用化する考え方を確認する。
4. ymatsux を読み、自由度の高いグラフ追加を高速に扱うための幾何データ構造を理解する。
5. terry_u16 を読み、一般グラフ探索とは別方向の「強い分別部品を組む」発想を確認する。

## 実装するならどのルートか

理解のための最小実装は、Delaunay または近傍点接続で非交差候補グラフを作り、入口根の二分木を構築し、後ろ向き DP で分別器種類を貪欲に選ぶルートである。これは uta_ccc 型に近く、まず有効出力と確率計算を確認しやすい。

スコアを伸ばすなら、eijirou/rhoo 型の `fdp/bdp` 差分を入れて、分別器種類変更、出口 swap、処理装置割り当て swap を焼きなましするのがよい。次に、接続先変更を追加する。接続先変更は交差・閉路バグの温床なので、候補辺をトポロジカル順序や幾何候補で絞ってから入れる。

さらに上位を狙うなら、ymatsux のような既存辺への分別器挿入ビーム、または terry_u16 のような分別アセンブリ構築へ進む。ただしどちらも実装量が大きく、最初の再現対象には向かない。

## 重要な実装要素

- 状態表現:
  - 使用分別器、分別器種類、2出口、処理装置割り当て、入口行き先。
  - トポロジカル順序、親子、または候補グラフ。
  - `fdp[v][g]` と `bdp[v][g]`。
- 評価関数:
  - 基本は `sum_g q_g` の最大化。
  - 低確率段階では `log` 評価や近似評価を使う方針もある。
  - 木構造探索では、正確 DP の代わりに軽い代理評価を使うことがある。
- 近傍:
  - 分別器種類変更。
  - 出口1・出口2 swap。
  - 接続先変更。
  - 処理装置割り当て swap。
  - 既存辺への分別器挿入。
  - 木の切断・再接続。
- 差分更新:
  - 単一分別器変更は `fdp[v][g] * changed_success[g]` で `O(N)`。
  - 接続先変更は影響範囲の前向き・後ろ向き DP 更新が必要。
  - 差分が怪しい場合は、まず全再計算で検証する。
- 候補管理:
  - 交差しない候補辺。
  - トポロジカル順序上の後方候補。
  - その頂点に来やすいごみに対する分別器種類候補。
  - 未使用分別器のうち空間的に余裕のある候補。
- 出力判定:
  - 未使用分別器は `-1`。
  - 分別器への参照先は必ず設置済み。
  - 辺は閉路なし。
  - 無関係な線分同士は交差なし。
  - 処理装置割り当ては `0..N-1` の順列。
- パラメータ:
  - 焼きなまし温度、近傍比率、候補辺幅、ビーム幅、時間配分。
  - Delaunay/近傍候補数、AABB 葉サイズ、分別器候補数。

## 落とし穴

- 端点共有の交差判定を誤ると、有効な辺を落とすか、無効な交差を通してしまう。
- トポロジカル順序を固定していても、処理装置や入口を含めた順序の扱いを誤ると閉路が出る。
- 分別器種類を変えた後に `fdp` や `bdp` を更新し忘れると、探索が存在しないスコアを最適化する。
- 処理装置配置を固定すると、どれだけ分別器を調整しても上限が低くなる場合がある。
- 出口反転を忘れると、`p` が0.1や0.9に寄った強い分別器を半分しか使えない。
- グラフを大きく使うほど確率分離の機会は増えるが、処理装置へ到達するまでの誤分類・漏れも増える。
- 近似評価だけで木構造を焼くと、最終の正確スコアとずれる。
- AABB 木や可視グラフのヒューリスティックは高速だが、最終検査を省くとWAの原因になる。
