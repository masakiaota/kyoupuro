## 問題の本質

この問題は、指定目的地を順に訪れる経路を作るだけではなく、その経路を少ない `C+Q` の状態遷移機械として表現する問題である。経路長は `T` 以内であればスコアに直接入らないため、最短路よりも「同じ規則をどれだけ再利用できるか」が重要になる。

解法視点では、各ステップを個別の `(色, 状態)` に割り当てると `2sqrt(X)` 前後の団子解に落ち着く。そこから抜けるには、長い直進、同じ方向、同じ交互移動、同じ固定パターン、反射などを盤面や状態の共通ルールへ押し出し、個別割当が必要な不規則ステップ数を減らす必要がある。

## 共通している考え方

- 経路構築と規則割当を分ける。
- 経路は最短でなくてよく、`T` 以内なら規則再利用しやすい遠回りが有利になる。
- 後ろから見ると、各マスの「以後の規則的な挙動」が確定しやすい。
- 色0または固定色を、直進・方向固定・交互移動などの共通規則に割り当てる。
- 個別規則が必要なステップ数 `x` を減らしてから、`C ≈ Q ≈ sqrt(x)` に詰める。
- 規則割当は後ろから行うと、次に必要な `(A,S,D)` が分かるため再利用判定しやすい。
- 同じ `(A,S,D)`、同じ `(A,S)`、または同じ状態写像を見つけて `(c,q)` を再利用する。

## 実装するならどのルートか

理解のための最小実装は、公式解説の4固定色モードがよい。固定色なしの団子解を作り、次に4方向固定色を入れて、不規則ステップだけを後ろから `C ≈ sqrt(x)` で割り当てる。

スコアを伸ばすなら、tetra型の色0氷床を入れる。各マスの最後の方向転換後を色0直進にし、経路コストに最後の方向転換位置を入れる。規則割当は最初は貪欲でよく、動いた後にビームサーチ化する。

最上位化を目指すなら、oimo_shr型の反射板と状態圧縮が必要になる。ただし、反射板写像と色・状態マージ条件が難しいため、氷床のみで経路構築と後ろ割当を安定させてから取り組むべきである。

## 重要な実装要素

- 状態表現:
  - 経路ステップ列、訪問セル、移動方向、目的地インデックス。
  - 各マスの固定色、未確定色、最後の方向転換、最後の直進。
  - 不規則ステップ列と、固定色で吸収できるステップ列。
  - 規則表 `(c,q) -> (A,S,D)` と既出 `(A,S,D)` / `(A,S)` の逆引き。
  - 高度圧縮では、ユニーク状態、割当可能状態集合、同色クラス、状態衝突判定。
- 評価関数:
  - `C+Q` の近似として、不規則ステップ数、方向転換セル数、固定色を壊す回数を下げる。
  - `T` 余裕が少ないときは経路長を重くし、余裕が大きいときは固定色維持を優先する。
  - ビーム中は `C+Q` に、`|C-Q|` や未確定色数の減衰ペナルティを足す。
- 近傍:
  - 固定色セルの追加、解除、連続2列/2行の初期化。
  - 氷床化、隣接交換、セル種変更。
  - 目的地区間の破壊再構築。
  - 規則割当での既存規則再利用、新色追加、新状態追加。
  - 状態圧縮での状態swap、混雑状態から空き状態への置換。
- 差分更新:
  - 山登りでは、各区間までの訪問回数と最後の方向転換/直進を差分管理する。
  - ビームでは、Actionに追加規則、色確定、`C/Q`増加、評価値差分を持たせ、rollbackできるようにする。
- 候補管理:
  - `C` は `sqrt(x)` 近傍を全探索する。
  - 新規規則候補は多すぎるため、ランダムサンプリングや再利用優先度で絞る。
  - 固定色や氷床候補は、後ろ側の規則的区間が長いマスを優先する。
- 出力判定:
  - シミュレーション中に未定義 `(c,q)` を読まない。
  - 同じ `(c,q)` を複数回出力しない。
  - 壁方向へ永遠に直進する固定規則を作らない。
  - 目的地が氷上や固定経路上にある場合も、訪問順として正しく到達する。
- パラメータ:
  - 固定色モード `0/4/8`。
  - `sqrt(x) ± 5` の色数候補。
  - fixed color追加数 `T/1000` 基準、`2..10`。
  - 公式解説の未固定マス閾値5、ランダム初期化5マス。
  - tetraのビーム評価係数、oimo_shrの氷床近傍比率など。

## 落とし穴

- 色0や固定色にしたマスは、以後その色の規則でしか動けない。後で方向転換が必要な訪問を残すと破綻する。
- 壁に向かって直進しても停止できない。通常の氷パズルのように壁で止まると考えるとWAになる。
- 目的地は順番が来た時点で改めて到達する必要がある。固定経路で先に通過しても訪問扱いにならない。
- 目的地が氷床上にあると、進入方向によって次の位置や状態が変わる。
- `T` に余裕があるからといって遠回りしすぎると、固定色維持は良くても全目的地を訪問できなくなる。
- 後ろから規則を割り当てるとき、初回出現ステップと再利用可能ステップの扱いが違う。
- 未確定色を残す遅延割当は強いが、最後に具体色を割り当てられない矛盾を作りやすい。
- 差分更新ビームは、`move_forward` / `move_backward` の漏れがそのまま壊れた規則表につながる。
- 状態圧縮では、色の同一性と状態の衝突制約が絡む。単に同じ方向だからマージできるとは限らない。
