## 解法の全体像

移動経路の決定と遷移規則の割り当てを順に行う。各マスには、ある時点以降は規則的な移動パターンだけが現れるという性質がある。そこで、その「後ろの規則的な部分」に固定色を割り当て、固定色で処理できない前半の不規則ステップだけを後ろから個別に割り当てる。

固定色は 0色、4色、8色の3モードを試す。経路構築では、固定色に沿う移動を安く、固定色を潰す移動を高くしたダイクストラを用い、固定色配置と経路を反復的に改善する。最後に、不規則ステップを後ろから `(c,q)` へ割り当て、同じ `(A,S,D)` の規則を再利用して圧縮する。

## 主要アイデア

- 各マスの後ろ側に現れる規則的移動パターンへ固定色を割り当てる。
- 固定色モードは `0`, `4`, `8` の3種類を試し、最良の `C+Q` を採用する。
- 4色モードは「以後そのマスでは上/下/左/右のみ」に対応する。
- 8色モードは4方向に加え、上下交互・左右交互のような戻りやすいパターンを扱う。
- 後ろから経路を決め、既存固定色を壊さない経路をダイクストラで探す。
- 固定色以外のステップは後ろから `(c,q)` を割り当てる。
- 同じ `(A,S,D)` が既に現れたら、同じ `(c,q)` を再利用する。

## 最終コードの構造

以下は本文から読み取っていた構造である。キャッシュ実装で確認した差分は後述する。

### 状態表現

- 入力:
  - 壁つきグリッド
  - 目的地列
  - `T`
- 固定色配置:
  - 各マスの固定色。未決定のマスもある
  - 固定色モード `0/4/8`
  - 各マスの後ろ側の規則的移動パターン長
- 経路:
  - 目的地間の移動列
  - 各ステップが固定色に沿うか、未固定マスか、固定色を潰すか
- 規則割当:
  - 不規則ステップ列
  - `(c,q) -> (A,S,D)` の規則表
  - 既出 `(A,S,D)` から `(c,q)` への対応
  - `C`, `Q` の候補値

### 観測・制約・入力の扱い

- 壁に従って隣接移動を列挙する。
- 後ろから目的地間経路を決めることで、後ろ側の固定色パターンを先に活用する。
- 経路の長さが `T` を超えないよう、余分ステップの有無に応じてダイクストラ重みを切り替える。
- すべての目的地を訪問できることを前提に、`C+Q` の小さい候補を選ぶ。

### 評価関数

ダイクストラの辺重みは、次の4要素からなる。

- 経路長
- 固定色に沿った移動
- 固定色が未配置のマスでの移動
- 固定色を潰す移動

重みは余裕ステップ量に応じて切り替える。

- 余裕が大きい場合: `(1, 1, 10, 100)`
- 余裕が小さい場合: `(10, 1, 10, 100)`
- それでも `T` 超過なら: `(1000000, 1, 10, 100)`

最終盤面構築中は、各マスの規則的でない部分の長さの総和をスコアとし、焼きなましの基準にする。

### 探索・構築・更新

- 固定色モード `0/4/8` を試す。
- まだ固定色が決まっていないマスのうち、後ろの規則的移動パターンが長いマスから数マスへ固定色を割り当てる。
- その状態で全体経路を再構築し、再び固定色を割り当てる。
- 一度に割り当てる個数は `T/1000` を基準に `2..10` に収める。
- 未固定マス数が一定以下になったら、固定色の一部をランダムに初期化する。
  - 連続する2列または2行を初期化する。
  - 固定色決定済みマスから5マス初期化する。
- 最小スコアを基準に焼きなましを行い、全体で最良の経路を採用する。

### 操作・クエリ・出力選択

- 固定色ステップ:
  - 内部状態を維持する。
  - 後ろから割り当てられた `q` を引き継ぐ。
  - 固定色が表す規則的移動を行う。
- 固定色以外のステップ:
  - 後ろから `(c,q)=(*,Q-1), ..., (*,0)` の順に割り当てる。
  - 同じ `(A,S,D)` が既出なら再利用する。
  - 再利用確率を増やすため、以前の移動方向と `c mod 4` が対応する色を優先する。
- 色数:
  - 割当対象ステップ数を `x` とし、各固定色モードで `sqrt(x) ± 5` を全探索する。
- 状態数:
  - 割当後に使った状態の最小値が0になるよう全体をずらす。

### 時間配分・パラメータ

- 固定色モードは3種類。
- 一度に固定色を追加する個数は `T/1000` 基準、下限2、上限10。
- 未固定マス数の閾値は5。
- ランダム初期化は2列/2行、または5マス。
- 色数候補は `sqrt(x) ± 5`。

## 実装上重要な断片

```text
for mode in [0, 4, 8]:
    initialize fixed_color as undecided
    while time remains:
        assign fixed colors to cells with long regular suffix
        path = rebuild_path_with_dijkstra(fixed_color)
        update regular suffix lengths
        if remaining undecided cells on path <= 5:
            randomly reset fixed colors
        keep best by irregular suffix sum
    assign_rules_from_back(best_path, mode)
```

```text
assign_rules_from_back(path):
    remove / mark fixed-color steps
    choose C around sqrt(number of irregular steps)
    for irregular step from last to first:
        target = (A, S, D)
        if target already used and not first occurrence:
            reuse same (c, q)
        else:
            assign new (c, q), preferring c whose c mod 4 matches previous direction
```

## この解法の本質

この解法は、各マスの「後ろ側の規則性」を固定色として取り出す。ロボットはセル位置を直接知らないが、同じマスを何度も訪れるなら、最後の数回は同じ方向や同じ交互パターンになることがある。その部分を全マス共通の規則へ移せば、個別に割り当てるステップ数 `x` が減る。

さらに、経路構築を固定色配置に合わせてやり直すため、単に後処理で圧縮するよりも固定色に乗りやすい経路を作れる。

## 真似するならまず実装する部分

まず4色固定モードだけを実装する。目的地列の後ろから、固定色を壊す移動に大きいペナルティを置いたダイクストラで経路を作り、後ろの規則的移動が長いマスを固定する。規則割当は、固定色以外のステップを後ろから `C ≈ sqrt(x)` で単純に詰めるところから始めるとよい。

## 実装確認（提出 71036020）

キャッシュ実装は C++ で、まず各目的地間の通常最短手数 `turns_min` をBFSで求める。その後、`MakePathAll(0,200)`, `MakePathAll(4,1200)`, `MakePathAll(8,1900)` の3モードを試し、`C+Q` が最小の解を出す。

経路構築は目的地列を後ろから処理する。固定色配置 `colors_last` があるとき、ダイクストラのコストは長さ、固定色に乗る移動、未固定セル、固定色を壊す移動の重み付き和である。余りターンが十分なら固定色に乗りやすい経路を選び、余裕が少ない場合は長さ重視へ切り替える。

固定色は各マスの後ろ側の方向列から選ぶ。4色モードは最後の同方向連続、8色モードは方向が反転しながら続く列を評価し、長いものから追加する。詰まりすぎたら行・列・ランダムセルの固定色を外して再探索する簡易SAが入る。

規則割当 `AssignRules` は、固定色で処理できない不規則ステップ数 `cnt` から `C ≈ sqrt(cnt)` 周辺を試す。後ろから `(new_color,new_mode,dir)` の再利用を探し、なければ残り色を割り当てる。色選択では前回そのマスで出た方向 `prev_dirs` と `c mod 4` が合う色を優先する。最後に同じ `(color,mode)` の規則をunique化して出力する。

## 注意点・未理解点

- 提出 `71036020` により、時間分割、固定色追加の打ち切り、規則割当は確認できた。
- 8色モードは実装にも入っているが、記事で触れられている見落とし可能性は検証対象として残る。
- 固定色を増やしすぎると経路が `T` を超えるため、ダイクストラ重みの切り替えが重要である。
- 後ろからの規則割当では、最初に現れる不規則ステップだけ再利用条件が例外になる。ここを誤ると未定義規則や違う色読みにつながる。
