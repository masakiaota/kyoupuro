## 解法の全体像

種ごとの評価値と隣接ペアの相性を持つ盤面評価を定義し、その盤面を焼きなましで改善する解法である。良い成分を持つ種を内側へ置くために、マスの内側重みを使う。一方で、同じ強い成分を持つ種同士を隣接させると補完性が低いため、隣接ペアの類似度をペナルティとして引く。盤面内の 36 種と盤面外の 24 種も swap 候補に含め、種の選択と配置を同時に最適化する。

## 主要アイデア

- 種評価は、各次元の現在最大値で正規化した値のべき乗和で作る。
- べき指数はターンが進むほど小さくし、序盤は尖った成分、終盤は総合力を相対的に見る。
- マスに内側重みを持たせ、中心付近に良い種が置かれるほど高評価する。
- 隣接ペアには、同じ次元が強い種同士を隣に置くことへのペナルティを入れる。
- swap 近傍には「盤面内同士」「盤面内と盤面外」の両方を含め、36 種の選択も焼きなましで変える。
- 差分計算で、swap に関係するマスと近傍辺だけを更新する。

## 最終コードの構造

### 状態表現

- `seeds[60][15]`: 現在の種ベクトル。
- `MaxElem[15]`: 各次元の現在最大値。
- `pow_score[60]`: 種単体の評価値。
- `pow_val[60][15]`: 隣接ペナルティ計算用にべき乗・正規化した値。
- `board_arrange[6][6]`: 盤面上の seed id。
- `seed_pos[60]`: 各 seed id の位置。盤面外は `-1`。
- `best_board_arrange`: 焼きなまし中の最良盤面。

### 観測・制約・入力の扱い

- 各ターンで、現在の 60 種から `MaxElem` を計算する。
- `pow_score` と `pow_val` を前計算し、評価で使い回す。
- 初期盤面は先頭 36 種を行優先で置く。
- 出力後に次世代 60 種を読み、次ターンで再び焼きなましを行う。

### 評価関数

種単体評価は概ね次の形である。

```text
seed_score(k, turn):
    p = 5.5 - 0.45 * turn
    return sum_l (MaxElem[l] / 100) * (seeds[k][l] / MaxElem[l])^p
```

盤面評価は、内側重み付きの種評価から隣接ペアの重なりペナルティを引く。

```text
board_score:
    score = sum_cell inner_weight[cell] * seed_score(seed[cell])
    score -= dot_alpha * sum_edge overlap(seed[u], seed[v])
```

コード上の `overlap` は、正規化・べき乗した各次元値の積をさらに指数 `0.8` でならした和である。似た強成分を持つ種同士を隣接させると引かれる。

### 探索・構築・更新

- 焼きなましで 2 つの seed id をランダムに選び、位置を swap する。
- 片方が盤面外なら、盤面上の種と未使用種の入れ替えになる。
- 両方が盤面外なら変化がないためスキップされる。
- 差分評価では、swap される seed の位置とその隣接辺だけを見る。
- 採択は `diff > 0` または `exp(diff / temp)` による確率採択。
- 温度は初期値から反復ごとに減衰する。

### 操作・クエリ・出力選択

- 各ターン、焼きなまし終了時点の最良盤面を出力する。
- 盤面外 seed も swap 候補なので、出力する 36 種の選択も探索に含まれる。
- 最終ターン専用の期待値計算は入っていない。

### 時間配分・パラメータ

- 全体制限約 2 秒をターンごとの累積時刻で分けて使う。
- 代表的な定数は、種評価指数の初期 `5.5`、隣接ペナルティ係数 `0.1`、ペナルティ指数 `0.8`。
- 内側重みは、中心付近が高く外側が低い固定配列から作られる。
- コードでは温度を反復ごとに `0.9993` 倍して下げる。

## 実装上重要な断片

```text
try_swap(seed_a, seed_b):
    affected_cells = positions of seed_a and seed_b if on board
    old = local_cell_scores + local_edge_penalties around affected_cells
    swap positions, allowing board <-> outside
    new = same local scores after swap
    diff = new - old
    accept by SA, otherwise rollback
```

盤面外の seed を `seed_pos = -1` として同じ swap 処理に含めると、選択と配置を一つの近傍で扱える。

## この解法の本質

この解法は、子が「隣接する 2 親の各次元の混合」であることを、補完的な隣接を作る問題として解いている。強い種を中心に置く単体評価と、似た種同士を離すペナルティを同時に持つため、良い成分が多くの辺に散らばる。さらに盤面外との swap を含めることで、選択問題と配置問題を一体で改善できる。

## 真似するならまず実装する部分

まず、内側重み付きの種評価だけで焼きなましを作る。次に、隣接ペアの重なりペナルティを足す。最後に盤面外 seed との swap と差分更新を入れる。差分更新なしの全評価でも小さなテストはできるが、本番の反復数を確保するには局所差分が必要だ。

## 注意点・未理解点

- ペナルティは「似た強成分を避ける」発想だが、強い成分を同じ辺に重ねた方が良い場面もあり、係数調整に依存する。
- 内側重み、指数、温度減衰はチューニング値であり、記事だけから最適性は判断できない。
- 差分計算では、swap する 2 マスが隣接している場合や、同じ近傍辺を二重に数える場合に注意が必要だ。
- コードには途中実験用と思われる単純解法クラスも含まれるが、最終出力は焼きなまし解法を使っている。
