# A - Breed Improvement

実行時間制限: 2 sec / メモリ制限: 1024 MiB

## ストーリー

AtCoder社は、穀物の品種改良に取り組んでいる。穀物は美味しさ、収穫量、病気への耐性など複数の評価項目を持っており、高橋社長は全ての評価項目に優れた穀物を作り上げたいと考えている。

グリッド状の畑に穀物の種を植えると、隣り合ったマスに植えられた2つの種同士の各評価項目の値をランダムに受け継いだ新しい種が1年後に収穫できる。種植えと収穫を何度か繰り返して、できるだけ優れた穀物の種を作り上げて欲しい。

## 問題文

N × N マスのグリッドで表される畑がある。畑の一番左上のマスの座標を (0,0) とし、そこから下方向に i マス、右方向に j マス移動した先のマスの座標を (i,j) とする。

穀物の種が 2N(N-1) 個与えられる。評価項目が M 個存在し、種 k には各評価項目の良さを表す非負整数ベクトル x_k=(x_{k,0}, x_{k,1}, ..., x_{k,M-1}) （以下、評価項目ベクトルと呼ぶ）が定められており、種 k の価値 V_k は V_k=sum_{l=0}^{M-1}x_{k,l} で表される。

以下の操作を T 回繰り返すことで、手持ちの種の価値の最大値 max (V_0, V_1, ..., V_{2N(N-1)-1}) をできるだけ大きくせよ。

- 畑の N^2 個のマスに1つずつ種を植える。同じ種を複数のマスに植えることはできず、植えなかった 2N(N-1)-N^2 個の種は全て破棄される。その後、上下左右に隣接するマスに植えられた種のペア (k, k') について、新たな評価項目ベクトルを持った新しい種が生成される。この評価項目ベクトルの l 番目の要素の値は、もとの種の x_{k,l} および x_{k',l} から等確率でランダムに選ばれる。これによって生成された 2N(N-1) 個の種が新たな手持ちの種となる。

## 得点

最初に与えられる 2N(N-1) 個の種に対して、評価項目ベクトルの l 番目の要素の最大値を X_l=max(x_{0,l}, x_{1, l}, ..., x_{2N(N-1)-1, l}) とする。 T 回の操作終了後の手持ちの種の価値 V_i の最大値を W=max(V_0, V_1, ..., V_{2N(N-1)-1}) としたとき、 round(10^6× W/sum_{l=0}^{M-1}{X_l}) 点が得られる。

一つ以上のケースで不正な出力や制限時間超過をした場合、提出全体の判定がWAやTLEとなる。

## 入出力

※この問題はインタラクティブ形式である。以下の内容を読み、ジャッジプログラムとのやり取りを行うこと。

まずはじめに、標準入力からグリッドの大きさ N、評価項目の数 M、操作回数 T、評価項目ベクトル x_k=(x_{k,0}, x_{k,1}, ..., x_{k,M-1}) が以下の形式で与えられる。

```text
N M T
x_{0,0} ... x_{0,M-1}
...
x_{2N(N-1)-1,0} ... x_{2N(N-1)-1,M-1}
```

ここで、入力は以下の制約を満たす。

- N=6
- M=15
- T=10
- 0<= x_{k,l}<= 100
- 入力は全て整数

上記の情報を読み込んだら、以下の処理を T ターン繰り返す。

各ターンでは、まず各マスにどの種を植えるかについて以下の形式で標準出力へ出力せよ。

```text
A_{0,0} ... A_{0,N-1}
...
A_{N-1,0} ... A_{N-1,N-1}
```

ここで、 A_{i,j} はマス (i,j) に植える種の番号を表し、 0<= A_{i,j} < 2N(N-1) を満たす整数である必要がある。同一ターン内で同じ A_{i,j} を複数回出力してはならない。

出力後、新たに生成された 2N(N-1) 個の種の評価項目ベクトルが以下の形式で標準入力から与えられる。

```text
x_{0,0} ... x_{0,M-1}
...
x_{2N(N-1)-1,0} ... x_{2N(N-1)-1,M-1}
```

ここで、評価項目ベクトルの各要素は 0<= x_{k,l}<= 100 を満たす整数である。

出力の後には改行をし、更に標準出力を flush しなければならない。 そうしない場合、TLEとなる可能性がある。

解答プログラムは、# から始まるコメント行を出力に含めてもよい。ジャッジプログラムはコメント行を全て無視する。

## 入力生成方法

標準正規分布から値を生成する関数を randnormal() と定義する。

各 k=0, 1, ..., 2N(N-1)-1 に対して、以下のようにして x_k=(x_{k,0}, x_{k,1}, ..., x_{k,M-1}) を生成する。

M 次元のベクトル (x_{k,0}',...,x_{k,M-1}') を x_{k,l}'=|randnormal()| により生成する。 p_k=100/sqrt{sum_{l=0}^{M-1}x_{k,l}'^2} として、 x_{k,l}=round(p_kx_{k,l}') とする。
