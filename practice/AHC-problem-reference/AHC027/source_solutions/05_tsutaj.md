## 解法の全体像

左手法で壁沿いを一周する経路を作り、そこから通れていない内部セルを DFS で埋めて初期解にする。その初期解に対して、時間いっぱい焼きなましを行う。焼きなまし近傍は、経路挿入、経路削除と追加、経路削除、経路スワップ、経路移動、隣接2文字スワップの6種類である。

提出コードでは、全点対最短距離、汚れやすいセルの連結成分、各マスの訪問時刻列を前計算・更新しながら使う。多くの近傍は新しい経路を作って生スコアを再計算するが、隣接2文字スワップだけは、新たに訪れるセルと訪れなくなるセルが1つずつで済む性質を使って差分計算する。

## 主要アイデア

- 初期解は左手法で壁を伝う経路から始める。
- 左手法だけでは内部セルを訪問しないため、未訪問連結成分を DFS で埋める。
- DFS は全セル訪問が完了したら途中で打ち切り、最短経路で挿入元へ戻る。
- 焼きなましの主要近傍は、経路の追加・削除・入れ替え・移動で大きく状態を変えるものと、隣接2文字スワップの軽い近傍で構成する。
- 高 `d` 領域を「ボトルネック」として連結成分化し、そこへ出張して戻る経路を追加する。
- 隣接2文字スワップは差分更新が軽く、記事でも順位を大きく上げた近傍とされている。
- スコア比較は、訪問間隔 `gap` ごとの三角形和 `d * gap * (gap - 1) / 2` を周期全体で足して `L` で割る。

## 最終コードの構造

### 状態表現

- `Board`
  - `N`
  - `wall[cell][dir]`: 壁の有無
  - `dirtiness[cell]`: `d`
  - `GLOBAL_DISTANCE[from][to]`: 全点対最短距離
  - 高 `d` セルの連結成分 `component_id`, `component_cells`
- `State`
  - 開始座標 `sr, sc`
  - 移動文字列 `operations`
  - `change_base` により周期列を回転し、開始位置を変えられる
- `StateInfo`
  - `visit_times[cell]`: 各セルの訪問時刻列
  - `position[t]`: 時刻 `t` の位置
  - `swappable_times`: 隣接2文字スワップ候補時刻

### 観測・制約・入力の扱い

- 入力の `h`, `v` を双方向の壁配列へ展開し、外周も壁として明示する。
- 各セルから BFS して全点対最短距離を作る。
- `get_shortest_path` は最短距離を保つ隣接候補のうち、移動先の `d` が最大の方向を選ぶ。
- 高 `d` セルは上位40%程度を閾値にし、隣接しているものを Union-Find で連結成分にする。
- `calculate_score` は、全マス未訪問がある場合や開始位置が `(0,0)` でない場合を無効値にする。

### 評価関数

- 生スコア計算は、周期中の各マスの連続訪問間隔 `gap` について `d * gap * (gap - 1) / 2` を加算する。
- 周期のつなぎ目は、最後の訪問時刻から最初の訪問時刻へ戻る間隔として別途加算する。
- 最終的な評価値は合計を経路長 `L` で割り、切り上げに近い形で整数化する。
- 焼きなましはこの評価値を小さくする方向に進める。
- 隣接2文字スワップでは、消える訪問セルと新たに訪れるセルの2セルだけについて、訪問間隔の分割・結合を差分計算する。

### 探索・構築・更新

- `left_hand`
  - 右向き開始で、左、直進、右、反転の優先順に進み、`(0,0)` へ戻るまで壁沿いを歩く。
- `flesh_out`
  - 左手法経路で訪れていないセルを Union-Find で連結成分化する。
  - 経路上の各位置から隣接未訪問成分を見つけ、DFS 経路を挿入する。
- `dfs_prunning`
  - 未訪問成分内を DFS で歩く。
  - 全セルを訪れたら探索を打ち切り、最短経路で挿入元へ戻る。
- `resolve_bottle_neck`
  - 高 `d` 連結成分をランダムに選ぶ。
  - 現在位置に近い成分内セルへ最短経路で向かい、その成分を DFS で回って戻る経路を挿入する。
- `delete_route`
  - 隣接セル `rc0, rc1` の2つの訪問時刻を使い、間の経路を直接辺で置き換えて削除する。
- `swap_route`
  - 同じ隣接セルペアを結ぶ2つの経路区間を選び、区間の順序を入れ替える。
- `move_route`
  - 同じセルを始点・終点にする経路区間を別時刻へ移動し、前後を最短経路で接続する。
- `swap_seq`
  - 隣接する2操作を入れ替え、合法なら差分スコアを返す。却下時は swap を戻す。

### 操作・クエリ・出力選択

- 焼きなまし後の最良 `State` の `operations` を出力する。
- 経路の開始位置が変わる近傍があるため、必要に応じて `change_base(0,0)` で周期を回転する。
- `calculate_score` は `(0,0)` 開始でない状態を無効にするため、出力候補は最終的に `(0,0)` 始まりへ揃える。

### 時間配分・パラメータ

- 制限時間は `1.97` 秒で打ち切る。
- 焼きなまし温度は開始 `1000`、終了 `1` の線形冷却。
- 高 `d` 成分の閾値は `N*N*0.4` 番目程度、すなわち上位40%を基準にする。
- 経路移動の接続先距離は `N * max_distance_ratio` 以下に制限し、`max_distance_ratio = 1.0`。
- 6種類の近傍から一様に選ぶが、提出コード上では経路削除と追加の近傍にさらに確率的な continue が入る。

## 実装上重要な断片

```text
score(route):
    for each cell:
        collect visit times in one period
        if never visited: invalid
        for consecutive visits including wrap-around:
            total += d[cell] * gap * (gap - 1) / 2
    return ceil(total / L)
```

```text
flesh_out(left_hand_route):
    mark cells visited by wall-following route
    build components of unvisited cells
    for each position on route:
        for each adjacent unvisited component:
            insert dfs_prunning(component, return_to_position)
```

```text
annealing_loop:
    choose one of 6 neighborhoods
    build next state or compute local delta
    accept with exp((current_score - next_score) / temp)
    update best when score improves
```

## この解法の本質

この解法の本質は、初期解を素朴に作ったうえで、近傍設計でスコアを大きく動かしている点である。左手法と DFS による初期解は強くないが、全マス訪問と帰還を安定して満たす。その後、経路挿入や経路スワップのような大きな近傍で周期構造を変え、隣接2文字スワップのような軽い近傍で反復回数を稼ぐ。

特に隣接2文字スワップは、操作列上の局所変更が訪問セル2個の差分に落ちることを利用している。AHC027では訪問間隔がスコアの本体なので、訪問時刻列を持つとこのような軽量近傍が作れる。

## 真似するならまず実装する部分

まず、左手法または DFS で全マス訪問の周期路を作り、生スコアを正しく計算する関数を作る。次に、削除しても全マス訪問が維持される区間削除、または隣接2文字スワップを実装するのがよい。

提出コード全体を真似るなら、`State` と `StateInfo` を分ける構造が重要である。経路文字列だけでなく、訪問時刻列と時刻ごとの座標を再構築できるようにしておくと、近傍を追加しやすい。

## 注意点・未理解点

- 記事中の G4NP0N 氏スライドは読めていない。ただし tsutaj 氏の最終提出コードと本文の説明は確認できた。
- 提出コードには、`swap_route` 内でコメント上「バグだけど放置」とされている重複区間がある。意図的な近傍として許容されている可能性はあるが、再実装時には検証が必要である。
- `calculate_score` は `State` の開始位置が `(0,0)` でないと無効にするため、周期回転を忘れると正しい経路でも評価不能になる。
- フルスコア計算を多用する近傍は経路長に比例して重くなる。隣接2文字スワップのような差分近傍を混ぜないと反復回数が伸びにくい。
