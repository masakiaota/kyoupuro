## 解法の全体像

公式ページは本文解説というより解説リンク集である。実質的な公式解説は AHCラジオで、問題を「連続座標の幾何問題」ではなく「グリッド上のマス集合選択問題」に変換する方針が説明されていた。

座標平面を粗いグリッドへ分割し、各マスに `サバ数 - イワシ数` を割り当てる。選ぶマス集合は連結で、外側も連結、境界長が制限以下である必要がある。この制約下でマスの ON/OFF を探索し、最後に ON/OFF 境界を多角形として辿って出力する。さらに、粗いグリッドで大域的な形を作ってから細かいグリッドへ分割し直すことで、大域移動と局所調整を両立する。

## 主要アイデア

- 座標が `10^5 x 10^5` と大きいため、直接多角形頂点を動かすのではなくグリッドに落とす。
- 各マスの価値を `サバ数 - イワシ数` とし、内側にするマス集合の合計を評価する。
- 選ぶマス集合は連結、外側マスも連結に保つ。外側連結を保つことで穴を避け、単純多角形として復元しやすくする。
- 1 マス ON/OFF 近傍で探索する。スコア差分と境界長差分は局所的に計算できる。
- 連結性判定は毎回 DFS せず、周囲 `3x3` の局所パターンだけで安全側に判定する。
- 出力は、ON/OFF 境界に辺を張り、右手法・左手法または境界グラフの巡回で多角形頂点列へ復元する。
- 最初から細かいグリッドにすると探索が動きにくいため、粗いグリッドの解を細分化して次の初期解にする。

## 最終コードの構造

コードなし。公式ページと AHCラジオから推測できる実装構造を書く。

### 状態表現

- `grid[h][w]`: 各マスが内側なら ON、外側なら OFF。
- `cell_score[h][w]`: マス内の `サバ数 - イワシ数`。
- `current_score`: ON マスの `cell_score` 合計。
- `current_perimeter`: ON/OFF 境界の長さをグリッド幅で換算した値。
- 番兵として外周に OFF マスを置くと、外側連結や境界追跡を扱いやすい。

### 観測・制約・入力の扱い

- 入力の `N=5000` サバ、`N=5000` イワシを、現在の分割数に応じてマスへ加算・減算する。
- グリッド化では境界上の魚の扱いに注意が必要である。公式ラジオでは正確な境界処理より、グリッド近似として扱う方向が主に説明されていた。
- 出力時には、頂点数 `1000`、周長 `4e5`、座標範囲、軸平行、自己交差なし、全頂点相異なることを満たす必要がある。

### 評価関数

- 基本評価は ON マスの合計値である。

```text
score(grid) = sum(cell_score[y][x] for ON cells)
```

- 実スコアは境界上の魚を含む点やセル近似のずれがあるため完全一致ではないが、探索用の代理評価として十分使える。
- 境界長は制約として扱い、長さ超過する遷移を拒否する。

### 探索・構築・更新

- 近傍は 1 マスの ON/OFF 反転。
- 反転候補は、現在の境界に隣接するマスから選ぶと有効遷移の比率が上がる。
- 反転時には次を差分で見る。
  - スコア差分: そのマスの `cell_score` を足す、または引く。
  - 周長差分: 4 近傍に同じ状態のマスがいくつあるかで境界辺数の増減を出す。
  - 連結性: ON を消す場合は ON 側、ON を足す場合は OFF 側が分断されないかを `3x3` で安全判定する。
- 焼きなましまたは山登りで反転を採択する。ラジオでは焼きなましとして紹介されていた。
- 粗い分割で探索し、各マスを `2x2` へ分割して同じ ON/OFF をコピーし、さらに探索する。

### 操作・クエリ・出力選択

- 最終的な ON/OFF 境界を座標に戻す。
- 境界グラフを作る方法と、壁沿いを右手法・左手法で辿る方法が紹介されていた。
- 連続する 3 点が一直線上にある場合は中間点を消すと頂点数を減らせる。
- 複数解を出力できる問題だが、最後の解だけが採点される。通常は最良解だけを出す。

### 時間配分・パラメータ

- 公式ラジオでは、粗いグリッドから細かいグリッドへ進める方針が本質として説明されていた。
- 細かくしすぎると、周長が減る遷移が起きにくく、局所的な凹凸で周長を浪費しやすい。
- 粗い解を初期解にして細かいグリッドへ移すことで、大域形状を維持しながら局所の無駄を削る。
- 具体的な温度、反復数、分割数の最終値は公式コードとしては公開されていない。

## 実装上重要な断片

```text
solve_grid(M, initial_grid):
    cell_score = build_cell_scores(M)
    grid = initial_grid
    while time remains for this level:
        p = random_boundary_neighbor_cell()
        if not local_connectivity_ok_after_toggle(p):
            continue
        delta_len = perimeter_delta(p)
        if current_perimeter + delta_len > LIMIT:
            continue
        delta_score = score_delta(p)
        if accept(delta_score, temperature):
            toggle(p)
    return grid

for M in coarse_to_fine:
    grid = solve_grid(M, grid)
    grid = split_each_cell_to_2x2(grid)
```

境界復元は次の考え方になる。

```text
build boundary edges between ON and OFF cells
start from one boundary edge
walk while keeping ON side consistently on one side
remove collinear intermediate vertices
output vertex list
```

## この解法の本質

この問題の難所は、魚の分布を見つけることよりも「良い領域を、短い軸平行単純多角形として表す」ことにある。グリッド化すると、幾何の自己交差判定や多角形操作を、連結なマス集合と境界長の問題へ置き換えられる。

粗いグリッドでは遠いクラスタを取りに行く大域的な形を作りやすい。細かいグリッドでは境界を少しずつ削って、局所的にイワシを避けやすい。段階的細分化は、この 2 つの利点を同じ実装で両立するための工夫である。

## 真似するならまず実装する部分

まず `M x M` グリッドに `サバ数 - イワシ数` を持ち、ON/OFF マス集合のスコアと周長を差分更新する部分を作る。最初は全 ON から山登りでマスを消すだけでもよい。次に ON/OFF 両方の連結性を壊さない判定を入れ、最後に境界を辿って多角形へ復元する。

上位化するなら、粗い分割から細かい分割への引き継ぎを入れる。これが公式ラジオでも最も重要な拡張として説明されていた。
