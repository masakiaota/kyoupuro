## 解法の全体像

2つのシーンに同じ形のブロックを置く候補を大量に作り、その候補でシルエットを覆う構築問題として扱う。単純な山登りや焼きなましでは、同じ形状を保ったまま小変更するのが難しいため、前向きのビームサーチで「まだ満たしていないシルエットセル」を順に埋める。

基本形は、未充足セルを1つ選び、そのセルを覆えるブロック対を追加し、重なりを許さない範囲でBFSにより最大拡張する。被覆量だけで評価するとブロックサイズの分布が悪くなるため、不要セルの削除、既存ブロックからのセル奪取、セル重み、最終山登りを組み合わせて、少数かつ大きさの偏りが少ない共通ブロック集合を作る。

## 主要アイデア

- 2つのシーン内の同型ブロック対を、24回転を含めてBFSで最大拡張した候補として考える。
- 最初に「シルエット集合被覆」として見るが、交差を後から消す方針は難しいため、有効な部分解だけを保つ前向きビームに寄せる。
- ビームでは次の未充足シルエットセルを覆うブロック候補を追加し、重ならない最大形状まで伸ばす。
- 追加後に、被覆改善に寄与しない葉セルをBFS木の逆順で削る。
- 完成後は小さいブロックから再拡張し、`sum 1/v_i` を下げる。
- 候補ブロックの統計から、覆いにくいシルエットセルに高い重みを付ける。
- 未充足セルの処理順も重みに基づき、重要なセルを先に埋める。
- 最後に、ブロック削除・再構築・セル奪取系の山登りでバランスを改善する。

## 最終コードの構造

Browserで読めた提出 `40300018` と記事本文を合わせた実装構造を書く。

### 状態表現

- 2つのシーンそれぞれに、`D^3` の占有配列を持つ。
- 各ブロックIDに対して、シーン1側のセル集合、シーン2側のセル集合、BFS拡張木、体積を持つ。
- 各ブロック候補は、シーン1の始点、シーン2の始点、回転、BFSで得た同型セル列を持つ。
- ビーム状態は、現在の占有、満たしたシルエットセル集合、ブロック集合、評価値を持つ。
- 交差数や被覆数は高速化のためビットマスクで持つとされている。

### 観測・制約・入力の扱い

- 各シーンの置ける3Dセルは、`f[z][x]=1` かつ `r[z][y]=1` のセルに限定する。
- シルエットセルは正面セル `(z,x)` と右側セル `(z,y)` の2種類として扱う。
- あるブロックを置くと、そのセル集合から投影される正面・右側のシルエットセルが新たに被覆される。
- ブロック同士の占有交差は、最終的にWA要因になるため、前向きビームでは基本的に許さない。

### 評価関数

- 基本評価はシルエットの被覆量である。
- 改良版では、被覆セル数ではなくセル重みの合計を使う。
- セル重みは「候補ブロックで覆える頻度が低いセルほど重要」という統計から作る。
- 交差を許す被覆問題として解く試みでは、集合サイズと交差数を評価に入れるが、交差解消が難しいケースがある。
- 完成後は本来スコアに近い、共通ブロック体積の逆数和と未使用体積を意識して改善する。

### 探索・構築・更新

- 事前計算:
  - 全候補または多くの候補について、24回転を試す。
  - BFSで同型ブロック対を最大拡張する。
  - 同じシルエットを覆う候補が複数ある場合は小さい候補を捨てる。
- 前向きビーム:
  - 重い未充足シルエットセルから順に選ぶ。
  - そのセルを覆える候補ブロックを列挙する。
  - 現在の占有と重ならない範囲で最大拡張する。
  - 追加後に不要な葉セルを削る。
  - 被覆重み、ブロック分布、交差なしなどで状態を評価して上位だけ残す。
- 既存ブロックからのセル奪取:
  - 新ブロックの拡張時、片側だけ衝突するセルなら所有元から外せるか試す。
  - 外しても所有元が非連結にならず、もう片側の被覆も減らない場合に奪う。
- 後処理:
  - 完成解の小さいブロックから順に再拡張する。
  - 上位ビーム解を初期値として、削除・再構築・セル奪取の山登りを行う。

### 操作・クエリ・出力選択

- 出力は、ビームおよび山登りで得た最良の占有配列をブロックID付きで出す。
- 全シルエットセルが両シーンで満たされ、ブロックごとに同型・連結・非重複であることが必要である。
- 使われないブロックIDは出力しない。

### 時間配分・パラメータ

- 事前計算候補数、ビーム幅、候補削減数、最終山登り時間が主要パラメータになる。
- 記事では具体値は示されていない。
- 連結性判定が最も遅い部分の1つとされているため、セル削除や奪取を多用する場合は高速な切断判定が重要である。

build_candidate(start1, start2, rot):
    queue = [(0,0,0)]
    shape = []
    while queue:
        local = pop()
        for dir in 6近傍:
            nxt = local + dir
            p1 = start1 + rotate(nxt, rot1)
            p2 = start2 + rotate(nxt, rot2)
            if p1,p2 が置けるセルかつ未占有:
                add nxt
    return shape, bfs_tree
```

beam_step(state):
    target = highest_weight_uncovered_cell(state)
    for candidate covering target:
        next = add_maximal_non_overlapping_block(state, candidate)
        trim_redundant_leaves(next.block)
        push next by evaluation
    keep top beam_width
```

## この解法の本質

この問題を「3D形状を直接少しずつ変える局所探索」ではなく、「同型ブロック対による重み付きシルエット被覆」として扱っている点が本質である。スコアは完成して初めて意味を持ちやすく、部分解の評価が難しい。そこで、まず未充足セルを確実に減らす前向き構築で可行性を守り、覆いにくいセルを先に処理し、最後に体積分布を整える。

また、候補統計から難しいシルエットセルを推定する発想が強い。大きいブロックを作るだけでは後半の狭い領域が残りやすいので、後で詰まりやすい制約を早く処理する。

## 真似するならまず実装する部分

最初に作るべきなのは、24回転込みの「2シーン同型BFS拡張」と、未充足シルエットセルを1つ選んでブロックを追加する前向き構築である。ビーム幅を小さくしてもよいので、交差なしの可行解を作れるようにする。

その後、被覆頻度からセル重みを作り、未充足セルの順序と候補評価に入れる。セル奪取や最終山登りは実装が重く、連結性判定も壊れやすいため、基本構築が動いてから追加する方がよい。
