# 記号一覧

このファイルは、問題で使う記号と、実装・会話で使う代表名・型・制約の正本である。

## notation 方針

- 公式記号名は保持する。公式が `N`, `K`, `X`, `T` ならそのまま使う。
- 添字は 0-based とし、盤面上の値は `a[i,j]` のような配列アクセス風表記を使う。
- 座標 `(i,j)` は `i` が上から下への行、`j` が左から右への列である。
- TeX は条件分岐や総和などの数式構造だけに使い、コードフェンスには入れない。
- 解法考察や仮説は混ぜない。状態量・添字・型・不変条件だけを書く。

## 固定サイズ

### 盤面サイズ `N`

N x N マスの盤面の一辺の長さを表す。

- 議論用 notation: `N`
- コード上の代表名: `N`、または Rust 実装では `n`
- Rust 型: `usize`
- index 範囲・不変条件: 全テストケースで `N = 20`。問題文上は偶数である。
- 派生値: 盤面マス数は `N^2 = 400`、カード番号の種類数は `N^2 / 2 = 200`、操作回数上限は `2N^3 = 16000`。

## 入力

### 初期配置 `a[i,j]`

初期状態でマス `(i,j)` に置かれているカードの番号を表す。

- 議論用 notation: `a[i,j]`
- 公式表記: `a_i,j`
- コード上の代表名: `a`, `grid`, `board`
- Rust 型: `Vec<Vec<usize>>`、`[[usize; 20]; 20]`、またはフラット配列 `[usize; 400]`
- index 範囲・不変条件: `0 <= i < N`, `0 <= j < N`
- 値域: `0 <= a[i,j] <= N^2 / 2 - 1`
- 個数条件: 同じ値の `a[i,j]` はちょうど 2 つ存在する。

### カード番号 `v`

カードに書かれた番号を表す。問題文では明示的な記号名はない。

- 議論用 notation: `v`
- コード上の代表名: `v`, `card`, `label`
- Rust 型: `usize`
- index 範囲・不変条件: `0 <= v < N^2 / 2`
- 個数条件: 各 `v` は初期状態で盤面上に 2 枚ずつ存在する。

## 座標・移動

### 位置 `(i,j)`

盤面上のマスの座標を表す。一番左上のマスが `(0,0)` である。

- 議論用 notation: `(i,j)`
- コード上の代表名: `pos`, `(i, j)`, `Point { i, j }`
- Rust 型: `(usize, usize)` または専用 `struct`
- index 範囲・不変条件: `0 <= i < N`, `0 <= j < N`
- 備考: 下方向に進むと `i` が増え、右方向に進むと `j` が増える。

### 現在位置 `pos`

各ターンの操作前後におけるプレイヤーの現在位置を表す。問題文では明示的な記号名はない。

- 議論用 notation: `pos = (i,j)`
- コード上の代表名: `pos`, `cur`
- Rust 型: `(usize, usize)` または専用 `struct`
- 初期値: `(0,0)`
- 不変条件: 常に盤面内にある。

### 移動方向 `d`

操作 1 で隣接マスへ移動するときの方向を表す。出力文字と座標差は次の対応である。

```text
U: (-1,  0)
D: ( 1,  0)
L: ( 0, -1)
R: ( 0,  1)
```

- 議論用 notation: `d`
- コード上の代表名: `dir`, `mv`
- Rust 型: `char`、`u8`、または enum
- 不変条件: 移動後も `0 <= i < N`, `0 <= j < N` を満たす必要がある。

## 操作列

### 操作文字 `c[t]`

t ターン目の操作を表す 1 文字である。

- 議論用 notation: `c[t]`
- 公式表記: `c_t`
- コード上の代表名: `ops`, `answer`, `out`
- Rust 型: `Vec<char>`、`Vec<u8>`、または `String`
- index 範囲・不変条件: `0 <= t < T`
- 値域: `U`, `D`, `L`, `R`, `Z`, `X`

### 操作回数 `T`

出力する操作列の長さを表す。

- 議論用 notation: `T`
- コード上の代表名: `T`, `ops.len()`
- Rust 型: `usize`
- 制約: `T <= 2N^3`
- 備考: 移動、取る、置くのすべてが `T` に含まれる。

### 移動回数 `K`

出力した操作列に含まれる移動操作の回数を表す。

- 議論用 notation: `K`
- コード上の代表名: `K`, `move_count`
- Rust 型: `usize`
- 値域: `0 <= K <= T`
- 備考: 評価で直接引かれるのは `K` のみで、`Z` と `X` の回数は評価値には直接含まれない。

## 状態量

### 盤面状態 `board[i,j]`

操作列を実行している途中のマス `(i,j)` のカード有無とカード番号を表す。問題文では明示的な記号名はない。

- 議論用 notation: `board[i,j]`
- コード上の代表名: `board`, `cells`
- Rust 型: `Vec<Vec<Option<usize>>>`、`[[Option<usize>; 20]; 20]`、またはフラット配列
- index 範囲・不変条件: `0 <= i < N`, `0 <= j < N`
- 値: カードがある場合は `Some(v)`、空きマスの場合は `None`
- 初期値: `board[i,j] = Some(a[i,j])`

### 山札 `stack`

現在持っている山札を表す。最後に取ったカードまたは置かずに残っているカードが一番上にある。

- 議論用 notation: `stack`
- コード上の代表名: `stack`
- Rust 型: `Vec<usize>`
- 不変条件: 末尾を一番上として扱うなら、取る操作 `Z` は `push`、置く操作 `X` は `pop` に対応する。
- 取る操作後の除去規則: 取った結果、山札の上から 2 枚のカード番号が一致した場合、その 2 枚を山札から取り除く。

### 残カード枚数 `X`

最終的に盤面および山札に残っているカードの枚数を表す。

- 議論用 notation: `X`
- コード上の代表名: `X`, `remaining`
- Rust 型: `usize`
- 値域: `0 <= X <= N^2`
- 定義: 最終盤面上のカード枚数と最終山札内のカード枚数の合計。

## スコア

### テストケース得点 `score`

1 テストケースに対して得られる得点を表す。

- 議論用 notation: `score`
- コード上の代表名: `score`
- Rust 型: `i64` または `isize`
- 定義:

$$
score =
\begin{cases}
N^2 + 2N^3 - K & (X = 0) \\
N^2 - X & (X > 0)
\end{cases}
$$

### テストケース数

提出の総合得点は 150 個のテストケースの得点合計である。

- 議論用 notation: `case_count`
- コード上の代表名: `case_count`
- Rust 型: `usize`
- 値: `150`
