# スコア重みの分析

この問題の得点は、各クエリの品質 `a_k / b_k` に対して
`0.998^(1000-k)` の重みを掛けて加算する形である。

```text
score = round(2312311 * sum_{k=1}^{1000} 0.998^(1000-k) * a_k / b_k)
```

ここでは、経路品質 `a_k / b_k` が全ターンで同じだった場合の、ターン区間ごとの相対寄与を整理する。

## 100ターンごとの寄与

| ターン | 区間寄与 | 累積寄与 |
|---:|---:|---:|
| 1-100 | 3.46% | 3.46% |
| 101-200 | 4.23% | 7.69% |
| 201-300 | 5.17% | 12.85% |
| 301-400 | 6.31% | 19.17% |
| 401-500 | 7.71% | 26.87% |
| 501-600 | 9.42% | 36.29% |
| 601-700 | 11.51% | 47.80% |
| 701-800 | 14.06% | 61.85% |
| 801-900 | 17.17% | 79.02% |
| 901-1000 | 20.98% | 100.00% |

全重み和は約 `432.467738777` である。全ターンで `a_k / b_k = 1` の場合、得点は約 `999999910` になる。

## 観察

- 1ターン目の重みは約 `0.135335`、1000ターン目の重みは `1.0` であり、1000ターン目は1ターン目の約 `7.39` 倍重い。
- 1-100ターンの合計寄与は `3.46%` にすぎない。
- 1-300ターンまで含めても累積寄与は `12.85%` である。
- 1-500ターンまでの累積寄与は `26.87%` であり、前半全体の重みはかなり軽い。
- 701-1000ターンだけで全体の `52.20%` を占める。
- 901-1000ターンだけで全体の `20.98%` を占める。

## 探索と活用への含意

序盤のクエリは、多少遠回りしても、未知辺長の推定に役立つなら回収しやすい。特に 1-100 ターンの総寄与は小さいため、後半の経路品質を改善できる情報を取れるなら探索的な出力を許容しやすい。

一方で、後半の遠回りは重い。900ターン目以降は残りクエリ数も少なく、そこで得た情報を将来に反映できる機会が限られる。そのため、後半では探索よりも既存推定に基づく活用を優先するのが自然である。

序盤探索で価値が高い情報は、単発の辺長推定よりも、将来の多くのクエリに効く情報である。例えば、行ごとの横辺傾向、列ごとの縦辺傾向、`M=1/2` の判定、分割位置 `x_i` / `y_j` の推定、全体スケールの補正などが候補になる。

## 損益分岐の目安

あるターン `k` で、最短なら `a_k / b_k = 1` のところを、`r` 倍遠い経路にして `a_k / b_k = 1/r` に落とすと、重み付き損失は次である。

```text
loss = 0.998^(1000-k) * (1 - 1/r)
```

この損失を将来ターンの平均改善 `delta` で回収するには、概ね次を満たせばよい。

```text
delta > loss / sum_{j=k+1}^{1000} 0.998^(1000-j)
```

例えば2倍遠回りする場合、必要な将来平均改善量は以下である。

| 探索ターン k | 必要な将来平均改善量 |
|---:|---:|
| 1 | 0.000157 |
| 100 | 0.000198 |
| 300 | 0.000327 |
| 500 | 0.000581 |
| 700 | 0.001215 |
| 900 | 0.004512 |

序盤の2倍遠回りは、将来の `a_k / b_k` を平均で `0.0002` 程度改善できるだけでも回収できる。逆に900ターン目の2倍遠回りは、残りターンに平均 `0.0045` 程度の改善が必要であり、明確な根拠なしには採りにくい。
